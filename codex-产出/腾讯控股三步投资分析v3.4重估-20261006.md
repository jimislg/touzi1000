## 2. 第零步

主类型：**平台与成长型**（分阶段FCF/每股收益模型+反向DCF）。风险标签：监管、AI技术替代、资本开支、汇率。能力圈：向用户/广告主/游戏玩家/企业收钱；护城河在高转换成本与网络效应；十年后大概率仍是社交与内容基础设施。**无否决、无暂停**。

## 3. 第一步三轴（承接10-06五标的报告，2026中报复核）

- **需求轴：稳定偏结构**。微信MAU 14.39亿（+2%）见顶，增长靠单用户价值；视频号时长+20%、广告+22%（AIM+落地）、本土游戏+17%。传导：销量假设取正常化，不自动加终值倍数。
- **利润池轴：稳定**。社交/游戏/广告/支付四池均处头部，字节持续施压但未夺池。传导：利润率用正常化，禁止与增长重复计算。
- **范式风险：中**。AI Agent 若成新入口绕开微信是真实断代风险；腾讯卡位（Hy3模型+WorkBuddy/CodeBuddy breakout增长）已初步验证但未完成。传导：终值倍数取14x（低于历史中枢），乐观情景才允许18x。

**风险去重**：AI capex→已入基准增速（Q2剔除新AI产品经营利润+19% vs 含AI+9%）；监管→终值14x体现；不再重复降权。

## 4. 第二步结论（承接）

**A类维持**。最强证据：14.39亿MAU×99%留存、2021-2025利润复合+20.3%、净现金582亿+上市投资4872亿。最大风险：AI资本开支2026H1达847亿(+82%)、Q2 FCF-138亿、回报未验证。**但投资标签下调：见第三步**。

## 校准附录（10-06 深夜，回应《腾讯与安踏v3.4重新核算研究报告》）

独立审计报告指出本报告两处口径问题，**均属实，已更正**：

1. **H档位误用税前股息**：原 455/384/300/246 为税前口径，与平安 H 档（税后）不一致。税后（港股通20%）重算主口径：**H10=444.7 / H12=374.4 / H15=291.4 / H17.46=238.8**。新增资金门槛由 384 下修至 374.4。
2. **"悲观+10pct"权重合计 1.025**（0.35+0.45+0.225）：修正为 0.35/0.45/0.20 后，敏感性等效 CAGR 由约 10.2% 降为 9.78%（基准权重 2.78 倍/10.77% 不变）。
3. **采纳其 SBC 经济成本下端敏感性**：EPS 25.98（SBC 全额扣回代理）下税后 IRR 8.94%，档位 390.3/328.6/255.8/209.6——这是模型下端，非主口径。
4. **结论不变**：税后基准 10.44% 仍落入 10–15% 区间 → 组合辅助型、现价（428.2）持有合理、新增 ≤374.4 才进第四步。但按审计报告纪律：**归母正常化 owner earnings 现金桥未通过前，全部档位为研究口径，不构成正式定价**；正式定价需补 SBC 税效、经常维护投入分拆与独立现金流估值。

安踏对照：本日快筛（税后 11.1%）与审计报告基准诊断（税后 11.2%）独立收敛，档位维持 78.1/66.6/52.9/44.2；其"H1 剔一次性年化 EPS 5.61 → 72 港元 IRR≈12.0%"列为上端敏感性。
