# 三步个股投资分析法 + 第四步组合决策

版本：v3.4（压缩自由裁量，补齐目标导航、多上市地、压力损失与换仓门槛）
原定稿日期：2026-08-27
修订日期：2026-10-06
用途：中国A股、港股及其他可投资上市公司研究
目标：让不同Agent在使用相同数据时，得到同口径的事实、计算、公司分类和价格区间；只有前三步达到A/B类的公司进入观察池，并在第四步独立评估其纳入现有组合后的成果、风险与机会成本。

---

## 一、框架定位

本框架分为两个相互隔离的层次。前三步回答三个个股问题，顺序不可颠倒：

1. **公司所处细分市场的需求、利润池和范式风险是什么？**
2. **它是不是一家值得长期持有的好公司？**
3. **当前价格能否提供足够回报和安全边际？**

前三步完成后，只有A类或B类公司进入观察池。进入观察池不等于买入；当需要判断是否纳入现有组合时，才触发第四步：

4. **如果把它纳入组合，预计带来什么成果、增加什么风险、替代谁、买多少？**

细分市场需求下降或利润池恶化不自动否决公司，需求增长也不自动加分；好公司未通过，不因价格低而进入估值和买入环节；好公司通过，也不代表当前股票值得买入。第四步不得反向修改前三步已冻结的市场三轴判断、公司分类、经营假设和估值参数。

```text
第零步：数据、能力圈、类型标签、一票否决
    ↓
第一步：看清细分市场（需求轴、利润池轴、范式风险 → 参数传导）
    ↓（市场三轴结论强制传导至后两步）
第二步：好公司八维分析
    ↓
质量双重对标（茅台 + 最优秀直接竞争者）
    ↓
第三步：好价格与目标收益倒算
    ↓
茅台回报参考
    ↓
A/B类进入观察池；C/D类停止
    ↓（仅在拟纳入现有组合时触发）
第四步：组合适配与成果测算
```

### 前三步与第四步的防火墙

- 前三步只研究个股，不因现有组合缺口而降低质量标准或抬高估值；
- 前三步完成后冻结细分市场结论、A/B/C/D分类、正常化盈利、情景参数和目标回报买价；
- A/B类进入观察池只代表获得组合审查资格；C/D类不进入第四步；
- 第四步只评估边际组合效果，不重新评价公司；
- 若第四步结果不合格，结论是“不纳入组合”，不是回头修改前三步使其合格。

### 两种运行模式

- **快筛模式**：只执行第零步、第一步和否决检查，输出“继续 / 补数据 / 停止”资格卡；用户确认后再进入第二、三步；
- **完整研究模式**：用户明确要求完整研究时连续执行。第零步和第一步结束后自动执行内部闸门；只有命中停止条件才暂停，不增加一次机械确认。

第四步始终有条件触发，不因运行模式改变。

### 可复现性的边界

不同Agent必须一致的部分：

- 数据截止日、币种、复权口径；
- 历史财务数据及计算公式；
- 事实、计算、假设、判断的标签；
- 公司类型和使用的主估值模型；
- 5年与10年目标收益率；
- 情景计算方法、税费口径和买入档位；
- 第四步使用的组合基线、资金来源和持仓口径；
- 最终报告结构。

允许存在差异的部分：

- 未来收入增长率；
- 正常化利润率；
- 分红率、回购与再投资回报；
- 终值倍数；
- 风险发生概率。

上述判断性参数必须逐项列示依据。禁止只给结论、不公开假设。

### 估值口径与版本审计门（v3.1 新增）

以下规则是输出正式经济价值、H档位和仓位建议之前的强制门槛，不是可选检查：

1. **先锁定估值对象，再开始计算。** 明确列示纳入估值的业务、资产、负债和表外义务，以及按零、负值或另行估值处理的项目。报告中途不得在“核心业务”“核心生态”和“全公司”之间切换口径；如需切换，必须从头重跑模型。
2. **建立四座勾稽桥。** 分部收入与利润 → 合并收入与税前利润；税前利润 → 所得税、少数股东损益与归母净利润；归母净利润 ÷ 稀释后股本 → EPS；经营现金流 → 维持性资本开支、正常营运资本投入与所有者收益/自由现金流。任一桥无法勾稽或差异超过1%且无法解释，结论降为“无法定价”。
3. **四种 EPS 必须分栏。** 年报 EPS、TTM EPS、正常化 EPS、预测 EPS 不得混用。引用“当前市盈率”时必须同时写清价格日期、EPS 截止期及其属于哪一种 EPS，并验证 `股价 ÷ EPS = PE`。
4. **执行三项恒等式检查。** 股价 ÷ EPS = PE；股价 × 稀释后股本 = 市值；各分部加总 ± 抵销/总部成本 = 合并口径。恒等式未通过，不得进入估值结论。
5. **主模型必须有独立交叉验证。** 两条路径差异超过20%时，必须拆解原因；无法解释则停止输出正式买价，只保留情景测算。
6. **所有计算使用程序，并保留输入表。** 输入至少包括基准利润或现金流、增长率、利润率、股本变化、分红、税费、终值倍数和折现率；禁止只在文字中心算或倒推。
7. **版本漂移必须归因。** 新旧报告的内在价值或任一买价档位变化超过10%，必须输出“旧值—新值—变化额—归因”表，至少覆盖估值对象、基准盈利、增长率、利润率、税率、稀释、分红和终值倍数。
8. **旧价格线自动冻结。** 新报告发布后，旧报告须标记“已被复核替代”，不得继续作为下单依据；严禁静默覆盖历史结论。
9. **审计门未全部通过，不得给正式经济价值或H档位。** 可以输出“研究草案”或“情景敏感性”；仓位和“可下单”结论还必须通过第四步。

这组规则的目的不是追求假精确，而是确保同一套数据只能导出一套可解释、可复算、可追溯的结论。

## 二、用户目标与统一收益门槛

### 既定目标

- 投资本金：1,000万元；
- 5年2倍：要求年化总回报 **14.87%**；
- 10年5倍：要求年化总回报 **17.46%**；
- 长期被动股息目标：每年税前100万元，按名义固定金额管理，并具有可持续增长能力；
- 生活支出由投资本金之外的收入承担。

5年2倍是中期最低检查点，10年5倍是主目标。若前5年恰好只达到2倍，后5年从2倍增长到5倍需要年化20.11%；因此个股和组合不能为了满足5年检查点而降低10年回报纪律。

### 组合目标优先级

1. **硬约束**：避免不可接受的永久性资本损失；命中诚信、治理、杠杆、流动性或论文红线时，停止比较其他目标；
2. **主要目标**：在硬约束内提高10年人民币期末财富，争取达到5000万元；
3. **终态约束**：第10年组合具备产生税前100万元可持续年股息的能力；税后实际到手金额只作现金流披露，不另设统一80万元目标；
4. **路径指标**：第5年2000万元用于检查，不得成为降低质量标准、安全边际或提高风险预算的理由。

不把四项目标合成为单一分数。

### 所有A/B类公司统一输出四种目标回报买价

| 价格名称 | 基准情景要求 | 含义 |
|---|---:|---|
| H10 回报门槛价 | 10年年化总回报10% | 仅表示达到10%回报的最高价格，不等于内在价值 |
| H12 初始关注价 | 10年年化总回报12% | 达到最低新增资金门槛，可进入第四步审查 |
| H15 优秀机会价 | 10年年化总回报15% | 达到正常仓位候选门槛 |
| H17.46 目标机会价 | 10年年化总回报17.46% | 单项投资在基准情景下满足10年5倍目标 |

5年情景也必须计算，但买入价格以10年模型为主，5年模型用于检查估值回归依赖程度。

### 投资标签

- **目标达成型**：基准情景10年IRR ≥ 17.46%；
- **接近目标型**：15% ≤ 基准IRR < 17.46%；
- **组合辅助型**：10% ≤ 基准IRR < 15%，必须说明股息、防守或分散作用及其对组合目标的拖累；
- **回报不合格**：基准IRR < 10%，不投入新增资金；
- **无法定价**：关键数据或经营假设不可验证。

不能把组合辅助型公司写成“能够实现10年5倍”。低于17.46%的仓位只有在第四步证明其防守、股息或分散价值能够改善组合结果时才可纳入；不得用个股IRR的简单加权平均代替组合现金流与期末财富测算。

以上标签描述基准情景，不是实现承诺。报告必须同时披露悲观情景、情景权重及目标达成敏感性。

## 三、第零步：研究准备

### 1. 输入信息

研究开始前必须确认：

| 字段 | 要求 |
|---|---|
| 公司 | 全称、股票代码、交易所 |
| 研究日期 | 精确到日期 |
| 当前价格 | 价格、时间、币种、是否复权/除息 |
| 汇率 | 港股或海外股票必须注明汇率日期 |
| 多上市地 | 如同时有A股、H股或其他上市地，列明换股比例、权利差异和各市场价格 |
| 当前持仓 | 股数、成本、市场价值；未知则写“未提供” |
| 总投资本金 | 默认1,000万元；如有更新按最新输入 |
| 比较基准 | 默认贵州茅台，同时可增加同行龙头 |

### 2. 信息丰富度

| 等级 | 标准 | 处理 |
|---|---|---|
| A | 至少5年完整财报、最新报告、行业与竞争数据充分 | 正常分析，警惕市场共识偏见 |
| B | 只有3—5年数据或部分分部数据缺失 | 所有推算标记，结论最高为“中等置信” |
| C | 少于3年可靠数据、关键经营指标不可得 | 不强行填表，结论为“数据不足/观察” |

信息丰富度只代表AI研究能力，不代表投资确定性。

### 3. 数据来源优先级

#### 公司事实

1. 交易所公告、公司年报、中报、季报；
2. 公司投资者关系材料和业绩会记录；
3. 监管机构、行业协会、政府统计；
4. 独立金融数据库；
5. 券商报告；
6. 新闻和社交平台只用于发现线索，不单独作为关键结论依据。

#### 市场数据

- A股：交易所/行情接口 + 东方财富等独立来源；
- 港股：港交所披露易/行情 + AAStocks等独立来源；
- 美股：SEC/交易所行情 + StockAnalysis、Macrotrends等独立来源。

### 4. 双来源核验

以下关键数据必须至少两个来源，其中一个尽量为原始公告：

- 当前股价、总股本、市值；
- 收入、归母净利润、扣非利润；
- 经营现金流、资本开支、自由现金流；
- 现金、有息负债、净资产；
- 分红、回购注销、股本稀释；
- 关键市场份额和海外收入。

核验前必须先对齐定义、期间、币种、复权/除权、含税与否、合并范围和统计边界。只有同口径数据才计算误差：

```text
误差率 = |来源A - 来源B| ÷ |来源A|
```

| 误差 | 处理 |
|---:|---|
| ≤1% | 视为一致，使用原始公告数据 |
| 1%—5% | 标注差异并解释口径 |
| >5% | 回到原始报告核实；未解决前停止估值 |

不同口径数据不得直接计算误差率。应分别列出定义、数值和差异原因；若只能得到合理区间，使用区间并降低置信度，不得制造伪精确。

### 5. 标签纪律

报告中的重要数字和结论使用以下标签：

- `[事实]`：原始资料直接披露；
- `[计算]`：由已披露数据按明确公式计算；
- `[假设]`：用于未来预测的输入；
- `[判断]`：根据事实和假设形成的结论；
- `[缺失]`：没有可靠数据；
- `[争议]`：不同来源或口径无法完全统一。

严禁把假设写成事实，严禁用“预计”“大概率”掩盖数据缺失。

### 6. 历史区间

- 默认收集10个完整财年；不足时至少5年；
- 周期公司至少覆盖一个完整景气周期，优先7—10年；
- 同时加入最新中报/季报和TTM；
- 竞争对手至少比较最近3年；
- 使用追溯调整后的同口径数据。

### 7. 公司类型：一个主类型 + 多个风险标签

禁止仅凭“高分红”“成长”给公司单一贴标签。先选择一个主估值类型，再添加风险标签。

| 主类型 | 典型公司 | 主估值方法 |
|---|---|---|
| 稳定消费/医药质量型 | 茅台、东阿阿胶、迈瑞 | 所有者收益/FCF折现 + 正常PE |
| 平台与成长型 | 腾讯、泡泡玛特 | 分阶段FCF/每股收益模型 + 反向DCF |
| 成熟制造型 | 格力、福耀、宇通 | 中周期每股收益/FCF + 股息 + 正常PE |
| 强周期/资源型 | 万华及资源品公司 | 中周期利润、资产负债表、EV/EBITDA或NAV |
| 银行/券商 | 招行、中信证券 | 正常化ROE、账面价值、剩余收益/PB |
| 保险 | 中国平安 | 营运利润、内含价值、投资资产压力测试 |
| 资产经营/公用事业 | 小商品城、长江电力 | 分部资产价值/现金流折现 + 分红能力 |

风险标签可多选：地产相关、监管、单一客户、关键人物、汇率、海外政治、技术替代、高杠杆、原材料、渠道库存、资本开支、并购整合。

### 8. 能力圈测试

必须用不超过200字回答：

1. 公司向谁收钱；
2. 客户为什么持续付钱；
3. 哪三个变量决定利润；
4. 十年后大概率还在做什么。

不能清楚回答，结论为“能力圈不足”，停止分析，不进入第一步。

## 四、第一步：看清细分市场

本步骤先于公司分析完成。目的不是寻找一个抽象的“好赛道”，而是看清目标公司所处细分市场的需求方向、利润池变化和范式风险，并把结论逐项传导给第二步和第三步。

### 1. 细分市场定义与边界

- 按公司主要产品/服务划分细分市场，禁止用大行业冒充细分市场（"食品饮料"不是细分市场，"酱油"才是；"地产"不是，"代建"才是）；
- 明确替代品边界：什么产品/服务出现时客户会离开（技术断代风险的主要来源）；
- 明确价值链位置：上游是谁、下游是谁、谁付钱给谁、利润池当前停在哪一环节。

### 2. 需求轴

必查数据：

- 过去 5—10 年细分市场规模与增速，量价拆分（规模增长来自销量还是价格）；
- 未来 5—10 年驱动变量：人口、渗透率、技术、政策、消费习惯；
- **结构性 vs 周期性裁决（必答）**：当前需求变化是周期波动还是结构迁移？不得默认“周期论”；
- 需求轴结论三选一：**结构增长 / 稳定 / 结构下降**。

### 3. 利润池与竞争轴

- 集中度（CR3/CR5）与头部份额 3—5 年变化；
- 产能供需与利用率分层（头部 vs 尾部，禁止用全行业平均掩盖结构分化）；
- 进入壁垒与退出壁垒；尾部是出清还是全民扩产；
- 竞争要素演变：价格 → 技术 → 服务 → 生态，当前主流竞争手段是什么。
- 量化或方向性判断利润池是在扩大、稳定还是被上下游、替代品或竞争者夺走；
- 利润池轴结论三选一：**改善 / 稳定 / 恶化**。

### 4. 结构性机会

- 结构性增量：新场景、新客户、新技术、政策红利；
- 利润池迁移方向：该环节利润池在扩大，还是被上下游/替代品夺走（必须量化或给出方向性证据）；
- 谁最有能力吃下这些机会——不预设是目标公司。

### 5. 范式风险

- 替代品与技术断代风险（下一代技术会不会重写竞争格局）；
- 内卷与价格战历史及当前烈度；
- 监管、税收、政策变化；
- 十年后这个细分市场还存在吗？规模是更大还是更小？
- 范式风险旗标三选一：**低 / 中 / 高**。

### 6. 综合结论与参数传导（硬性）

禁止用一个“顺风/逆风”标签代替三个维度。必须先分别输出需求轴、利润池轴和范式风险，再形成综合判断。

固定句式：

> `该细分市场的需求轴为___，利润池轴为___，范式风险为___。最强竞争要素是___，最大结构性挑战是___。这些结论分别传导至销量/客户、价格、利润率、再投资、终值和情景概率如下：___。`

#### 参数传导表

| 市场结论 | 第二步证据要求 | 第三步参数传导 |
|---|---|---|
| 需求结构增长 | 证明公司能够获得增量，而非只引用TAM | 可反映到客户/销量，但不得自动提高终值倍数 |
| 需求稳定 | 正常验证份额、价格和复购 | 使用正常化量价与利润率 |
| 需求结构下降 | 客户需求与竞争地位至少各给两项反证 | 下调销量/客户或份额假设，增加结构下行情景 |
| 利润池改善 | 证明改善由供给退出、议价权或价值迁移驱动 | 可反映到利润率或ROIC，必须避免与增长重复计算 |
| 利润池恶化 | 解释价格战、成本转嫁和上下游挤压 | 下调利润率、再投资回报或情景权重 |
| 范式风险高 | 必答公司在下一代技术/监管结构中的卡位 | 禁用历史PE中枢直接做终值；无卡位证据时乐观情景按悲观处理 |

#### 终值纪律

- 需求结构下降或利润池恶化时，基准终值倍数不得高于以下三者中的最低者：当前倍数、历史中周期合理倍数、由成熟期增长和资本回报支持的倍数；
- 当前利润处于周期极端时，必须先使用正常化盈利再比较倍数；
- 需求增长不得自动推导估值倍数扩张；
- 终值占总价值比例过高时，必须披露并增加敏感性分析。

#### 风险去重表

同一风险不得未经说明同时通过经营预测、终值、情景概率和仓位重复惩罚：

| 风险 | 收入/利润率已反映 | 再投资/终值已反映 | 情景权重已反映 | 第四步仓位再折扣 | 是否重复 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

第四步的仓位折扣只处理模型无法吸收的不确定性、尾部风险、流动性和组合相关性。

纪律：

- 市场结论不替代公司判断：结构下降市场仍可能存在好公司，增长市场也可能没有好投资；
- 不得为了支持买入结论而改变需求、利润池或范式风险判断；
- 行业规模、增速、份额数据必须双来源核验（国家统计局、行业协会、龙头企业年报行业部分交叉），**禁止只引用券商行业报告的 TAM**；
- 若TAM并非决定每股价值的关键变量，可标注“非决策关键数据”并使用合理区间，不得为填表强造精确数字；
- 行业判断必须标注 `[事实]`/`[计算]`/`[估计]`/`[争议]`，与其他数据同标尺。

## 五、一票否决与研究暂停

### 永久或结构性否决

命中任一项，结论为D类，不进入估值：

- 经监管或司法确认的重大财务造假、资金占用、利益输送，且治理没有完成可信重建；
- 管理层持续系统性欺骗，关键承诺与事实反复冲突；
- 商业模式主要依赖违法、不可持续补贴或后续投资者接盘；
- 中小股东无法分享企业价值，且控制股东长期侵占价值；
- 竞争优势已被不可逆摧毁，企业只能持续低于资本成本经营。

### 暂停研究或暂不买入

以下情况不是永久拉黑，但必须停止给出买入价：

- 最新审计意见为否定或无法表示意见；
- 关键财务数据双来源差异超过5%且无法解释；
- 出现重大监管、诉讼、债务、产品安全事件，影响尚无法量化；
- 流动性或偿债风险可能迫使公司增发、贱卖资产；
- 最新财报尚未披露，旧数据已经不足以代表当前经营；
- 重大并购、重组或业务转型导致历史数据失去可比性。

暂停状态必须列出恢复研究所需证据。

## 六、第二步：好公司八维分析

每个维度必须输出五项：

1. 核心问题；
2. 至少两项支持证据；
3. 至少一项反方证据；
4. 可观察指标；
5. 结论：`通过 / 存疑 / 不通过 / 中性不适用`。

不使用数字总分。

> 市场输入：第一步的需求轴、利润池轴和范式风险是本步既有输入。维度5不再重复市场级分析，只判断公司在该格局中的相对位置；需求结构下降或利润池恶化时，维度5和维度6各提供至少两项反方证据；范式风险高时，护城河维度必须回答公司在下一代结构中的卡位。

### 维度1：业务聚焦与战略一致性

**核心问题**：公司是否把资本和管理精力放在具有共同能力的业务上？

必查数据：

- 各分部收入、营业利润、资产和资本开支；
- 核心业务利润与自由现金流占比；
- 过去10年并购、处置和跨界投入；
- 亏损新业务累计投入及未来承诺。

判定规则：

- **通过**：核心利润来源清晰；各主要业务至少共享客户、品牌、渠道、技术、数据或供应链中的两项；过去5年不存在持续吞噬价值的无关扩张；
- **存疑**：新业务有协同逻辑但尚未证明回报，或重大并购仍处整合期；
- **不通过**：说不清主要赚钱方式；无关业务连续3年亏损或长期低于资本成本，管理层仍持续投入；
- **注意**：主业收入占比80%只能作为事实，不能单独决定结论。

### 维度2：企业文化、诚信与治理

**核心问题**：管理层在没人监督时，会不会正确对待客户、员工、供应商和股东？

必查证据：

- 历年承诺与兑现记录；
- 审计意见、监管处罚、财务重述；
- 关联交易、薪酬、激励和大股东资金往来；
- 产品安全、客户赔偿、供应商账期；
- 核心人员流失、接班安排和坏消息披露。

判定规则：

- **通过**：没有重大诚信污点；承诺大体兑现；关联交易透明合理；愿意披露坏消息；
- **存疑**：存在关键人物依赖、激励偏宽松或个别治理争议，但没有证据显示系统性侵害；
- **不通过**：重大欺骗、侵占、反复修改口径掩盖问题或系统性损害中小股东；
- 诚信不通过直接触发一票否决。

### 维度3：护城河及变化方向

**核心问题**：客户为什么不换、竞争者为什么难以复制、超额回报能持续多久？

逐项检查：

| 护城河 | 必须提供的证据 |
|---|---|
| 品牌/定价权 | 同类价格溢价、提价后量和份额变化、毛利率 |
| 转换成本 | 迁移成本、合同期限、流程嵌入、客户留存 |
| 网络效应 | 用户增长是否提高产品价值、双边网络密度 |
| 成本/规模 | 单位成本、采购、渠道、产能利用率相对同行 |
| 技术/工艺 | 专利不是充分条件，必须体现良率、性能、成本或认证优势 |
| 牌照/资源 | 稀缺性、期限、监管可撤销性 |

判定规则：

- **通过**：至少一条强护城河，并有两个以上量化证据；过去5年稳定或变宽；
- **存疑**：护城河存在但份额、价格溢价、留存或回报率出现混合信号；
- **不通过**：只能依靠价格竞争，或护城河出现不可逆侵蚀；
- 必须写出“什么能够摧毁这条护城河”。

### 维度4：国际化质量

**核心问题**：国际化是在增加长期价值，还是增加复杂性和风险？

必查数据：

- 海外收入、利润、资产、资本开支和现金流占比及5年变化；
- 自主品牌、代工、产能出海的结构；
- 海外ROIC与国内ROIC；
- 国家、客户、渠道和汇率集中度；
- 海外合规、制裁、关税和本地治理风险。

判定规则：

- **通过**：海外业务至少经历3年验证，利润与现金回报健康，ROIC高于资金成本，风险可控；
- **存疑**：收入增长但利润/现金流未验证，或国家与客户高度集中；
- **不通过**：连续价值毁灭、重大减值、持续低于资本成本且没有退出纪律；
- **中性不适用**：公司不需要国际化即可长期经营；不扣分，也不加分。

### 维度5：行业结构与竞争地位

**核心问题**：公司是否在真实竞争中持续胜出？

必查数据：

- 前三大竞争者、市场份额和3—5年变化；
- 公司与同行价格、毛利率、ROIC、库存和获客成本；
- 上游、下游议价权；
- 新进入者、替代品和政策变化；
- 行业供给退出、集中度和价格战历史。

判定规则：

- **通过**：份额或利润池占比稳定/提升，回报率优于同行，竞争优势不是靠长期降价维持；
- **存疑**：份额与利润率信号不一致，或新技术/新渠道尚未形成结论；
- **不通过**：连续3年以上份额和单位经济同时恶化，行业结构又没有改善路径；
- 必须用一句话说明“最优秀的竞争对手强在哪里”。

### 维度6：客户需求持续性与增长空间

**核心问题**：十年后谁还会付钱，付费人数、频次和客单价如何变化？

必须拆解：

```text
收入 = 客户数量 × 购买频次 × 客单价 × 公司份额
```

订阅/平台公司增加留存率和货币化率；制造业增加更新周期和保有量；银行增加客户资产、贷款需求和风险成本。

判定规则：

- **通过**：需求长期稳定或增长，且公司至少能通过量、价、频次、份额中的一项创造每股价值；
- **存疑**：行业成熟、高渗透、人口或代际形成压力，但更新、提价或份额仍可部分抵消；
- **不通过**：核心客户或使用场景结构性萎缩，公司没有定价、替代产品或市场扩张能力；
- 不得只引用TAM，必须说明公司如何获得利润。

### 维度7：分行业财务质量与资本回报

**核心问题**：利润是否真实、可持续，资产负债表能否穿越压力？

#### 所有非金融公司共同指标

| 指标 | 计算 |
|---|---|
| 每股收入/利润/FCF | 使用加权稀释股数，防止总量增长掩盖摊薄 |
| 现金转换率 | 5年累计经营现金流 ÷ 5年累计调整后净利润 |
| FCF转换率 | 5年累计自由现金流 ÷ 5年累计调整后净利润 |
| ROIC | NOPAT ÷ 平均投入资本，明确现金和商誉口径 |
| 杠杆 | 净债务/EBITDA、利息覆盖、短债/可用现金 |
| 营运质量 | 应收、存货、合同负债和应付相对收入变化 |
| 股本变化 | 5年稀释股数变化、回购注销、员工激励 |

参考判定，不机械跨行业套用：

- 5年累计经营现金流/调整后净利润 ≥ 0.8通常为健康；0.6—0.8需解释；<0.6且无合理营运周期解释为不通过；
- 5年平均ROIC显著高于资本成本并稳定为通过；仅略高为存疑；长期低于资本成本为不通过；
- 净债务/EBITDA <1.5倍通常健康，1.5—3倍需结合稳定性，>3倍必须压力测试；
- 五年稀释超过10%且没有相应每股价值增长，通常不通过。

#### 成熟制造/周期企业追加指标

- 中周期毛利率和营业利润率，不用峰值；
- 维持性与扩张性资本开支；
- 产能利用率、库存跌价、应收和客户集中；
- 原材料、汇率和海外工厂压力测试。

#### 银行/券商

- 5—10年正常化ROE及波动；
- 净息差/手续费率、成本收入比；
- 不良生成率、关注类贷款、拨备覆盖、信用成本；
- 核心一级资本充足率及监管缓冲；
- 资产结构、房地产和地方融资暴露；
- 券商使用中周期ROE，不能使用牛市峰值利润。

#### 保险

- 营运利润和自由盈余；
- 新业务价值及其假设质量；
- 内含价值、合同服务边际；
- 综合/核心偿付能力；
- 投资资产信用、权益、地产和利率敏感性；
- 代理人数量、产能、退保和继续率。

判定规则：

- **通过**：完整周期内每股价值增长、现金/资本质量健康、杠杆可控，无重要趋势恶化；
- **存疑**：整体健康但一个关键指标连续恶化，或行业周期尚未验证；
- **不通过**：利润与现金/资本长期背离、杠杆可能导致被迫融资、每股价值持续被摊薄；
- FCF收益率、PE、PB和股息率属于第二步，不得在本维度参与好公司判断。

### 维度8：管理层与资本配置

**核心问题**：公司赚到的钱如何分配，是否增加每股内在价值？

必须制作过去5—10年资本配置表：

| 用途 | 累计金额 | 结果 |
|---|---:|---|
| 主业再投资 |  | 增量利润、增量ROIC |
| 并购 |  | 商誉、减值、协同兑现 |
| 分红 |  | 分红率、稳定性、税后股息 |
| 回购 |  | 回购价格、是否注销、股本变化 |
| 偿债/现金 |  | 财务弹性变化 |
| 员工激励/增发 |  | 摊薄及业绩条件 |

判定规则：

- **通过**：资本优先流向高回报再投资；无高回报机会时分红或低价注销式回购；并购克制；每股价值增长；
- **存疑**：再投资回报平庸、回购价格偏高、激励宽松或接班尚未验证；
- **不通过**：反复高价并购、低价增发、高价回购、关联输送或长期囤积低收益资产；
- 回购只有在低于内在价值且注销或真正抵消摊薄时才计入股东回报。

## 七、第二步综合判定

### 维度性质

| 类别 | 维度 |
|---|---|
| 核心门槛 | 2文化治理、3护城河、5竞争、6客户需求、7财务、8资本配置 |
| 条件维度 | 1聚焦、4国际化 |

### 公司分级

| 分类 | 规则 | 后续动作 |
|---|---|---|
| A 核心复利公司 | 无核心“不通过”；核心“存疑”≤1；护城河与财务必须均明确通过；无否决项 | 进入第三步，可作为核心候选 |
| B 优秀但有条件 | 无核心“不通过”；核心“存疑”≤2；护城河与财务不得同时存疑；风险可监控；无否决项 | 进入第三步，明确条件与折扣 |
| C 普通/看不清 | 核心“存疑”≥3，或护城河与财务均存疑 | 不投入新增资金，不进入第四步；估值仅作研究参考 |
| D 否决 | 任一核心维度不通过，或命中结构性否决 | 不投资 |

条件维度不单独导致D类，但若失焦或国际化已经形成持续价值毁灭，应反映到财务和资本配置维度，并可能触发D类。

### 第二步固定结论

必须使用以下句式：

> `[公司]属于[A/B/C/D]类。它是一家[好公司/有条件的好公司/普通公司/不合格公司]。最强证据是___；最大缺陷是___；未来三项验证指标是___。`

## 八、质量对标：只比较公司，不比较价格

贵州茅台作为长期商业质量标尺，同时增加最优秀直接竞争者作为行业现实标尺。这里不使用现有组合来改变公司质量判断。

直接竞争者最多选择两名：

1. 默认选择与目标公司处于同一利润池、可比业务占比足够高且利润池份额最大的竞争者；
2. 若第一名只代表规模、不代表质量，再增加一名五年平均ROIC/ROE或每股价值增长最高的竞争者；
3. 利润池数据不可得时，可退回收入、保费或销量口径并说明局限；
4. 无真正可比公司时写“无直接可比”，不得为了填表强行选择。

| 项目 | 贵州茅台 | 最优秀直接竞争者 | 目标公司 | 判断 |
|---|---|---|---|---|
| 商业模式简单度 |  |  |  | 更强/相当/更弱 |
| 需求持续性 |  |  |  |  |
| 定价权 |  |  |  |  |
| 资本投入强度 |  |  |  |  |
| 自由现金流质量 |  |  |  |  |
| 治理与关键人物风险 |  |  |  |  |
| 十年竞争地位可预测性 |  |  |  |  |
| 独特价值来源 |  |  |  | 增长/分红/国际化/成本/网络效应 |

固定输出：

- 目标公司在哪些方面不如茅台；
- 哪些方面优于或补充茅台；
- 相对最优秀同行，它真正胜出的变量是什么；
- 它是否具备进入第三步估值的独立质量资格。

此处禁止出现当前PE、PR、股价和买入建议。

## 九、第三步：好价格

只有A类和B类公司进入本步骤。

### 1. 建立正常化盈利基准

禁止机械采用“TTM与三年均值孰低”。Agent必须根据主类型重建正常化经营：

#### 稳定消费/平台

```text
收入 = 用户/销量 × 频次 × 价格 × 份额
经营利润 = 收入 × 正常化利润率
所有者收益 = 税后经营利润 + 非现金费用 - 维持性资本开支 - 正常营运资本投入
```

#### 成熟制造

- 使用中周期销量、价格、原材料和产能利用率；
- 区分维持性资本开支与扩张性资本开支；
- 海外工厂单独建模；
- 不能使用景气顶部利润对应的低PE。

#### 周期/资源

- 使用7—10年中周期价格、价差、开工率和利润率；
- 熊市检验资产负债表；
- 峰值利润只用于乐观情景，不进入基准。

#### 银行/券商

- 从期初每股净资产、正常化ROE、分红率和股本变化推演每股净资产；
- 银行纳入信用成本和资本约束；
- 券商使用中周期成交、投行和自营收益。

#### 保险

- 营运利润、内含价值和自由盈余分别建模；
- 压力测试投资收益、利率、信用损失、退保和偿付能力；
- 不直接把账面利润当作可分配现金。

### 2. 三情景统一要求

每家公司建立悲观、基准、乐观三个情景，分别给出5年和10年：

| 参数 | 悲观 | 基准 | 乐观 | 依据 |
|---|---:|---:|---:|---|
| 收入/客户增长 |  |  |  |  |
| 利润率/ROE |  |  |  |  |
| 再投资回报 |  |  |  |  |
| 分红率 |  |  |  |  |
| 净回购/稀释 |  |  |  |  |
| 终值倍数 |  |  |  |  |
| 税费 |  |  |  |  |
| 情景权重 |  |  |  | 证据与主观判断分开 |

情景纪律：

- 悲观情景必须是合理压力，不是世界末日；
- 基准情景不得自动采用管理层或卖方预测；
- 乐观情景仍需符合市场容量、资本需求和竞争约束；
- **市场传导**：逐项使用第一步参数传导表。需求结构下降必须进入销量/客户假设和结构下行情景；利润池恶化必须进入利润率或ROIC；范式风险高且无公司卡位证据时，乐观情景按悲观处理；终值执行第一步“终值纪律”；
- 分红、回购和股本变化不得重复计算；
- 港股红利税、交易渠道税费和汇率影响必须按用户实际渠道核验并给出税前、税后两套结果；
- 所有计算保留完整精度，最终展示时再四舍五入。
- 情景权重不是事实，必须标注为判断并做敏感性分析；目标达成不能只看刚好踩线的基准情景。

#### 概率加权期末财富（辅助指标）

各情景必须采用相同的股息累计或再投资规则：

```text
概率加权期末财富 = Σ（情景权重 × 该情景期末总财富）

概率加权等效CAGR =（概率加权期末财富 ÷ 初始投入）^(1/持有年数) - 1
```

同时输出“悲观情景权重提高10个百分点”的敏感性。不得直接加权各情景IRR。

只有三个主观情景时，不输出伪精确的`P(达成目标)`或`P(永久损失)`；改用“情景加权目标覆盖率”和“永久损失情景权重”，并明确它们不是统计概率。

### 3. 目标收益率倒算公式

以每股口径为主：

```text
P(r,n) = Σ[DPS_t ÷ (1+r)^t] + 终值_n ÷ (1+r)^n

终值_n = 正常化每股指标_n × 终值倍数
```

其中：

- `r`分别为10%、12%、15%、17.46%；
- `n`主要使用10年，同时计算5年；
- 普通公司终值指标可为EPS或FCF；
- 银行使用期末BPS×合理PB或剩余收益终值；
- 保险使用内含价值/营运利润/自由盈余的适用终值；
- 净回购通过未来稀释股数影响每股指标，不得再额外加一次回购收益；
- 如果使用总市值模型，必须最后除以同期预计稀释股数。

当前价格预期IRR通过求解下式获得：

```text
当前价 = Σ[DPS_t ÷ (1+IRR)^t] + 终值_n ÷ (1+IRR)^n
```

必须使用计算器或程序求解，禁止心算。

### 4. 主估值与交叉验证

| 类型 | 主模型 | 交叉验证 |
|---|---|---|
| 稳定消费/医药 | 所有者收益/FCF折现 | 正常PE、股息率、反向DCF |
| 平台成长 | 分阶段FCF/每股收益模型 | 反向DCF、PEG仅作辅助 |
| 成熟制造 | 中周期EPS/FCF + 股息 | 正常PE、EV/EBITDA、资产负债表 |
| 周期资源 | 中周期利润/NAV | EV/EBITDA、PB、周期分位 |
| 银行/券商 | 剩余收益或PB-ROE-Gordon | 股息折现、历史PB |
| 保险 | 内含价值/营运利润/自由盈余 | PB、股息、投资资产压力测试 |
| 资产经营/公用事业 | 分部DCF/NAV | 股息率、资产重置价值 |

PB-ROE交叉验证采用：

```text
合理P/B = (可持续ROE - g) ÷ (股权成本 - g)
```

只有在`g < 股权成本`且ROE、分红率可持续时使用。`g`必须与留存率和再投资回报一致。

禁止事项：

- 禁止用PR直接决定目标PE；
- 禁止把PE、PEG、PR、TRR、历史分位当作五个独立证据重复加权；
- 禁止用周期峰值利润计算“低PE”；
- 禁止只因为低PB就判断银行或保险便宜；
- 禁止选取最乐观模型作为最终价值。

如主模型与交叉验证的合理价值差异超过20%，必须解释；无法解释则降低置信度或停止给出买入价。

### 5. 经济价值、目标回报买价与安全边际

经济价值与目标回报买价是两组不同概念：

- **经济价值区间**：基于保守经营现金流与统一资本成本形成，用于判断价值范围；
- **H10/H12/H15/H17.46**：在统一税费、股息和终值口径下达到对应回报率的最高买价，用于行动；
- H档位不得称为内在价值，H10也不得作为唯一安全边际锚。

统一资本成本规则：

```text
默认基准折现率 = 10%

B类、强周期、高杠杆或高范式风险 = 12%
```

所有公司同时输出基准折现率±1个百分点的敏感性；例外必须基于明确证据并在输入表解释。经济价值取敏感性区间，保守经济价值取区间下沿。

```text
安全边际 = 1 - 当前价格 ÷ 保守经济价值
```

必须同时输出：

- 当前价格相对保守经济价值的折价；
- 当前价格相对H10/H12/H15/H17.46的距离；
- 悲观情景5年、10年IRR；
- 基本面永久损失压力结果；
- 盈利下降与估值倍数压缩同时发生的理论价格压力损失；
- 股息削减后的现金回报。

行动参考：

- 进入第四步的新增资金候选原则上满足“当前价格≤H12”，等价于基准10年IRR≥12%；
- 正常仓位候选优先达到H15；
- H17.46属于目标级机会，但仍必须通过第四步；
- 悲观情景5年总回报为负不自动否决，但必须说明永久损失情景权重/等级和仓位折扣；
- 如果估值结果高度依赖终值倍数扩张，结论不得高于“观察”。

#### 永久损失与价格压力定义

1. **经营性永久损失**：正常化每股所有者收益、自由现金流、每股净资产或其他核心价值基础发生难以恢复的下降；
2. **投资性永久损失**：在合理长期持有期内，以保守正常化经营和保守退出估值计算，累计分配加可实现经济价值仍低于投入成本；
3. **市场价格回撤**：市场报价阶段性下降但经营价值未必受损，不等于永久损失。

不得预测一个精确的“未来最大回撤”。第三步至少测试：盈利不变、倍数压缩30%；盈利下降20%且倍数压缩30%；以及一个公司特定严重情景。历史最大回撤仅作参考事实。

### 7. A股/H股多上市地选择规则

同一家公司同时有A股和H股时，使用完全相同的公司经营、盈利、终值和股本假设，分别计算：

- A股人民币IRR、税前/税后股息率；
- H股港币IRR、人民币IRR、税前/税后股息率；
- 红利税、交易费用、汇率、流动性、最小交易单位和持有渠道差异。

按实际换股比例或每股经济权利校准后：

```text
H股人民币等值价格 = H股港币价格 × 人民币/港币汇率 × 每股权利调整系数

A/H折价率 = 1 - H股人民币等值价格 ÷ A股价格
```

默认规则：

1. **H股至少较A股折价25%，才获得相对价格资格；**
2. **H股绝对价格同时必须≤其自身H12/H15/H17.46档位，才获得相应行动资格；**
3. 折价率只是第二道参考，买入决策永远锚定H股绝对价格和税后人民币回报；
4. 若折价扩大仅因A股上涨、H股价格不变，H股IRR没有提高，不构成新的买入触发；
5. A股也必须单独达到自身H档位；若A、H均不达标，则两地都不买；
6. 若A、H均达标，优先选择税费、汇率和流动性调整后人民币IRR更高者。

25%是用户设定的默认A/H相对价格门槛，不代表所有公司的理论公平折价。公司报告仍须解释红利税、派息率、流动性等因素所支持的个别合理折价。

- 哪个增长假设最脆弱；
- 如果股价5年不涨，最可能是什么原因；
- 本分析最可能错在哪里；
- 哪三个指标能最早证明分析错误。

## 十一、第四步：组合适配与成果测算

第四步是有条件触发的组合研究，不属于前三步个股质量与估值判断。只有A/B类观察池公司在拟纳入、加仓、减仓或替换时执行。

### 1. 第四步输入

必须锁定：

- 当前组合快照日期、持仓、市值、成本、现金和币种；
- 当前人民币总资产、10年目标日期和剩余年数；
- 候选公司的拟成交价格、目标仓位和交易税费；
- 资金来源：新增资金、现金、股息再投资或卖出某项持仓；
- 5年与10年期限；
- 分红是否再投资；
- 税前100万元年股息目标；
- 私募或非上市资产的估值频率、锁定期和现金分配规则。

输入不完整时可以输出方向性分析，但不得给出可下单仓位。

### 2. 机会成本基准与空集顺位

第四步同时比较：

1. **商业质量基准**：贵州茅台；
2. **组合机会成本基准**：当前组合中质量合格、价格达到新增门槛、未触及仓位上限且风险调整后预期回报最高的持仓；
3. **观察池可执行候选**：已经完成前三步和第四步、可立即执行的其他候选；
4. **低风险基准**：与投资币种、期限匹配的现金或低风险资产收益。

若第2、3项为空，机会成本直接降为低风险资产。茅台只有在自身达到新增门槛且未触及上限时才是实际替代方案；否则只作质量和公开回报参考。不得忽略继续持有现金的选择权。

### 3. 纳入前后成果测算

使用与第三步完全一致且已冻结的个股情景输入，分别计算组合纳入前和纳入后的悲观、基准、乐观结果：

| 指标 | 纳入前 | 纳入后 | 边际变化 | 目标要求 |
|---|---:|---:|---:|---:|
| 第5年期末资产 |  |  |  | ≥2000万元 |
| 第10年期末资产 |  |  |  | ≥5000万元 |
| 组合XIRR |  |  |  | 记录 |
| 概率加权期末财富/等效CAGR |  |  |  | 辅助指标 |
| 第5年税前股息 |  |  |  | 路径值 |
| 第10年税前股息 |  |  |  | ≥100万元 |
| 现金拖累 |  |  |  | 解释 |
| 基本面永久损失压力 |  |  |  | 可承受 |
| 估值压缩理论价格损失 |  |  |  | 不导致被迫卖出 |
| 永久损失情景权重/等级 |  |  |  | 披露 |

不得用个股IRR的简单仓位加权代替组合现金流、XIRR和期末财富计算。必须说明候选个股使目标缺口缩小还是扩大。

#### 动态目标进度仪表盘

```text
剩余所需CAGR =（5000万元 ÷ 当前人民币总资产）^(1 ÷ 剩余年数) - 1
```

每季度输出当前资产、绝对缺口、剩余年数、剩余所需CAGR、现有组合基准情景第10年资产及领先/落后金额。

目标落后不得成为降低A/B质量标准、安全边际、提高单股上限或引入杠杆的理由。若所需CAGR已明显超出合格机会集合能够提供的范围，只能增加本金、延长期限或调整目标。

### 4. 组合角色与资金来源

每家公司只能选择一个主角色：

- 核心复利；
- 高增长；
- 稳定股息；
- 周期反转；
- 风险分散。

必须说明：它替代谁，或为什么是新增独立角色；若卖出原持仓融资，列出税费、损失的股息、放弃的上行和新标的的增量回报。

### 5. 税前100万元股息路径

第四步必须输出：

| 指标 | 当前 | 纳入后第5年 | 纳入后第10年 |
|---|---:|---:|---:|
| 税前年股息 |  |  |  |
| 适用税率与持有渠道 |  |  |  |
| 税后实际到手股息 |  |  |  |
| 对100万元目标覆盖率 |  |  |  |
| 前五大股息来源占比 |  |  |  |
| 股息覆盖率/派息率 |  |  |  |
| 压力情景削减后股息 |  |  |  |

100万元按税前、名义固定金额管理，不另设统一80万元税后目标。税后实际到手股息按各持仓注册地、分红性质和用户实际持有渠道逐项计算。高股息率不自动加分；必须同时验证自由现金流、派息覆盖、资产负债表和股息增长能力。

### 6. 相关性、集中度与压力测试

至少检查：

- 单股、前三大持仓、行业、商业模式、监管、币种和地区集中度；
- 名义分散但受同一中国消费、地产信用、出口、利率或科技资本开支因子驱动的风险；
- 全球衰退、中国需求走弱、政策变化、人民币/港币波动、利率上升及核心持仓同时估值压缩；
- 私募的净值平滑、赎回限制和底层持仓穿透风险。

输出前三大风险因子的损失贡献，而不只列持仓数量。

非人民币资产必须同时输出本币IRR和人民币IRR，并对期末汇率设置人民币升值、稳定、贬值三种压力；不要求预测十年逐年汇率路径。

### 7. 仓位规则与风险去重

默认上限仅作为起点，最终仓位由第四步决定：

| 公司分类与回报 | 首次仓位 | 正常上限 | 硬上限 |
|---|---:|---:|---:|
| A类 + 目标达成型 | 3%—5% | 10%—15% | 20% |
| A类 + 接近目标型 | 2%—4% | 8%—12% | 15% |
| A类 + 组合辅助型 | 2%—3% | 5%—8% | 10% |
| B类 | 1%—2% | 3%—5% | 8% |
| C/D类 | 0% | 0% | 0% |

任何单股超过20%必须单独完成集中度压力测试；25%为默认绝对硬约束，除非用户明确修改投资政策。

第一步风险若已经进入收入、利润率、再投资、终值或情景权重，不再自动按“降一档”重复惩罚。仓位额外折扣只处理模型无法吸收的尾部风险、流动性、治理不确定性和组合相关性，并完成风险去重表。

最低硬规则：

- 范式风险高且下一代卡位尚未验证：公司最高只能列B类，硬上限4%；若核心盈利模式可能被替代，降为C类，仓位为零；
- 需求结构下降且公司份额连续两个报告期下降：触发研究暂停或C类复核，不以简单减半仓位代替基本面判断。

风险去重表示例：

| 风险 | 收入/利润率 | 终值 | 情景权重 | 仓位 | 去重结论 |
|---|---|---|---|---|---|
| 长期利差收窄 | 已下调正常化利润率 | 已使用较低终值倍数 | 不再重复降权 | 仅处理金融暴露相关性 | 无重复 |

### 8. 分档建仓

默认按照第四步确定的最终目标仓位累计执行：

| 价格 | 累计达到目标仓位的比例 |
|---|---:|
| ≤H12 | 25% |
| ≤H15 | 60% |
| ≤H17.46 | 100% |

“累计仓位”包含已有持仓，不能把每档金额重复相加。实际下单数量按交易单位向下取整，港币股票须注明汇率和交易费用。

### 9. 暂停加仓条件

每家公司至少设置3个公司特定指标，并包括：

- 最新财报使基准正常化利润下调超过10%；
- 核心护城河指标连续两个报告期恶化；
- 资产负债表、审计、监管或管理层发生重大变化；
- 价格下降但经济价值下降幅度更大；
- 组合相关风险已经超过上限。

价格下跌本身不是加仓理由。

### 10. 卖出与减仓规则

买入时写死条件，不写死永久绝对价格。

**论文退出审查：**

- 命中一票否决；
- 核心投资论文被事实破坏；
- 护城河不可逆恶化；
- 管理层诚信或重大治理问题；
- 财务风险可能造成永久损失。

**目标降级审查：**

- 更新后预期回报显著低于组合目标，成为目标拖累；
- 原组合角色不再成立；
- 税前股息的可持续性或增长能力明显下降；
- 单股或相关风险超过组合硬上限。

**机会切换审查：**

- 原持仓论文未破坏且未触发风险上限时，新标的质量不得低于原持仓，悲观情景不得更差；
- 扣除交易税费、损失的股息、汇率和换仓摩擦后，新标的概率加权等效10年CAGR至少高3个百分点，才进入主动换仓审查；
- 两边估值置信度低时，门槛提高至5个百分点或不换；
- 原论文破坏、诚信问题或风险超限时，不适用3个百分点门槛，直接按风险退出规则处理。

不再使用固定“低于6%才审查”的统一阈值。估值高不自动清仓，目标拖累也不等于立即卖出；必须通过第四步比较继续持有、换仓和现金三种方案。

### 11. 第四步固定结论

四选一：

1. **纳入组合**：说明价格、仓位、资金来源和预期成果；
2. **等待价格**：保留观察池身份和触发价；
3. **保留观察但不纳入**：个股合格，组合适配不合格；
4. **移出观察池**：前三步结论已降为C/D或命中否决项。

## 十二、复盘与更新频率

| 触发 | 动作 |
|---|---|
| 年报 | 完整重跑前三步；持仓或拟纳入组合的观察池公司同时重跑第四步 |

## 十三、标准报告模板

任何Agent必须按以下顺序输出。

### 标题与元数据

- 公司、代码、交易所；
- 研究日期和数据截止日；
- 当前价格、币种、市值、除权口径；
- 信息丰富度、当前持仓；
- 一句话生意本质。

### 第零步：研究资格

- 能力圈200字测试；
- 主类型与风险标签；
- 数据完整度；
- 一票否决/暂停检查；
- 结论：继续或停止。

### 第一步：看清细分市场

| 模块 | 必答内容 | 结论 |
|---|---|---|
| 定义与边界 | 细分市场、替代品、价值链、利润池 | — |
| 需求轴 | 5—10年量价、驱动变量、结构性/周期性裁决 | 结构增长/稳定/结构下降 |
| 利润池轴 | 集中度、供需、竞争、上下游议价、利润迁移 | 改善/稳定/恶化 |
| 范式风险 | 技术、监管、替代品、十年存续 | 低/中/高 |
| 结构性机会 | 新场景、新客户、新技术、谁能获得利润 | 增量来源 |

必须附参数传导记录和风险去重表。

固定句式：

> 该细分市场的需求轴为___，利润池轴为___，范式风险为___。最强竞争要素是___，最大结构性挑战是___。这些结论分别传导至___。

### 第二步：好公司

| 维度 | 结论 | 最强证据 | 最大反证 | 监控指标 |
|---|---|---|---|---|
| 聚焦 |  |  |  |  |
| 文化治理 |  |  |  |  |
| 护城河 |  |  |  |  |
| 国际化 |  |  |  |  |
| 竞争格局 |  |  |  |  |
| 客户趋势 |  |  |  |  |
| 财务质量 |  |  |  |  |
| 资本配置 |  |  |  |  |

- A/B/C/D分类；
- 三个最强事实、三个最大风险；
- 茅台与最优秀直接竞争者质量对标；
- 第二步固定结论。

### 第三步：好价格

- 正常化盈利与估值对象；
- 悲观/基准/乐观假设、权重和依据；
- 5年/10年现金流、税前/税后股息和终值；
- 当前价IRR；
- 概率加权期末财富、等效CAGR和权重敏感性；
- 经济价值区间与H10/H12/H15/H17.46；
- 10%/12%资本成本规则及±1个百分点敏感性；
- 安全边际与压力测试；
- 如有A/H两地上市，输出25%相对门槛与各自绝对H档位；
- 主模型和独立交叉验证差异；
- 茅台回报参考；
- 最强反方与最可能错误。

### 第三步结论

- A/B/C/D分类保持不变；
- 观察池—可进入第四步 / 观察池—等待价格 / 观察池—待补数据 / 不进入观察池；
- 镜子测试；
- 数据、生意、估值三类置信度。

### 第四步：组合适配与成果测算

仅在A/B类观察池公司拟交易时输出：

| 对象 | 固定输出 |
|---|---|
| 组合基线 | 快照日期、持仓、现金、币种、税费、资金来源 |
| 机会成本 | 茅台参考、合格可加仓持仓、可执行观察池候选、低风险资产 |
| 成果 | 纳入前后5年/10年资产、XIRR、概率加权财富、税前/税后股息和动态目标缺口 |
| 风险 | 集中度、相关性、基本面永久损失、估值压缩压力和汇率压力 |
| 组合角色 | 核心复利/增长/股息/周期/分散 |
| 仓位 | 首次、正常上限、硬上限 |
| 建仓表 | H档价格、累计金额、累计仓位 |
| 暂停条件 | 至少3项 |
| 退出条件 | 论文退出、目标降级、机会切换 |
| 结论 | 纳入/等待价格/观察但不纳入/移出观察池 |

### 镜子测试

> 我愿意在___元关注/买入___，因为它向___客户提供___，客户持续付费的原因是___。它最可靠的护城河是___，目前正在___。管理层在资本配置上的记录是___。基准情景10年IRR为___，悲观情景为___。我最可能错在___；如果___发生，我将停止加仓或退出。

无法在200字内写清楚，不买。

### 置信度与审计

- 数据、生意质量、估值确定性：高/中/低；
- 关键缺失数据；
- 关键来源、双来源差异、计算工具和日期；
- 未解决的数据差异；
- 第四步另列组合输入置信度。

## 十四、Agent执行硬规则

### 必须做到

1. 确认当前日期并刷新最新股价和财报；
2. 估值前锁定估值对象；
3. 关键数据先对齐定义再双来源核验；
4. 建立四座勾稽桥；
5. 分栏披露年报、TTM、正常化和预测EPS；
6. 区分事实、计算、假设、判断、缺失与争议；
7. 所有估值使用程序并保留输入表；
8. 验证三项恒等式；
9. 输出5年和10年、三情景及权重敏感性；
10. 个股股息给出税前、税后口径；第四步以税前100万元为目标；
11. 使用每股数据并纳入回购和稀释；
12. 将市场、公司、价格和组合分别下结论；
13. 独立交叉估值差异超过20%必须解释；
14. 新旧价值或买价变化超过10%必须归因并冻结旧价格线；
15. 审计门通过后才可输出经济价值与H档位；第四步通过后才可输出仓位；
16. 写出最强反方和最可能错误；
17. 第一步输出需求轴、利润池轴、范式风险并逐参数传导；
18. 行业数据禁止只引用券商TAM；
19. 前三步结论先行并冻结，第四步不得倒推修改；
20. 只有A/B类进入观察池和第四步，C/D类仓位为零；
21. 第四步比较纳入前后期末财富、税前股息、风险、资金来源与机会成本；
22. 同一风险必须完成去重检查；
23. 经济价值默认使用10%或12%折现率，并输出±1个百分点敏感性；
24. A/H两地上市时，H股默认同时满足折价≥25%和绝对价格≤相应H档位；
25. 第四步披露税后实际到手股息，但税前100万元仍是唯一股息目标；
26. 非人民币资产同时输出本币IRR和人民币IRR；
27. 每季度更新剩余所需CAGR，但不得用目标落后提高风险预算；
28. 主动换仓执行3个百分点默认摩擦门槛。

### 禁止事项

1. 禁止使用过期价格直接下单；
2. 禁止只引用卖方一致预期；
3. 禁止把TTM峰值利润当正常利润；
4. 禁止跨行业机械套用统一指标；
5. 禁止把多个高度相关估值指标重复加权；
6. 禁止因低PE、低PB或高股息单独认定便宜；
7. 禁止把市占率或知名度直接等同护城河；
8. 禁止忽略海外利润、ROIC和政治风险；
9. 禁止给没有数据支持的精确预测；
10. 禁止以“长期看好”代替价格和触发条件；
11. 禁止写死永久卖出价格；
12. 禁止为了得出“可以买”而调整增长和终值；
13. 禁止静默切换估值对象；
14. 禁止混用四种EPS；
15. 禁止在审计失败时输出正式定价；
16. 禁止用大行业冒充细分市场；
17. 禁止为了支持买入而改变市场三轴判断；
18. 禁止把H档位称为内在价值，或只用H10计算安全边际；
19. 禁止用个股IRR简单加权代替组合XIRR和期末财富；
20. 禁止在第四步为了组合达标而修改前三步参数；
21. 禁止A/B以外公司建立正式仓位；
22. 禁止预测精确的未来最大回撤；
23. 禁止把A/H折价扩大本身当作买入信号；
24. 禁止将港股统一按20%税率或税后80万元处理；
25. 禁止直接加权各情景IRR或把三情景权重冒充统计概率。

## 十六、框架自身的复盘规则

本框架不是永久不变。出现以下情况应修订版本：

- 连续三家公司在同一维度出现无法执行或明显误判；
- 实际投资结果与基准情景长期偏差，且来自同一个模型假设；
- 会计准则、税收、交易制度或监管环境重大变化；
- 组合目标或风险承受能力改变；
- 新证据表明某一硬门槛过严或过松。

每次修订必须说明：修改内容、修改原因、影响哪些历史结论。禁止为了证明过去买入正确而修改标准。

v3.4发布后暂停增加新维度，优先连续运行10—20家公司。连续三家公司在同一规则出现无法执行或明显误判，只触发复核，不自动修改；须确认问题来自框架而非数据、执行或公司特例。

### v3.1 修订记录（2026-09-24）

- 修改内容：新增估值对象锁定、四座利润/现金流勾稽桥、EPS口径分栏、三项恒等式、独立交叉估值、版本漂移归因和旧价格线冻结规则。
- 修改原因：小商品城分析中曾把“核心业务”“核心生态”和“全公司”口径混用，并以不同EPS与终值假设输出不可直接比较的价格，导致结论大幅漂移。
- 影响范围：所有历史报告中的买价仅代表报告当时版本；再次执行前必须用v3.1重跑。小商品城2026-08-26及2026-08-28报告的旧买价已停止作为下单依据。

### v3.2 修订记录（2026-10-02）

- 修改内容：新增"第一步：细分市场分析"（定义与边界、趋势、竞争、机会、挑战、赛道判定四选一与传导规则），两步法升级为三步法；原"好公司八维"顺延为第二步、"好价格"顺延为第三步；组合执行门新增赛道逆风/动荡降档规则；复盘频率中中报增加赛道漂移复核。
- 修改原因：郎刚 2026-10-02 决定。此前领展（NAV 折价修复博弈）、分众（结构性 vs 周期性之争）、绿城管理（代建新拓塌方）等案例显示：不先裁决细分市场趋势与格局，公司八维容易在错误前提下展开，估值参数缺少赛道层面的锚，"结构性下行管道"会被当成"周期波动"给出过高价格线。
- 影响范围：所有基于两步法的历史报告再次执行前，须按 v3.2 补做细分市场分析并执行传导规则；历史买价继续按版本冻结规则处理。框架名称由《两步投资分析法：好公司 + 好价格》变更为《三步投资分析法：好赛道 + 好公司 + 好价格》。

### v3.3 修订记录（2026-10-06）

- 修改内容：明确前三步为独立个股研究；将现有组合执行门扩展为有条件触发的第四步；A/B类进入观察池，C/D类停止；税前年股息目标固定为名义100万元；细分市场由单一四分类改为需求轴、利润池轴和范式风险；增加风险去重；区分经济价值与H档目标回报买价；增加茅台、最佳可加仓持仓和低风险资产三重机会成本基准；取消统一“10年IRR低于6%”减仓阈值。
- 修改原因：避免组合目标反向污染个股研究，同时确保合格个股在执行前接受期末财富、税前股息、相关风险、资金来源和机会成本审查；修复单一赛道标签、P10安全边际和重复风险折扣的概念问题。

### v3.4 修订记录（2026-10-06）

- 修改内容：增加组合目标优先级、快筛/完整研究双模式、概率加权期末财富、10%/12%资本成本规则、永久损失定义、估值压缩压力、A/H多上市地双重门槛、动态目标缺口、税后实际到手股息、本币/人民币IRR、接近目标型仓位、范式风险最低硬规则、风险去重示例和主动换仓摩擦门槛。
