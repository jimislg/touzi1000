# 股票分析两个技能（A 股 / 港股）

本仓库分支收录一套自用的股票研究方法论，共两个技能包：

| 技能 | 版本 | 定位 | 体量 |
|---|---|---|---|
| `investment-advisor` | **v3.4.16** | 主框架：三步个股分析 + 第四步组合决策 | SKILL.md 5.8 万字 · 41 条禁止事项 |
| `tangchao-valuation` | **v3.10.12** | 第二把尺子：唐朝估值法（三锚定 + 价格区间） | SKILL.md 12.3 万字 · 69 条硬规则 |

两者不是「二选一」，是**必须配对使用**的。下文第 1 节解释为什么。

> 这不是通用金融教材。它是把唐朝《价值投资实战手册》第一辑 + 第二辑（约 37.6 万字）和一套自建的三步框架，在 18 个真实标的、上百次算错之后，压缩成可执行规则的结果。**规则之所以啰嗦，是因为每一条都对应一次真实的误判。**

## 1. 两个技能的关系：强制双向配对

**核心纪律（2026-10-25 定，全类型无条件）**：任何一个标的都必须同时出两份报告——唐朝法一份、四步法一份。

- 已有四步法 → 补唐朝法；已有唐朝法 → 补四步法。
- **不按 A/B/C/D 分级豁免**。C/D 类也要两份，因为两法同时否决才是硬否决。
- 只出一份时，结论必须标注「单尺子结论，不构成仓位建议」。

两份报告到齐后，按 `tangchao-valuation/SKILL.md` §5.1 的三条判据做验证：

| 判据 | 要求 |
|---|---|
| 判据零 | 收敛倾向：当前 PE ÷ 加权退出 PE 落在 0.8–1.25 之外时，年限本身会制造分歧，收敛非必然 |
| 判据一 | **同口径六开关对齐**：起点利润 / 年限 / 退出方式 / 税率 / 聚合方式 / 非经营性资产口径 |
| 判据一·补 | **公式同构检测**：两法在测量点相等不算验证，必须把折现率挪到现价隐含 r 重算（见 §4 第 3 条） |
| 判据二 | 差额拆到开关级，残值 < 0.5pct；拆不干净就是口径没对齐 |
| 判据三 | 分歧幅度对应动作：< 10% 收敛 / 10–30% 取较低价 / > 30% 或拆不干净 → 仓位五折 / **方向相反 → 不买** |

**「两个数字接近」不构成验证。** 这条被违反过四次（1.4pct、0.2%、3.07pct、0.0000），最后一次连残值都是 0 却仍然不是验证——见 §4。

## 4. 十二条最硬的规则（从 110 条规则里挑出来的）

**1. 分类必须数出来，不能判出来。**
A 类 = 无核心「不通过」+ 核心「存疑」≤ 1 + 护城河与财务明确通过 + 无否决项（核心门槛 = 第 2/3/5/6/7/8 维）。存疑 1 个时 A/B 条件同时成立，B 只是 A 的超集。**选 B 不是保守**——上限从 20% 砍到 8%，会把 12.8% 的持仓判成「超配 60%、该卖 48 万」。方向上的谨慎，后果上的激进。

**2. 三道前置闸必须在开写报告之前跑，不是交付前。**
实测八处错误全部发生在结论形成那一刻；到交付前，分类、仓位、币种已是既成事实，改一项等于重写全文。

**3. 两法在测量点相等，不等于验证。**
腾讯实测：12% 线给出 323.2058 与 323.2058，差 0.0000，标准收敛档。把 r 挪到现价隐含的 10.2384% 再算 → 377.62 vs 383.60（差 5.98 元）；现价 IRR 10.09% vs 10.24%（差 0.15pct）。
根因：两段式的进攻项含 `(ρ/r − 1)` 因子而 ρ 恒取 12%，测量点又是 r=12% → 因子恒为 0。**capex/净利 > 70% 的标的，两法必然退化为同一模型。此时「收敛」是同一把尺子量两次。**
→ 只准说「确认了算术」，不准说「确认了假设」。必须另找一把真独立的尺子。

**4. 主句只能是现价 IRR，不能是「现价低于 N 条线」。**
「低于四档」是事实，但四档回答的不是「值多少」，是「若第 N 年按 X 倍接盘、且 capex 归零，今天该付多少」——上界。给主句「加一条读法警告」等于承认主句写错；**主句错了就改主句**。

**5. H 档是曲线不是点。**
H12→H15 差 18.6%，全部来自 `(1.12/1.15)^10 = 0.7677`。终值占价格 93%、加权久期 9.7 年 → 每 1pct hurdle ≈ 7.5% 价格。**禁止用「现价刚好等于 H15」这类贴线做买卖判断，判贵贱只能用现价 IRR。**

**6. 退出倍数必须当自变量报。**
同一个 12% 要求，8.0× 只要 367.87、15× 要 572.05。不报倍数的 H 档价格无法检验。

**7. 非经营性资产按「今天价值直加」。**
禁止只折现不给 `g_inv`——那等价于假设这块资产十年零回报（85 折 + 零增长 + 折现，三重惩罚），NPV 并不为 0。唐朝法 SOTP 本来就这么算，两法必须同口径。
> 这条规则自己错过一次：我以「更严谨」为名把它改成折现，方向更保守但结论是错的，还把它固化成规则写进技能，活了一天。**更保守 ≠ 更正确。**

**8. 银行股拨贷比检验必须双轨。**
单年轨抓「刚反转」，累计轨抓「匀速舀」，任一 > 2 倍即判报表 ROE 不可采信。只跑单年轨会把累计释放 485 亿的招行判得比成都银行更轻。

**9. 保险股必须拆 EV，且报「PEV 历史低位」前先折算。**
`EV = 调整后净资产 + 有效业务价值(VIF)`。平安每股 EV 86.58 = 57.67 + 28.91，现价 52.80 低于净资产。
EV 按 4.0% 投资收益率计量，实际净投资收益率年化只有 3.3%；公司披露每 −50bp → 集团 EV −9.6%、寿险 EV −15.5%、NBV −16.8%。**按 −70bp 折算，PEV 不是 0.610，是 0.705**，历史区间 0.45–0.95，中位——离「历史低位」远了一截。
保险不能用 FCF 永续：保费流入是负债，且 7,251 亿 CSM 是已签合同的时间表，永续折现会把真实的护城河抹平。

**10. 增长穿零时，经验线必然给出虚假的「便宜」。**
高预收行业的收现比会与合同负债互相抵消，必须并列报三项。

**11. 仓位要给绝对金额，且每次独立分析。**
1,000 万基数下写「目标 10%–15% = 100–150 万 + 硬上限」。只给百分比不合格。不做组合加总约束——总和超 1,000 万是正常的（那是理想权重）。

**12. 报告骨架固定，不许自创编号。**
固定 §1–§12；四档只准 H10/H12/H15/H17.46；自创档必须标「非 H 档」+ 写出与最近 H 档的差 + 只能进表 B；交付前跑 `report_lint.py`。
> 起因：14 份存量报告结构各异，**PASS 0**。规则一直都有，只是从来没有执行过——**有规则但没有执行载体，等于没有规则**。

## 5. 这套方法自己承认的局限

1. **它是事后长出来的，不是先验设计的。** 110 条规则里几乎每条都对应一次真实算错，因此它擅长防已知错误，不擅长发现未知错误。
2. **两法经常共用框架**，尤其保险（EV-PEV）、银行（PB-ROE）、重资产（永续 FCF）。18 个标的里已查明 5 家「收敛」不是独立验证：宋城=同义反复、恒隆=结构决定、成都=共用假设、汾酒=共用情景、腾讯=公式退化。
3. **对「capex 算不算成本」高度敏感。** 腾讯同一个现价，capex 全部算成本时 IRR 6.84%，一分不算时 13.14%，首尾差 6.3pct，全部来自这一个假设。
4. **不解决「长期利率往哪走」。** 保险、银行、收租物业的估值一半不由自己决定，这类标的最高只能给 B 类。
5. **规则数量已接近维护上限。** 两个 SKILL.md 合计 18 万字，人读不完，只能靠脚本闸门兜底。这套东西真正可迁移的部分是 §4 那十二条，不是全文。
