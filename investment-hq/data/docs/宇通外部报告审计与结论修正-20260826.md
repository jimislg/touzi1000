# 宇通外部报告审计与结论修正

> 数据截止：2026-08-26。审计结论：报告需要针对性修正，不能直接作为加减仓依据。

## 一、总评

报告的五年财务数据大体正确，“利润增长不可线性外推、海外业务和高派息需要正常化”也是有价值的提醒。但报告把两个并不成立的指标解释为周期顶部证据，并混淆基金持仓、卖方目标价和市场预期。因此，“当前位置不宜重仓追买”可以保留，“现金流已经预示周期顶部”不能保留。

## 二、关键问题

| 严重度 | 原报告判断 | 审计结果 | 正确解释 |
|---|---|---|---|
| 严重 | 经营现金流下降是应收账款和存货累积，属于周期顶部前兆 | 外部核验错误 | 2025年应收账款增加约11.43亿元，但存货仅增加约0.29亿元；应付账款减少约20.43亿元、应付票据减少约14.73亿元，供应商付款增加是现金流下降的主要原因 |
| 严重 | 动态PE 17.78倍说明市场在定价下一期利润下降 | 方法错误 | 约17.8倍来自市值除以2026年上半年利润乘二，是行情软件的简单年化，不是市场给出的预测PE；宇通下半年通常更强 |
| 高 | 公司已经处在周期顶部 | 证据不足 | 2026年上半年销量下降，但收入增长3.65%、扣非利润增长15.83%、经营现金流59.49亿元；只能说明增速放缓风险上升，不能确认顶部 |
| 高 | 机构从115家降到49家，证明机构撤退 | 需要复核 | 必须标明机构类别、披露完整度、截止日和持股数量；公募基金家数不等于全部机构，前十大机构持股仍达64.37% |
| 高 | 机构目标价42.21元但同时减仓，嘴上看多脚在跑 | 逻辑混淆 | 卖方分析师目标价与买方基金持仓不是同一主体，不能直接并列推断 |
| 中 | 8.4%股息率证明好日子将结束 | 推论过度 | 8.4%是2.5元特殊高派息对应的追踪股息率；99.65%派息率不可外推，但高股息本身不能证明周期顶部 |
| 中 | 用五年平均ROE估值即可得到正常价值 | 方法不稳健 | 高分红会压低净资产、机械抬高ROE；宇通更适合使用正常化EPS、自由现金流和分红覆盖进行三情景估值 |

## 三、现金流重新核对

2025年经营现金流31.97亿元确实比2024年的72.11亿元下降55.67%，但资产负债表显示：

- 应收账款：42.37亿元升至53.80亿元，增加11.43亿元；
- 存货：35.13亿元升至35.42亿元，仅增加0.29亿元；
- 应付账款：54.81亿元降至34.38亿元，减少20.43亿元；
- 应付票据：15.11亿元降至0.39亿元，减少14.73亿元。

因此，现金流下降主要来自主动或阶段性支付供应商款项，而不是库存失控。2021—2025年累计经营现金流约190.93亿元，累计归母利润约128.60亿元，累计现金含量约148%。按2026年上半年滚动计算，TTM经营现金流约74.31亿元、TTM归母利润约54.86亿元，现金含量约135%。现金流需要继续观察，但目前不构成顶部确认。

## 四、估值口径修正

按29.90元和22.139亿股计算，市值约661.97亿元；TTM归母利润约54.86亿元，对应PE约12.1倍。

行情软件的动态PE约17.7倍，基本等于661.97亿元除以2026年上半年归母利润18.67亿元的两倍。它假设上下半年利润相同，忽略宇通历史上的下半年旺季，因此不能解释为“市场预测2026年利润下滑”。

2.5元最新年度分红对应追踪股息率约8.36%，但派息率接近100%。正常化分红可暂按每股1.8—2.1元，对应约6.0%—7.0%股息率；最终仍需根据2026年全年利润、海外投入和产品质量保证支出更新。

## 五、修正后的投资结论

1. 宇通利润增速很可能从过去三年的高增长回落，海外高毛利、国内需求下降和国际采购限制是真风险。
2. 目前不能用现金流和动态PE证明公司已经进入周期顶部。
3. 29.90元不是显著低估，也不是必须回避的高估：空仓者可建立1%—2%观察仓；已有5%仓位者不追买。
4. 27—28元且出口份额、扣非利润未恶化时，可提高至累计5%；24—26元且全年基本面通过，可提高至8%。
5. 真正的减仓信号是海外收入和份额连续恶化、海外毛利率明显下行、预计负债与售后现金支出失控，而不是单季基金家数或软件动态PE。
