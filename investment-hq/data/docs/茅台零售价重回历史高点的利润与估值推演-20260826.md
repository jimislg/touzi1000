# 茅台零售价重回历史高点的利润与估值推演

数据截止：2026-08-26。信息丰富度：A。AI研究局限：公司没有披露标准飞天茅台的独立销量、渠道加权成交价和各渠道净利润，因此“价格上涨能够转化为多少上市公司利润”只能做透明假设下的情景推演，不能作为确定预测。

## 一、直接结论

采用散瓶飞天茅台2021年约3170元的历史最高批价，将3200元作为可比历史高点：

- 如果只是社会市场价回到3200元，公司没有提高实际销售价格，茅台归母净利润仍大致只有830—900亿元；
- 如果公司通过直营、i茅台和合同价调整，捕获新增渠道价差的约50%，归母净利润约1050—1100亿元；
- 如果捕获75%，归母净利润约1180—1200亿元；
- 如果接近全额捕获，归母净利润理论上可达到约1300亿元，但这意味着渠道利润被大幅压缩，销量、政策和消费者接受度风险都会明显上升，不应作为基准情景。

最可采用的中性结论是：市场价稳定回到3200元后，茅台中期归母净利润约1050—1150亿元，合理价值约1550—1800元，具有25%—30%安全边际的买入价约1150—1300元。

## 二、为什么零售价不能直接换算成利润

茅台存在三种完全不同的价格：

1. 公司向经销体系销售的合同价；
2. 公司自营和i茅台面向消费者的零售价；
3. 经销商、烟酒店和二级市场形成的批发及终端成交价。

2021年散瓶批价最高约3170元、原箱最高约3880元，但当时公司并没有把全部渠道溢价收入囊中。社会价格越高，只能证明品牌稀缺性和渠道提价空间；只有公司提高合同价、增加直营占比或提高自营价格，差价才会进入上市公司报表。

2026年上半年直销收入519.62亿元、批发代理收入386.97亿元，直销占主营酒类收入约57%。直营能力增强，意味着这一次如果终端价上涨，上市公司捕获价差的能力会高于2021年，但仍不可能无成本地拿走全部渠道利润。

## 三、模型假设

- 历史高点：3200元/瓶；当前市场及自营价格参考约1700—1753元，取新增价差1500元；
- 归母净利润基数：830亿元，接近2025年及2026年TTM正常化利润；
- 2025年茅台酒销量4.675万吨，相当于约1亿瓶500ml产品；由于公司未披露标准飞天占比，假设其中约6500万瓶为能直接受益于飞天价格体系的标准化产品；
- 新增售价先扣除13%增值税；
- 新增不含税收入转化为归母净利润的边际比例取55%，包含消费税、附加税、所得税、渠道和运营成本；
- 总股本约12.5227亿股。

标准飞天瓶数和边际净利率均为估算，是模型最敏感的两项参数。

## 五、合理估值为什么只给18—20倍

历史高价恢复如果来自供需周期和财富效应，可能在高点后回落，不应按30—40倍成长股估值。2025年归母净利润下降4.53%，2026年上半年下降1.95%，第二季度下降6.9%，说明茅台目前是高质量低速现金牛，而非已被验证的高速成长股。

- 利润低于950亿元、增长约0%—3%：合理PE 16—18倍；
- 利润1050—1150亿元、可持续增长约5%—8%：合理PE 18—20倍；
- 只有利润持续增长8%以上、渠道库存健康、批价稳定，才可讨论20—22倍；
- 不能因为终端价短暂冲到3200元就提高到25倍以上。

因此中性合理价值取1550—1800元，而不是简单用历史最高股价或历史最高PE锚定。

## 六、买入价格结论

需要把安全边际分为两种：

### 1. 不依赖零售价回到3200元的安全价

按830—900亿元利润、17—18倍估值，合理价值约1125—1295元；再留出约25%的严格安全边际，对应约850—970元，取整为900—1000元。1000—1100元仍有吸引力，但已经不是完全不依赖提价的25%安全边际价格。

### 2. 假设零售价稳定回到3200元且公司捕获约50%价差

中性合理价值约1700元，留出25%—30%安全边际后约1190—1280元。1150—1200元处在这个区间的偏下方，属于有吸引力的重仓价格。

### 3. 价格高于1400元

需要提前支付较高比例的涨价兑现，只有在公司实际合同价、自营价和利润已经同步上升后才合理，不再属于明显安全边际区。

## 七、对1000万元组合的含义

中性情景下EPS约85—90元，如果维持80%分红率，每股股息约68—72元：

- 1150元买入8600股，年税前股息约58—62万元；
- 1200元买入8300股，年税前股息约56—60万元。

即使零售价重回历史高点并有一半价差被公司捕获，1000万元全仓茅台仍未立即达到100万元年股息目标。这说明涨价逻辑能够提高回报，但不足以消除单一持仓风险或自动完成目标。

## 八、必须验证的四个兑现指标

1. 飞天合同价、自营价与社会批价是否同步上升，而不只是二级市场炒价；
2. 直营和i茅台收入增长是否带来吨酒价格、毛利率和归母利润同步增长；
3. 经销商库存、合同负债和真实开瓶消费是否健康；
4. 涨价后销量是否保持稳定，系列酒是否停止下滑。

社会批价达到3200元但归母利润仍停留在850亿元附近，说明涨价收益主要被渠道取得，应采用低捕获情景估值，不能按1700元以上内在价值买入。
