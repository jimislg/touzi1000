# 康臣药业两步投资分析

> 数据截止：2026-08-31；最新行情：13.53港元（17:21，前收14.13港元）。

## 结论

康臣药业属于B类上沿：近五年利润持续增长、现金转化优秀、净现金充足，当前估值和股息率有吸引力；但肾病药收入约占75%、尿毒清单品依赖、医药支付和循证风险、几乎无国际化以及董事长兼CEO，使其不能成为A类核心仓。

## 好价格

当前正常化PE约9倍，毛股息率约5.52%，港股通个人税后约4.42%。基准十年回报约18.6%，悲观情景约8%。执行必须用小仓限制模型误差：

| 价格 | 累计仓位上限 |
|---:|---:|
| ≤14.0港元 | 1.5% |
| ≤12.2港元 | 3% |
| ≤10.6港元 | 5% |
| ≤8.6港元且论文完整 | 8%硬上限 |

当前13.53港元已经触发1.5%首档，但应在首轮腾讯、福耀、宇通完成后的下一交易日执行，避免超过单日50万元上限。每次加仓必须同时确认肾病药仍增长、现金流/利润≥80%、无重大医保质量事件、资本配置未漂移。

## 组合角色

稳定增长型医疗股息仓，与东阿阿胶竞争医疗/中药风险预算，不替代茅台。正常仓上限5%，硬上限8%。
