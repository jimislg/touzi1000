# 席位总览与组合压力情景改版

日期：2026-10-18。本轮对应“席位展示混乱”和“压力测试没意义”两项反馈。源码、测试结果、本报告及合成数据界面截图一并交付到 `codex/source-delivery-20261018`。

## 席位表：总览与详情分层

- 顶部只保留预算合计、当前市值和待配置预算三项。
- 主表五列：席位与成员、配置进度、待配置、价格观察、详情。进度用当前市值/席位预算及进度条表示，超出预算单独提示。
- 价格观察优先显示已到档或接近首档的成员，并显示下一观察价；同席其他成员和完整档位展开查看。
- 成本、不同口径的股息率、预计普通股息、全部策略与权重编辑放到详情；保留排序和原席位索引，排序后修改权重不会改错席位。
- 保留原预算分母、档位累计参考额分母、买入预算公式与执行限制；规划缺口不视为批准买入额度。

## 压力测试：资产与收入分别受压

原表多数行重复同一股息率与股息金额，历史故事占用空间，“静态股息抵亏年数”容易被误解为回本时间。现改为：

1. 默认“当前组合”：实际持仓估值 + 已输入可投资资金，现金保留。单独切换“规划配置”，明确同席成员等分只是建模假设，不是执行比例。
2. 三个可切换入口：股价回撤（20%）、普通股息减派（30%）、联合冲击（股价35%、减派30%、港币兑人民币10%）。这些仅为可调整的假设，不是概率、历史复刻或预测。
3. 三个主要结果：资产减少及占比、冲击后总资产、冲击后税后年普通股息。另显示最多三项主要损失来源。
4. 自定义股价、减派、汇率幅度，点击“应用假设”再计算。可选税后年普通股息目标默认留空，明确填写后才计算收入缺口与覆盖率，不继承旧税前目标。
5. 不再显示“股息抵亏年数”；不推断何时回本。行情或DPS缺失时完整结论显示“待核实”，已覆盖部分单独标注，不能把缺失当作零。

共用模型为 `investment-platform/public/investment-core.js` 的 `stressPortfolio`；小程序镜像通过 `sync-core.js` 生成，校验字节一致。本轮网页使用此函数，小程序保持四tab只读页面，未增加另一套计算。

价格下跌本身不自动减少DPS；普通股息按现有A股90%、港股通80%税后口径估算，不含特别股息和现金利息。港股资产使用 `(1−股价跌幅)×(1−汇率跌幅)`，港股普通股息使用 `(1−减派幅度)×(1−汇率跌幅)`。资产与收入不能互相抵销。估算不等同已到账或经审计的可持续收入，模型不推断永久损失、价格恢复或未来分红路径。
