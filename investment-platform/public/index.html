目标驾驶舱 1000万目标本金口径

目标本金可编辑并保存。核心逻辑：1000万全部投完并实现17.46%年化 → 5年2229万（≥2000万✓）、10年4968万（≈5000万✓）、按4%股息率≈199万/年（≥100万✓）。三个目标在「投完+达标」前提下自洽。

目标本金（万元） 账户现金 万（可改并保存）

持仓 · 目标仓位预警 权重=市值÷1000万目标本金

预警拆成两个独立维度——价格信号：现价对比购买触发价（≤触发价=可加仓；距触发价≤+5%=接近；否则等待），触发价可直接修改；仓位信号：按目标本金全部投完后的权重检查（超限给减持金额、未超限给可加金额）。上限：A·目标达成型20%／接近型15%／辅助型10%；B类8%；绝对硬约束25%。股数可直接改并保存。

信号中心 价格触发 + 仓位预警 汇总

价格信号规则：现价 ≤ 档位价 → 已触发（可进下一步流程）；距档位 ≤ +5% → 接近；否则等待。触发≠下单，仍须按SOP先刷新前三步数据再走第四步。

A类公司池 · 实时跟踪 9家

每只展示：购买触发价（现价≤触发价→整行标红「可购入」；≤+5%→整行标黄「接近」；否则灰「等待」）和建仓策略（首仓/正常/硬上限或条件说明）。状态列已前置到第二列，一眼扫状态即可。触发价与建仓策略均可直接修改，「保存修改」后持久化。

B类公司池 · 实时跟踪 22家（含A/H两地）

同A类：购买触发价与建仓策略可直接修改保存。B类硬上限8%（目标本金口径）；「回报不合格」标的任何价格不投新增。

股息目标追踪 税前100万/年 · 实仓成本口径

实仓展示：成本股息率 = DPS ÷ 持仓成本价（非现价）。税率按买入日计算：A股持股>1年免税、1个月-1年10%、<1个月20%——现有持仓统一按 2026-06-30 买入起算（2027-06-30 后转免税，期间分红按10%档）；港股通固定20%。买入日可改，后续新增股票按实际买入日填。

档位复核器 与股票池联动

用途：①复核研究报告的四档价格（换参数看敏感性）；②给池内「待定价」标的快速定价。选一只池内标的 → 按 v3.4 口径输入参数（正常化EPS，禁TTM峰值；保守情景优先）→ 算出 IRR 与四档价 → 一键把任一档写入该标的的购买触发价，股票池/持仓预警/信号中心同步更新并自动保存。

方法论速查 v3.4

流程（前三步研究 → 第四步组合，防火墙）

  • 第零步准备·双源核验·一票否决
  • 第一步细分市场三轴（需求/利润池/范式风险）+ 传导 + 风险去重
  • 第二步八维 → A/B/C/D；A/B才进观察池
  • 对标茅台 + 最优竞争者，只比公司不比价格
  • 第三步审计门9条 → 正常化 → 三情景+概率加权 → 经济价值区间 + 四档价格
  • 第四步（拟交易才触发）三重机会成本 → 仓位分档；不得倒推修改前三步

    • 档位与标签

  • P10=10年10%（门槛参考）；P12初始关注/最低新增门槛；P15优秀机会价；P17.46目标机会价
  • 目标达成型≥17.46%／接近型15-17.46%／辅助型10-15%／回报不合格<10%（不投新增）

    • 仓位（占目标本金）与分档

  • A·目标达成：3-5%/10-15%/硬20%；A·接近：2-4%/8-12%/硬15%；A·辅助：2-3%/5-8%/硬10%；B：1-2%/3-5%/硬8%；绝对25%
  • 分档建仓：≤P12累计25% → ≤P15累计60% → ≤P17.46累计100%

    • A/H 双门槛

  • H较A折价≥25% 且 绝对价≤自身档位，两道全过才行动；折价扩大≠买入信号

    • 红线精选

  • 禁止TTM峰值当正常利润；禁止为「可以买」调参；价格下跌不是加仓理由；旧价格线冻结，历史报告须按v3.4重审

    • 更新节奏
