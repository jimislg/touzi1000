# 携程集团两步投资分析

> 数据截止：2026Q1；2026Q2尚未披露；反垄断处罚后仍在整改期。

## 结论

携程仍是B类平台公司，但当前暂停买入。反垄断认定同时证明了平台市场地位和治理缺陷：取消独家合作、全网最低价及流量惩罚后，供给、佣金率、营销费用和利润率能否维持，尚无完整季度报表验证。

当前356.20港元对应正常化PE约14倍，基准十年回报约9.7%，本就未达到目标。P10/P12/P15/P17.46约为345/288/221/179港元，但整改数据出来前全部只是敏感性参考，不是下单价格。

解除暂停至少需要一个完整整改后季度、酒店供给和复购没有持续双位数下降、公开整改措施落地，随后用新的正常化EPS重算价格。
