## 2. 与被替代方案的差异（如实记录）

1. **硬上限变更：10%（100 万）→ 25%（250 万）**。这是本策略的实质变更——腾讯从"组合辅助型小仓位"升级为主力持仓之一。v3.4 方法论 tierPct[3,8,8,10] 对腾讯不再适用，config 已改为 [13,19,25]。
2. **档位价格变化**：新档 420/375/330，与 v3.4 H 档位 444.7/374.4/291.4/238.8 对照——T0（420）低于 H10（444.7），方向一致；T1（375）≈H12（374.4），几乎重合；**T2（330）显著高于 H15（291.4）**，即在 v3.4 框架的 H12-H15 之间就把仓位打满。
3. **v3.4 H 档位保留作回报参照**：H10≈444.7 / H12≈374.4 / H15≈291.4 / H17.46≈238.8 不删除，用于回答"什么价格对应 10%/12%/15% 回报"；建仓执行以新三档为准。
4. **PE 对照口径**：T1/T2 的"约 10x/8.8x PE（核心主业 7x）"来自外部策略文档的分部估值口径，按其 EPS 基准计算；与 v3.4 报告的整体 PE 口径不同，引用时不背书，仅作档位命名依据记录。
5. **现价状态**：415 港元已低于 T0 触发价 420，**当前处于 T0 入档区间**——增持 68.4 万须先走第四步流程（机会成本/纳入前后测算/换仓门槛），档位触发≠自动下单。

## 4. 风险提示（一次说完）

硬上限提到 25% 后，腾讯单一标的占组合四分之一——集中度压力测试表里"腾讯腰斩"情景对组合的冲击将从约 3% 升至最高约 12.5%（打满后）。此为郎刚知情的主动选择，本报告只做记录，不重复劝导。T2（330）触发通常意味着系统性事件，届时仍须重新过第四步，确认"黑天鹅没有伤到腾讯的生意本身"再加仓。
