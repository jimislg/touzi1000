# 三步投资分析法 v3.2 评审与 v3.3 建议

评审日期：2026-10-06  
评审对象：《三步投资分析法：好赛道 + 好公司 + 好价格 v3.2》  
评审视角：1000万元本金、5年2倍、10年5倍、长期税前被动股息100万元且持续增长（名义金额固定为100万元）

---

## 一、结论先行

**v3.2 是一次方向正确、而且必要的升级。** 新增细分市场分析，并把赛道结论强制传导到公司证据、估值参数和仓位上限，修复了两步法最容易出现的错误：在错误的行业前提下，把公司研究得很精细，再用失真的长期假设给出看似精确的买价。

但从最终投资目标倒推，v3.2 仍然存在一个结构性缺口：

> **它已经是一套很强的“个股研究与执行SOP”，但还不是一套完整的“目标实现系统”。**

目前框架能回答“这家公司是否值得买、什么价格买、买多少”，但还不能稳定回答：

1. 整个组合按当前结构，5年是否大概率达到2000万元；
2. 10年是否大概率达到5000万元，而不只是基准情景刚好达到；
3. 现金、低回报辅助仓和税费会把组合回报拖低多少；
4. 何时能够形成税前100万元股息，且不靠牺牲本金增长实现；
5. 如果5年只实现2倍，后5年需要多高回报，以及风险是否可接受。

因此，我对 v3.2 的修正后判断是：**保留三步法作为独立的个股研究体系，不在前三步之前加入组合目标层；A类和B类个股进入观察池后，再以“第四步：组合适配与成果测算”评估纳入组合的边际效果。** 同时修正赛道分类、估值概念和退出规则。

---

## 二、目标数学：现有框架哪里对，哪里还没闭环

### 1. 两个财富目标本身都算对了，但要明确它们是两个检查点

- 1000万元到5年2000万元，所需年化总回报为 **14.87%**；
- 1000万元到10年5000万元，所需年化总回报为 **17.46%**；
- 如果前5年恰好只达到2000万元，后5年必须从2000万元增长到5000万元，后半程所需年化回报为 **20.11%**。

这意味着“5年2倍”和“10年5倍”不能被理解成同一条匀速增长曲线。更合理的定义是：

> **5年2倍是最低检查点，10年5倍是主目标；组合长期规划应以17.46%的10年复合回报为主，同时要求第5年资产不低于2000万元。**

若组合每年稳定实现17.46%，第5年约为2236万元，天然高于2倍。因此不应为了第5年目标而降低前半程的组合门槛。

### 2. 100万元股息目标与5000万元资产目标可以自然统一

若第10年组合达到5000万元：

| 第10年组合税前股息率 | 年税前股息 |
|---:|---:|
| 2.0% | 100万元 |
| 2.5% | 125万元 |
| 3.0% | 150万元 |

因此最健康的路径不是现在就追逐高股息，而是：

> **先以每股内在价值增长和总回报做大本金，在目标期逐步把组合转换为“2%—3%税前股息率、股息可持续增长”的结构。**

这也解释了为什么“高股息”不能独立成为好投资标准。一个6%股息率但利润持续萎缩的公司，不如一个当前股息率2%、每股自由现金流和股息能长期增长的公司。

本次已明确：100万元是**税前、名义金额固定**的年度股息目标，不随通胀自动上调。第四步仍需记录目标从第几年开始实现，以及实现前股息是否全部再投资，否则总回报目标和现金收入目标可能互相冲突。

### 3. “低于17.46%的仓位由更高回报资产补偿”方向对，但计算表达需要升级

个股IRR不能简单按仓位做算术平均后当作组合复合回报。现金流时点、分红再投资、调仓、汇率、税费和亏损路径都会影响组合结果。

建议将这条改成：

> 在第四步中，将候选个股与已有仓位共同纳入组合现金流模型，按悲观、基准、乐观三情景计算第5年和第10年期末财富、组合XIRR及税前股息。前三步的个股结论先行并冻结，第四步不得为了使组合“看起来达标”而反向修改公司分类或估值参数；也不得用个股IRR的简单加权平均代替组合测算。

## 三、三步法升级最合理的五个地方

### 1. 先看利润池，再看公司，纠正了“只见树木”的问题

细分市场边界、替代品、价值链和利润池迁移，是长期预测收入、利润率和资本回报的前提。领展、分众、代建等案例所暴露的问题，确实不是多看一张公司报表就能解决的。

### 2. 赛道不直接否决公司，这一点很成熟

逆风赛道仍可能存在份额提升、现金牛或高赔率机会；顺风赛道也可能因为竞争激烈、资本回报差而没有好公司。v3.2 没有把“行业增长”等同于“投资回报”，这是正确的。

### 3. 将赛道判断传导到估值和仓位，而不是只写行业故事

许多研究报告的行业章节与估值完全脱节。v3.2 要求赛道结论改变反方证据标准、终值、压力情景和仓位，这是从“描述行业”走向“约束决策”的关键进步。

### 4. 估值审计门很强，应继续保留

估值对象锁定、四座勾稽桥、四种EPS分栏、三项恒等式、独立模型复核、版本漂移归因和旧价格线冻结，能够显著减少口径漂移和“为了得到想要的价格而换分母”的问题。

### 5. 好公司、好价格、组合执行被分开

公司质量不因便宜而改变，价格合理不代表必须买入，买入还要受组合角色、相关性和仓位约束。这符合巴菲特、芒格和段永平共同强调的机会成本思维。

## 四、需要优先修正的八个问题

## P0：不修会直接影响目标实现

### 问题1：需要明确前三步与第四步的研究边界

三步法的研究对象是**个股**，其任务是独立回答：细分市场是否可理解、公司是否达到A/B质量门槛、当前价格对应什么回报。组合策略不应前置，否则可能为了填补组合缺口而降低个股标准，或者反向修改增长与估值假设。

建议采用以下边界：

- 前三步只研究个股，不讨论为了组合目标“必须买谁”；
- 前三步完成后冻结赛道判断、A/B/C/D分类、估值输入和买价；
- 只有A类或B类公司进入观察池；C类和D类不进入第四步；
- A/B类进入观察池不等于买入，只代表具备接受组合适配审查的资格；
- 第四步只回答“如果加入现有组合，会取得什么成果、增加什么风险、替代谁”，不得倒推修改前三步结论。

这样既保留个股研究的独立性，也能在执行前完成组合闭环。

### 问题2：P10不是“内在价值”，现有安全边际公式概念混淆

P10、P12、P15、P17.46本质上是不同目标回报率下的**最高可接受买价**，不是四种内在价值。把P10称为“合理持有价”，再用：

`安全边际 = 1 - 当前价格 ÷ 基准情景P10`

会把“10%目标回报价”误当成价值锚。安全边际不应随着投资者任意选择10%、12%或15%的回报门槛而改变。

建议分成两组输出：

1. **经济价值区间**：基于保守现金流与统一资本成本得到；
2. **目标回报买价**：H10、H12、H15、H17.46，分别代表达到相应回报门槛的最高价格。

安全边际应相对保守经济价值或悲观价值计算；目标买价用于行动，不再称作内在价值。P10可改名为“H10回报门槛价”，避免“合理”二字造成锚定。

### 问题3：需要把组合研究正式定义为有条件触发的第四步

建议将现有“组合执行门”扩展并正式升格为第四步，同时新增以下强制表：

| 指标 | 悲观 | 基准 | 乐观 |
|---|---:|---:|---:|
| 第5年期末资产 |  |  |  |
| 第10年期末资产 |  |  |  |
| 组合XIRR |  |  |  |
| 第5年税前股息 |  |  |  |
| 第10年税前股息 |  |  |  |
| 现金拖累 |  |  |  |
| 最大阶段回撤 |  |  |  |
| 前三大风险因子损失贡献 |  |  |  |

第四步的触发条件是：前三步已完成，个股达到A类或B类并进入观察池，而且需要评估是否纳入现有组合。第四步必须回答：

1. 以当前价或拟买入价纳入后，第5年和第10年组合资产预计变化多少；
2. 组合距离5年2倍、10年5倍的目标缺口缩小还是扩大；
3. 第5年、第10年税前股息增加多少，对100万元目标贡献多少；
4. 它在组合中承担核心复利、增长、稳定股息、周期反转还是风险分散角色；
5. 它增加了哪些行业、币种、政策和相关性风险；
6. 资金来自新增现金还是替换现有持仓，替代谁，机会成本是什么；
7. 合理首次仓位、正常上限与硬上限是多少。

### 问题4：只用“基准情景IRR”给目标标签，成功概率不足

17.46%的基准IRR不等于大概率实现17.46%。高目标尤其不能依靠刚好踩线的单点预测。

建议至少同时使用三项：

- 基准情景10年IRR；
- 悲观情景下的永久损失与期末财富；
- 目标达成概率或情景权重下的期望期末财富。

概率本身可以主观，但必须公开依据，并对概率做敏感性测试。先以“情景覆盖率”替代复杂蒙特卡洛也可以，关键是不能把一个基准点当成确定结果。

## P1：会导致重复惩罚、错误锚定或执行矛盾

### 问题5：“顺风/中性/逆风/动荡”把三个不同问题压成了一个标签

一个市场可能需求增长但竞争恶化，也可能需求萎缩但供给退出、龙头利润池扩大。“动荡”又是技术不确定性，不与前三者处在同一维度。

建议改为三轴输出：

1. **需求轴**：结构增长 / 稳定 / 结构下降；
2. **利润池轴**：改善 / 稳定 / 恶化；
3. **范式风险旗标**：低 / 中 / 高（技术、监管或商业模式断代）。

最后再生成综合赛道结论。这样估值传导可以落到销量、价格、利润率、再投资率和终值，而不是依赖一个宽泛标签。

框架名称也建议从“好赛道 + 好公司 + 好价格”改为：

> **看清赛道 + 选对公司 + 等到好价格**

因为第一步的目的不是只投资“好赛道”，而是看清公司所处的经济环境。这个名字更符合正文的真实纪律。

### 问题6：赛道折扣可能被计算三次

逆风目前会同时：

- 提高公司分析门槛；
- 下调增长与终值；
- 增加折扣情景；
- 再把仓位上限降一档。

这可能是合理的多层防线，也可能是对同一风险重复惩罚。建议增加“风险传导与去重表”：

| 风险 | 经营预测已反映 | 终值已反映 | 情景概率已反映 | 仓位再折扣 | 是否重复 |
|---|---|---|---|---|---|

仓位折扣只处理无法通过估值吸收的模型不确定性、尾部风险和相关性风险，不再重复处理已经进入现金流的普通逆风。

### 问题7：“逆风终值倍数上限=当前水平”不一定保守

如果当前估值处于高位，当前倍数本身就不是可靠上限。建议改为：

> 逆风赛道的基准终值倍数不得高于“当前倍数、历史中周期合理倍数、由成熟期增长与资本回报支持的倍数”三者中的最低者；若当前倍数因周期底部利润失真，应改用正常化盈利后再比较。

### 问题8：卖出阈值与17.46%目标脱节

框架允许持仓在未来10年基准IRR降至6%以下才进入估值减仓审查。对追求17.46%组合回报的目标而言，这个阈值过低。即使没有明显更优替代，一个长期仅有7%—9%预期回报的大仓位也会显著拖累目标。

建议把卖出/减仓拆为三类：

1. **论文退出**：质量或诚信破坏，立即审查退出；
2. **目标降级**：预期回报低于组合最低门槛，降为资金来源或辅助仓；
3. **机会切换**：税费后替代标的回报优势足够大，执行换仓。

具体阈值不宜凭直觉一次定死，应在第四步中结合组合目标反推，并通过历史样本校准。

## 五、其他内容层面的修改建议

### 1. 修正文内两个明确矛盾

- A类、B类公司在第二步综合判定后，应写“进入第三步”，不是“进入第二步”；
- C类写着“不投入新增资金”，但仓位表又允许0%—1%观察仓及2%上限。建议统一为：C类不得用正式投资资金建仓；如确需跟踪，只允许独立核算的研究仓，且不计入正常仓位体系。

### 2. 茅台应保留为质量标尺，但不应成为唯一机会成本标尺

建议改为“三重基准”：

- 质量基准：贵州茅台；
- 机会成本基准：当前组合中风险调整后回报最高的持仓；
- 无风险/低风险基准：人民币现金、国债或对应币种低风险收益。

这样既保留中国优质公司的实战标尺，又避免把白酒商业模式变成所有行业的隐性模板。

### 3. 双来源核验应先对齐定义，再比较误差

行业规模、份额和资本开支常因统计边界不同而相差很大。建议把规则改为：先核对定义、期间、币种、含税与否、合并范围；只有同口径数据差异超过阈值，才触发停止。不同口径不能直接计算误差率，应列出区间和差异原因。

### 4. 精简重复规则，降低Agent漏项概率

同一硬规则目前在框架定位、估值章节、Agent硬规则和复制提示词中多次出现。长提示词会提高遗漏和机械填表风险。

建议拆成三份：

1. **投资政策与核心门槛**：短、不可修改；
2. **研究操作手册**：解释为什么和怎么做；
3. **结构化输出Schema/检查器**：机器检查缺项、口径和计算。

最终提示词只引用规则编号，不重复整套正文。

### 5. 增加“决策有用性”原则

并非每家公司都需要完整TAM；资料不足时，强行给出行业精确数字会制造伪精确。允许写明“该数据对估值不构成关键变量”，把精力放在真正决定每股价值的2—3个变量上。

### 6. 增加框架校准，而不只做文字复盘

每次报告保存当时的悲观、基准、乐观预测；1年、3年、5年后比较实际值，记录：

- 收入、利润率、ROIC、FCF偏差；
- 偏差来自事实、模型还是估值；
- 哪个Agent或哪类公司最容易过度乐观；
- 赛道判断是否真的提高了预测质量。

至少积累5—10个不同类型案例后，再决定硬阈值是否过严或过松。三家公司连续失效可以触发检查，但不足以单独证明规则应修改。

## 六、建议的 v3.3 总体结构

```text
第零步：数据资格、能力圈、类型标签、一票否决
    ↓
第一步：看清细分市场
    ├─ 需求轴
    ├─ 利润池/竞争轴
    └─ 技术与监管范式风险
    ↓（逐参数传导，并检查风险是否重复计算）
第二步：好公司八维分析
    ↓
质量三重对标
    ↓
第三步：好价格
    ├─ 经济价值区间
    └─ H10/H12/H15/H17.46目标回报买价
    ↓
A/B类 → 纳入观察池；C/D类 → 停止
    ↓
第四步：组合适配与成果测算（有条件触发）
    ├─ 纳入前后5年/10年期末财富变化
    ├─ 组合XIRR、现金拖累与目标缺口
    ├─ 税前股息贡献及100万元目标覆盖
    ├─ 资金来源、替代对象与机会成本
    ├─ 集中度、相关性和压力测试
    └─ 首次仓位、正常上限、硬上限与执行计划
    ↓
执行、监控、归因与校准；前三步结论保持冻结
```

## 七、建议直接加入 v3.3 的核心条款

### 条款A：个股研究与组合研究边界

> 第一至第三步是独立的个股研究，不因现有组合缺口而修改公司分类、经营假设、估值参数或买价。只有完成前三步且达到A类或B类的公司，才进入观察池并获得第四步组合适配审查资格。进入观察池不等于买入。

### 条款B：股息目标

> 100万元被动股息目标按税前、名义固定金额管理。第四步应输出纳入候选个股前后的税前股息金额、目标覆盖率、前五大股息来源集中度和未来5年增长能力。不得以牺牲本金长期增长为代价机械追求当期高股息。

### 条款C：价值与买价分离

> 经济价值用于判断证券价值范围，目标回报买价用于决定行动。H10/H12/H15/H17.46仅表示在统一税费与分红口径下达到相应回报门槛的最高价格，不称为内在价值；安全边际不得仅以H10计算。

### 条款D：第四步组合闭环

> 对拟纳入组合的A/B类观察池公司，必须在第四步重算组合悲观、基准、乐观三情景下的第5年与第10年期末财富、组合XIRR、税前股息和最大阶段回撤，并与纳入前组合对比。若个股合格但使组合目标缺口扩大，必须说明其独立角色与补偿来源，否则不执行。第四步不得反向修改前三步已经冻结的个股结论。

### 条款E：风险去重

> 同一风险若已进入收入、利润率、资本投入、终值或情景概率，不得未经说明再次通过仓位机械重复惩罚。仓位折扣只处理模型无法吸收的不确定性、尾部风险、流动性和组合相关性。

## 八、最终评价

三步法相比两步法更接近真正的长期投资：**先理解公司所处的经济环境，再判断公司能否持续获得超额回报，最后等待价格给出安全边际。** 这一步升级应当保留。

但你的目标不是“多写几份高质量公司报告”，而是让1000万元在可承受风险下，经过10年形成5000万元资产和每年税前100万元可增长现金收入。为此，下一版最关键的升级不是把组合目标塞进个股研究，而是保持两个层次清晰分工：

> **前三步独立完成个股研究并形成A/B观察池 → 第四步评估纳入组合后的期末财富、税前股息、风险与机会成本 → 执行 → 归因校准。**

完成这个闭环后，前三步仍然保持为纯粹的个股研究方法，第四步则把合格个股转换为真正服务于个人目标的组合决策。
