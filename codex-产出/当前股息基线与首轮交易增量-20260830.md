# 当前股息基线与首轮交易增量

> 日期：2026-08-30  
> 持仓基准：2026-08-25券商截图，未假设此后已经成交。  
> 汇率：港元兑人民币0.86498（2026-08-28中间价）。  
> 口径：优先采用正常化普通股息；A股基准假设持有超过一年、红利税0%，港股通按20%扣税。A股各批次实际持有期限未知，因此另列税务敏感性。

当前正常化税后股息约7.19万元，仅完成名义100万元目标的7.2%。股息占总资产收益率约0.72%，主要原因不是持仓公司都不分红，而是约80%资产仍为现金。

股息来源目前高度集中：招商银行贡献约62%。这不符合终态“至少五家公司、最大单一来源不超过30%”的安全标准，但在建仓初期可以接受；后续必须通过增加非金融现金流来源自然摊薄，而不是继续追加招行。

|---|---:|---:|---|

按最近已宣派金额回看，现有持仓一年股息约7.31万元；按正常化口径约7.19万元，两者接近，但不能因此忽略格力、宇通等公司的分红周期性。

## 三、A股持有期限的税务敏感性

长期规划按持有超过一年、A股红利税暂免计算。但当前各批次买入时间尚未录入：

| A股经济税率假设 | 当前组合正常化税后股息 |
|---:|---:|
| 0%（持有超过一年） | 约71,862元 |
| 10%（持有一个月至一年） | 约65,664元 |
| 20%（持有不超过一个月） | 约59,466元 |

这不是建议为了免税拒绝卖出已经破坏投资论文的公司；它只是要求每次置换都记录批次持有期和潜在补税，避免把税前股息误作可支配收入。

## 四、执行首次交易后的股息

按执行总表：分两日先买入腾讯700股、福耀2,000股、宇通6,600股；三笔买入全部成交后，再卖出万华1,200股。若任一买入未成交，则继续保留万华。

| 交易 | 正常化税后股息变化 |
|---|---:|
| 买入腾讯700股 | +2,567元 |
| 买入福耀2,000股 | +4,200元 |
| 买入宇通6,600股 | +11,616元 |
| 三笔买入均成交后卖出万华1,200股 | -1,500元 |
| **净增加** | **约16,883元** |

交易后正常化税后年股息约88,745元，完成100万元目标的8.9%。招商银行占股息来源约50.2%，仍然偏高，但已从62%下降。

首次交易的首要目的仍是建立预期总回报更高的起步仓，不是立刻最大化股息。若为了多获得一两万元股息而全部买入成熟高股息公司，会牺牲本金增长速度。

## 五、两年股息进度观察线

目标组合900万元股票的正常化税后股息约33万元，即股票部分平均约3.67%。若按目标结构逐步部署：

| 时间/仓位 | 股票仓位观察线 | 对应正常化税后股息参考 | 说明 |
|---|---:|---:|---|
| 当前 | 约19.5% | 约7.19万元 | 招行贡献过半，现金比例高 |
| 首轮交易后 | 约24.45% | 约8.87万元 | 起步仓，不追求立即高股息 |
| 12个月 | 45%—55% | 约16.5万—20.2万元 | 若无合格价格，顺延而非强买 |
| 24个月 | 70%—90% | 约25.7万—33.0万元 | 主要部署应基本完成 |
| 第5年 | 资产约1570万—1610万元 | 约50万—53万元 | 依赖盈利与股息增长，并非只靠加仓 |
| 第9—10年 | 资产约2380万元以上 | 迁移后约100万元 | 终态税后股息率约4.2% |

上述是规划观察线，不是收益保证。若公司削减股息、资产增长低于基准或现金长期未部署，进度必须下调。

## 六、目前真正的股息缺口

| 阶段 | 正常化税后股息 | 距100万元缺口 |
|---|---:|---:|
| 当前持仓 | 约7.19万元 | 约92.81万元 |
| 首轮交易后 | 约8.87万元 | 约91.13万元 |
| 1000万元目标组合全部建成 | 约33万元 | 约67万元 |
| 终态迁移完成 | 约100万元 | 0 |

这表明100万元目标不能靠寻找一只10%股息率股票解决。真正的任务是：两年内完成高质量资产部署、约十年内把总资产做大约2.4倍、后期再迁移约四分之一资产提高分配率。

## 七、下一步数据要求

为了把估算变成真实现金流账本，持仓系统还需要增加：

1. 每一批买入日期与数量；
2. 每笔实际收到股息、币种、到账汇率和代扣税；
3. 普通股息与特别分红标签；
4. 公司正常化DPS及其调整理由；
5. 未来十二个月预计除权日和到账日。

在这些数据补齐前，7.19万元是适合规划的正常化估算，不应表述为已经实际到账的精确金额。
