## 八、这次分析真正的发现（比结论重要）

### 发现一：这是一只「现金流极好、增长失速、现金不分」的类债股

三个事实同时成立：

- 净现比 159%、ROIC 20.3%、FCF/净利 146% —— **赚钱能力是真的**
- 主品牌 +0.2%、门店 −4%、毛利率跌破 50% —— **成长已经停了**
- 派息 80.2%、股息率 7.09% —— **分钱是真分，但只分流量，不动存量**

它的定价逻辑已经从「成长股」换成「类债资产」。PE **11.00×**（FY2026 净利口径；TTM 口径 10.97×）、**10 年分位 1.07%**（历史最便宜的 1%），不是市场犯错，是市场把它当债券定价了。

### 发现二：市场对账上 156 亿，按 0 计价

拆解非常干净：经营业务按 12% 折现 + 156 亿现金 × 0 = 现价。这有两个可能：

- **市场是对的**：这钱永远不会分，只是管理层的理财池
- **市场是错的**：公司 60% 控股 + 有回购先例 + 现金充裕，某个时点会特别分红或私有化

我倾向前者——**但这是可证伪的**。一旦出现派息率上调到 90%+、首次特别分红、或大额回购，这个 156 亿就开始被计价，结论会翻。

### 发现三：与海天对照，同是「现金不被计价」，机理不同

| | 海天国际 | 波司登 |
|---|---|---|
| 派息率 | 33% | **80.2%** |
| 净现金/市值 | 54.26% | 35.50% |
| 留存去向 | 全买理财（2.0–8.3%） | 20% 留存也买理财，但 80% 已分 |
| FCF ② | **FAIL**（留存毁灭价值） | PASS（ROIC 20.27%） |
| 净现金剥离后 | 经营 PE 3.21×、ROE 31.45% | 经营 PE 9.64×、1/PE 税后 8.30% |
| 问题 | 钱到不了股东 | 增长到不了 5% |
| 两法结论 | 不买 | 不买 |

**同样是「不买」，理由完全不同。** 海天是「便宜但你拿不到」，波司登是「拿得到但不够多」。

## 十、方法边界

1. **这是「不买」，不是「该卖」**。H12 5.22 高于现价 15.2%，H15 也有 4.73——推演从未给出「贵」。
2. **口径敏感性 >> 参数敏感性**。退出 PE 从 11× 到 7×，H12 从 5.22 到 4.07（−22%）；净现金从五折到零，H12 从 5.22 到 4.43（−15%）；**两者叠加就翻结论**。相比之下 g 从 5% 到 4% 只动 6%。
3. **不构成建仓建议**。四步法在这里输出「档三 + 仓位 0」；配对结论见同目录《波司登-20261128-唐朝估值法.md》。两法都说不买，但**不是互证**（F4）：唐朝法问「贵不贵」，四步法问「锁死在哪」。
