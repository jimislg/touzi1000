# 投资分析中心

基于《两步投资分析法：好公司 + 好价格 v3.0》构建的本地投资研究仪表盘，服务于三个长期目标：**5年2倍、10年5倍、长期年股息100万**（本金1000万元）。

## 启动

```bash
cd /Users/bytedance/Documents/郎刚的芒格/investment-hq
npm start               # 默认端口 4280
node server.js 4290     # 或指定端口
```

打开 <http://127.0.0.1:4280/>。零依赖，只需 Node.js ≥ 16。

## 五个模块

| 模块 | 内容 |
|---|---|
| 目标总览 | 三大目标的数学要求、真实路径、系统预警、股息缺口，以及**月度实际持仓上传、留档和集中度统计** |
| 持仓与建仓 | 当前实际持仓+实时最新价、**最多7席和一进一出硬约束**、可编辑目标配置、建仓阶梯、候选交易卡、成交登记与交易纪律 |
| 研究库 | 17只股票按A/B/C/D分组；回报标签由IRR自动校正；四档价格标尺、八维分析、三情景、茅台对标；**人工校准买入点可持久化保存** |
| 方法论 | 两步法SOP v3.0全貌 + **完整版Agent分析指令模板**（4770字，七大章节嵌入全部方法论，一键复制） |
| 文档库 | 全部源文档：分类筛选+搜索+在线阅读，**添加/删除文档**；新加入的两步法文档**自动解析**为研究库草稿卡片（分级/四档价格/IRR，标记"自动解析"待人工核对） |

## 实时行情

- 顶栏「⟳ 更新行情」按钮：从腾讯公开行情接口获取最新股价（30秒服务端缓存），页面加载时自动获取一次。
- 持仓表"最新价"列、建仓阶梯卡片、研究库卡片与价格标尺均显示实时价并标注涨跌幅。
- 价格标尺上「▼现价」为实时价（无行情时回退到文档时点价）。
- 到价只触发复核流程，不构成买入指令；实际下单前必须刷新行情与财报（SOP硬规则）。

## v2 目标一致性改造

- 组合基准收益不再读取写死的11.5%，而是按目标权重和各公司最新基准IRR自动计算。
- “目标达成型/接近目标型/组合辅助型/回报不合格”由统一阈值自动生成，C/D类直接显示“质量未过执行门”。
- 目标仓位自动对照各公司报告硬上限和25%绝对上限；越限在目标页和持仓页同时预警。
- 风险约束后的超额仓位转为“机会预备”，只允许投入进入P15/P17且基本面复核通过的标的。
- “校准买入点”保存到 `data/portfolio.json`，与报告四档价格分离，避免人工判断污染研究结论。

## 七席聚焦与月度快照

- 正式目标组合和实际持仓最多7只；目标编辑超过7只、满席后新增第8只成交都会被服务器拒绝。
- 新公司只能“一进一出”，观察池不占席位。
- 目标总览可上传月度持仓截图/PDF或CSV/JSON；核对后同步当前持仓，并统计持仓数、股票/现金仓位、第一大/前三大集中度、非目标持仓与正常化股息。
- 原始券商截图和PDF只保存在本机 `data/snapshots/`，默认不提交GitHub。

## 数据口径（重要）

- 所有分析价格均为**文档时点数据**（2026-08-25~28）；实时行情仅为价格参考，基本面数据仍以文档为准。
- 数据文件在 `data/`：
  - `goals.json` 目标与组合收益情景
  - `portfolio.json` 持仓、目标配置（可通过页面编辑保存）、建仓阶梯、候选、纪律
  - `portfolio-evolution.json` 组合决策演变时间线
  - `methodology.json` SOP v3.0 结构化 + 完整版Agent指令模板
  - `stocks/*.json` 16只股票两步法分析（提取自原文档，字段宁缺毋假）
  - `docs/` 源文档（页面可增删；删除仅影响本站副本，不动原目录）
- 更新数据：编辑 JSON 后刷新页面（已加 no-cache 头）；或通过页面交互（目标配置编辑、文档库增删）自动保存。
- 新增两步法文档：文档库→添加文档→命名「XX两步投资分析-YYYYMMDD」→ 研究库自动出现草稿卡片，核对后在 `data/stocks/` 补全标准JSON替换。
