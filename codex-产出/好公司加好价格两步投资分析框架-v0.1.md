# “好公司 + 好价格”两步投资分析框架 v0.1

状态：讨论稿，待共同校准。

## 总原则

公司质量和股票价格必须分开判断：

1. 先判断即使股票停牌十年，是否愿意成为这家公司的股东；
2. 再判断按照当前价格买入，能否达到目标收益率并保留安全边际；
3. 两项都通过后，才进入组合仓位和分批建仓决策。

“好公司”不因价格低而降低标准；“好价格”也不能挽救一家坏公司。

## 前置否决关：不计入八维评分

出现任何一项，原则上停止研究或暂不投资：

- 无法用一句话说清公司怎样赚钱以及最重要的三个变量；
- 管理层诚信、审计或关联交易存在无法解释的重大问题；
- 护城河正被不可逆地破坏；
- 资产负债表存在可能导致永久损失的杠杆风险；
- 投资逻辑主要依赖下一位投资者支付更高价格；
- 关键数据无法通过年报、公告和独立来源核实。

## 第一步：它是不是一家好公司

### 1. 是否聚焦——改为“业务聚焦与战略一致性”

不要求只有一个产品，而要求所有重要业务共享客户、品牌、渠道、技术或供应链优势。

重点检查：

- 核心业务贡献多少收入、利润和自由现金流；
- 新业务是否强化主业，还是管理层为了规模盲目扩张；
- 过去十年资本投入是否集中在高回报领域；
- 能否用一句话说清未来十年的主要赚钱方式。

腾讯虽然业务多，但如果围绕社交关系链和数字生态展开，仍可算聚焦；格力若进入与主业缺少协同的业务，则属于失焦。

### 2. 企业文化——扩大为“文化、诚信、治理与接班”

企业文化不能靠口号评分，只看长期行为证据：

- 对客户、员工、供应商和股东是否长期公平；
- 管理层承诺与实际交付是否一致；
- 分红、回购、并购和再投资是否理性；
- 关联交易、激励计划和薪酬是否公平；
- 创始人或核心人物离开后，公司能否正常运行；
- 是否愿意主动披露坏消息。

诚信问题是一票否决项，不应由其他项目的高分抵消。

### 3. 企业护城河

分别验证，而不是笼统说“品牌强”：

- 品牌与真实定价权；
- 网络效应；
- 转换成本；
- 规模或成本优势；
- 渠道、牌照、数据、专利和工艺；
- 护城河过去五年是在变宽、稳定还是变窄。

最终回答：竞争对手投入100亿元，能否在十年内复制？客户为什么不能轻易更换？

### 4. 国际化——作为条件性维度

国际化不是好公司的必要条件。茅台和招商银行主要依赖中国市场，仍可能是好公司；失败的国际化反而会摧毁价值。

检查内容：

- 公司是否必须国际化才能继续增长；
- 海外收入、利润和自由现金流占比；
- 自主品牌还是低价值代工；
- 海外ROIC能否覆盖资本成本；
- 本地渠道、管理团队、供应链和政治风险；
- 国际化是在分散单一市场风险，还是增加复杂度。

结论使用“加分、无影响、减分”，不因没有海外收入自动扣分。

### 5. 竞争对手——改为“行业结构与竞争地位变化”

不只列出竞争对手名称，而要回答：

- 行业是垄断、寡头竞争还是充分竞争；
- 公司份额、价格、毛利率相对同行如何变化；
- 上游和下游谁掌握议价权；
- 新进入者和替代技术是否改变竞争规则；
- 公司增长来自行业增长、抢份额，还是降价；
- 最优秀的竞争对手比它强在哪里。

竞争格局是护城河的外部验证：护城河讲“为什么强”，竞争分析讲“实际有没有持续赢”。

### 6. 细分客群的发展趋势——改为“客户需求的持续性与增长空间”

重点不是泛泛的行业规模，而是实际付费客户：

- 客户数量、购买频次、客单价和复购率；
- 客户收入、年龄和消费习惯如何变化；
- 产品属于刚需、改善型需求还是可延迟消费；
- 渗透率、更新周期和替代品；
- 公司是否能从现有客户获得更多价值；
- 需求在经济衰退、人口变化和技术迁移下是否仍成立。

### 7. 财务健康度——改为“财务质量与资本回报”

至少观察完整周期的五至十年数据：

- 收入、扣非利润和每股收益，而非只看总利润；
- ROIC/ROE及其来源，剔除高杠杆和低权益基数造成的虚高；
- 经营现金流、自由现金流与净利润的匹配程度；
- 有息负债、净现金、利息覆盖和表外承诺；
- 资本开支、营运资本和维持性投入；
- 股本稀释、回购注销和分红；
- 应收、存货、商誉及会计政策是否异常。

行业不同，主指标必须不同：银行看ROE、资产质量、净息差和资本充足率；保险看经营利润、内含价值和投资资产质量；周期制造看中周期利润；消费和平台公司看自由现金流与ROIC。

### 8. 与茅台对比——作为机会成本检验

第一步只比较公司质量，不比较股票收益率：

- 商业模式是否更简单；
- 需求持续性和可预测性；
- 定价权；
- 资本投入强度；
- 自由现金流质量；
- 管理和治理风险；
- 十年后竞争地位的确定性。

结果不要求“必须超过茅台”。应回答：这家公司在哪些方面不如茅台？它提供了茅台没有的什么——更大的增长空间、不同的风险暴露、国际化或更高现金回报？如果没有明显补充价值，为什么不直接持有茅台？

## 第一步的输出方式

不建议把八项简单相加后以60分判定好公司，因为诚信问题和财务脆弱不能被国际化等项目抵消。

采用“核心门槛 + 分级”制度：

- 核心门槛：文化诚信、护城河、竞争地位、客户需求、财务质量必须全部通过；
- 条件维度：聚焦和国际化可因公司类型解释，但必须说明；
- 茅台对比：只做机会成本结论。

最终分类：

- A类：核心复利公司——护城河强、需求长期、财务健康、可预测性高；
- B类：优秀但有条件——周期、单一人物、资本密集或行业变化造成明显约束；
- C类：普通好公司——能够经营，但没有足够股东回报优势；
- D类：否决——诚信、财务或竞争优势不合格。

只有A类和少数B类进入第二步估值。

## 第二步：它是不是一个好价格

### 1. 先确定正常化盈利

不能直接使用景气顶部的TTM利润。分别确定悲观、基准、乐观三种正常化EPS或所有者收益，并说明：

- 收入增长；
- 利润率；
- 再投资需求；
- 分红和回购；
- 股本变化；
- 周期位置。

### 2. 按公司类型选择一个主估值模型

- 稳定消费品：所有者收益/自由现金流折现 + 合理PE交叉验证；
- 银行：正常化ROE、PB和分红回报；
- 保险：经营利润、内含价值、投资资产压力测试；
- 周期制造：中周期利润和低位资产负债表，不用峰值PE；
- 高成长平台：自由现金流情景和增长持续期。

PE、PEG、股息率和历史分位不能重复堆叠成多个独立信号。

### 3. 倒算三种价格

你的目标对应：5年2倍需要14.87%年化；10年5倍需要17.46%年化。因此每家公司都应给出：

1. 合理价值：基准情景要求约10%年化的价格；
2. 优秀买入价：基准情景要求约12%—15%年化，并在悲观情景下控制永久损失；
3. 目标达成价：基准情景要求至少17.46%年化的价格。

“目标达成价”可能长期不到，这是框架诚实性的结果，不应为了方便买入而降低数学标准。合理价格可以持有，不等于适合用新增资金买入。

### 4. 同时给出安全边际

买入价不仅由收益目标决定，还应同时满足：

- 相对基准内在价值至少20%—30%的折价；
- 悲观情景不依赖估值扩张；
- 能承受利润低于预期、股息削减和估值下降同时发生；
- 三至五年不涨仍愿意持有。

最终取“目标收益倒算价”和“安全边际价格”中更低的一个。

## 第二步的标准输出

| 项目 | 输出 |
|---|---|
| 当前价格与数据日期 | 明确日期、币种、除权口径 |
| 正常化EPS/所有者收益 | 悲观、基准、乐观 |
| 合理价值 | 价格区间 |
| 优秀买入价 | 价格区间 |
| 17.46%目标达成价 | 价格或“不可实现” |
| 当前预期回报 | 5年、10年，包含股息 |
| 悲观损失 | 金额、跌幅及触发原因 |
| 买入结论 | 买入、等待、持有、不投 |

## 两步之后：组合执行门（不是第三次公司分析）

“好公司 + 好价格”仍不等于可以任意重仓。下单前必须回答：

- 它在组合中替代谁，还是承担独立角色；
- 与现有持仓的行业、宏观和监管相关性；
- 首次仓位、正常上限和极端上限；
- 分档买入价及累计仓位；
- 哪些基本面变化会暂停加仓或退出。

这是防止“每一只单看都不错，组合整体却高度同质化”的最后一道门。
