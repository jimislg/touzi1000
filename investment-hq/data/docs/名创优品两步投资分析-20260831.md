# 名创优品两步投资分析

> 数据截止：2026H1；价格参考：2026-08-31盘中18.66港元。

## 修正结论

名创优品降为C类观察公司，撤回“B类、当前可建仓”的旧判断。国内主业和全球门店网络仍有竞争力，但海外同店下降、直营扩张、销售费用率上升、库存、永辉投资与融资成本共同侵蚀所有者收益；聚焦、治理和财务健康三个核心维度同时存疑。

公司调整利润加回了永辉收购相关融资成本、股权激励并剔除汇兑损失，不能直接作为股东利润。按正常化EPS 1.30—1.50元重建，修正基准十年回报约8.8%。P12/P15/P17.46约14.44/11.47/9.57港元，但C类公司的价格只作观察，不构成买入动作。

恢复B类至少要求连续两季度真实所有者利润恢复增长、海外同店转正、直营回收和库存改善、停止新增跨界投资。
