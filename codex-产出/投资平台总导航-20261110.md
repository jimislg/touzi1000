## 四、运维流程（备忘）

### 数据改动（触发价/持仓/DPS）

```
本地 config.json 改动 → 备份 → scp 到 VPS /opt/invest-platform/ → ssh 写入+回读校验 → 重启服务 → API 校验 → git 提交推送双分支
```

### 代码改动（server.js / index.html / core / 小程序）

```
npm test 全绿 → rsync 到 VPS（排除 config.json 等数据文件）→ 重启 + md5 校验 → 小程序 bump 版本 + build + verify + preview 码 → git 双分支推送
```

### VPS 关键信息

- `ssh root@149.28.89.105`（免密），目录 `/opt/invest-platform/`
- 服务：`systemctl restart invest-platform`
- rsync 排除：config.json、config.json.backup*、publicConfig.json、divcache.json、test-*、*.md、.workbuddy*
- 核对纪律：远端操作一律用 python 校验，不信任 grep/sed 回显；ssh 远端读 /tmp 前先确认当轮 scp 已传

## 五、关键纪律（速查）

1. **价格口径**：平台所有价格线（档位/买点）一律**税前市场价**；港股通 20% 税费影响只进 note/决策层，不在页面混排两个维度。
2. **档位金额基数**：观察池每只档位按**总上限 100 万**配比（第四步 targetCapital 1000 万是另一维度，二者不混用）。
3. **先确认再写入**：个股分析结论先经郎刚确认，才更新平台档位；策略文本给出即视为确认。
4. **双更新纪律**：每次档位/策略更新必须同轮改**平台 + 对应个股研究文档**两处。
5. **git 备份**：所有修改验证通过后当轮提交推送（`jimislg/touzi1000` 双分支）。
6. **归档双写**：报告归档 codex-产出/ 同轮复制知识库。
7. **发布**：代码改动验证通过后直接发布到 VPS，不再走云服务发布（云发布已废除）。
