# 两步投资分析法：好公司 + 好价格

版本：v3.0  
定稿日期：2026-08-27  
用途：中国A股、港股及其他可投资上市公司研究  
目标：让不同Agent在使用相同数据时，得到同口径的事实、计算、价格区间和行动结论。

---

## 一、框架定位

本框架只回答两个核心问题：

1. **它是不是一家值得长期持有的好公司？**
2. **当前价格能否提供足够回报和安全边际？**

顺序不可颠倒。好公司未通过，不因价格低而进入估值和买入环节；好公司通过，也不代表当前股票值得买入。

两步完成后增加“组合执行门”。执行门不重新评价公司，只决定是否买、买多少、替代谁以及如何分批。

```text
第零步：数据、能力圈、类型标签、一票否决
    ↓
第一步：好公司八维分析
    ↓
茅台质量对标
    ↓
第二步：好价格与目标收益倒算
    ↓
茅台收益对标
    ↓
组合执行门
```

### 可复现性的边界

不同Agent必须一致的部分：

- 数据截止日、币种、复权口径；
- 历史财务数据及计算公式；
- 事实、计算、假设、判断的标签；
- 公司类型和使用的主估值模型；
- 5年与10年目标收益率；
- 情景计算方法、税费口径和买入档位；
- 最终报告结构。

允许存在差异的部分：

- 未来收入增长率；
- 正常化利润率；
- 分红率、回购与再投资回报；
- 终值倍数；
- 风险发生概率。

上述判断性参数必须逐项列示依据。禁止只给结论、不公开假设。

## 二、用户目标与统一收益门槛

### 既定目标

- 投资本金：1,000万元；
- 5年2倍：要求年化总回报 **14.87%**；
- 10年5倍：要求年化总回报 **17.46%**；
- 长期被动股息目标：每年100万元，并具有可持续增长能力；
- 生活支出由投资本金之外的收入承担。

### 所有公司统一输出四种价格

| 价格名称 | 基准情景要求 | 含义 |
|---|---:|---|
| 合理持有价 P10 | 10年年化总回报10% | 可以持有，不代表适合新增 |
| 初始建仓价 P12 | 10年年化总回报12% | 有一定安全边际，可小仓 |
| 优秀买入价 P15 | 10年年化总回报15% | 可进入正常仓位 |
| 目标达成价 P17.46 | 10年年化总回报17.46% | 单项投资满足10年5倍目标 |

5年情景也必须计算，但买入价格以10年模型为主，5年模型用于检查估值回归依赖程度。

### 投资标签

- **目标达成型**：基准情景10年IRR ≥ 17.46%；
- **接近目标型**：15% ≤ 基准IRR < 17.46%；
- **组合辅助型**：10% ≤ 基准IRR < 15%，必须说明股息、防守或分散作用及其对组合目标的拖累；
- **回报不合格**：基准IRR < 10%，不投入新增资金；
- **无法定价**：关键数据或经营假设不可验证。

不能把组合辅助型公司写成“能够实现10年5倍”。低于17.46%的仓位必须由其他更高预期回报资产补偿，否则组合数学上无法达标。

## 三、第零步：研究准备

### 1. 输入信息

研究开始前必须确认：

| 字段 | 要求 |
|---|---|
| 公司 | 全称、股票代码、交易所 |
| 研究日期 | 精确到日期 |
| 当前价格 | 价格、时间、币种、是否复权/除息 |
| 汇率 | 港股或海外股票必须注明汇率日期 |
| 当前持仓 | 股数、成本、市场价值；未知则写“未提供” |
| 总投资本金 | 默认1,000万元；如有更新按最新输入 |
| 比较基准 | 默认贵州茅台，同时可增加同行龙头 |

### 2. 信息丰富度

| 等级 | 标准 | 处理 |
|---|---|---|
| A | 至少5年完整财报、最新报告、行业与竞争数据充分 | 正常分析，警惕市场共识偏见 |
| B | 只有3—5年数据或部分分部数据缺失 | 所有推算标记，结论最高为“中等置信” |
| C | 少于3年可靠数据、关键经营指标不可得 | 不强行填表，结论为“数据不足/观察” |

信息丰富度只代表AI研究能力，不代表投资确定性。

### 3. 数据来源优先级

#### 公司事实

1. 交易所公告、公司年报、中报、季报；
2. 公司投资者关系材料和业绩会记录；
3. 监管机构、行业协会、政府统计；
4. 独立金融数据库；
5. 券商报告；
6. 新闻和社交平台只用于发现线索，不单独作为关键结论依据。

#### 市场数据

- A股：交易所/行情接口 + 东方财富等独立来源；
- 港股：港交所披露易/行情 + AAStocks等独立来源；
- 美股：SEC/交易所行情 + StockAnalysis、Macrotrends等独立来源。

### 4. 双来源核验

以下关键数据必须至少两个来源，其中一个尽量为原始公告：

- 当前股价、总股本、市值；
- 收入、归母净利润、扣非利润；
- 经营现金流、资本开支、自由现金流；
- 现金、有息负债、净资产；
- 分红、回购注销、股本稀释；
- 关键市场份额和海外收入。

误差计算：

```text
误差率 = |来源A - 来源B| ÷ |来源A|
```

| 误差 | 处理 |
|---:|---|
| ≤1% | 视为一致，使用原始公告数据 |
| 1%—5% | 标注差异并解释口径 |
| >5% | 回到原始报告核实；未解决前停止估值 |

### 5. 标签纪律

报告中的重要数字和结论使用以下标签：

- `[事实]`：原始资料直接披露；
- `[计算]`：由已披露数据按明确公式计算；
- `[假设]`：用于未来预测的输入；
- `[判断]`：根据事实和假设形成的结论；
- `[缺失]`：没有可靠数据；
- `[争议]`：不同来源或口径无法完全统一。

严禁把假设写成事实，严禁用“预计”“大概率”掩盖数据缺失。

### 6. 历史区间

- 默认收集10个完整财年；不足时至少5年；
- 周期公司至少覆盖一个完整景气周期，优先7—10年；
- 同时加入最新中报/季报和TTM；
- 竞争对手至少比较最近3年；
- 使用追溯调整后的同口径数据。

### 7. 公司类型：一个主类型 + 多个风险标签

禁止仅凭“高分红”“成长”给公司单一贴标签。先选择一个主估值类型，再添加风险标签。

| 主类型 | 典型公司 | 主估值方法 |
|---|---|---|
| 稳定消费/医药质量型 | 茅台、东阿阿胶、迈瑞 | 所有者收益/FCF折现 + 正常PE |
| 平台与成长型 | 腾讯、泡泡玛特 | 分阶段FCF/每股收益模型 + 反向DCF |
| 成熟制造型 | 格力、福耀、宇通 | 中周期每股收益/FCF + 股息 + 正常PE |
| 强周期/资源型 | 万华及资源品公司 | 中周期利润、资产负债表、EV/EBITDA或NAV |
| 银行/券商 | 招行、中信证券 | 正常化ROE、账面价值、剩余收益/PB |
| 保险 | 中国平安 | 营运利润、内含价值、投资资产压力测试 |
| 资产经营/公用事业 | 小商品城、长江电力 | 分部资产价值/现金流折现 + 分红能力 |

风险标签可多选：地产相关、监管、单一客户、关键人物、汇率、海外政治、技术替代、高杠杆、原材料、渠道库存、资本开支、并购整合。

### 8. 能力圈测试

必须用不超过200字回答：

1. 公司向谁收钱；
2. 客户为什么持续付钱；
3. 哪三个变量决定利润；
4. 十年后大概率还在做什么。

不能清楚回答，结论为“能力圈不足”，停止分析，不进入第一步。

## 四、一票否决与研究暂停

### 永久或结构性否决

命中任一项，结论为D类，不进入估值：

- 经监管或司法确认的重大财务造假、资金占用、利益输送，且治理没有完成可信重建；
- 管理层持续系统性欺骗，关键承诺与事实反复冲突；
- 商业模式主要依赖违法、不可持续补贴或后续投资者接盘；
- 中小股东无法分享企业价值，且控制股东长期侵占价值；
- 竞争优势已被不可逆摧毁，企业只能持续低于资本成本经营。

### 暂停研究或暂不买入

以下情况不是永久拉黑，但必须停止给出买入价：

- 最新审计意见为否定或无法表示意见；
- 关键财务数据双来源差异超过5%且无法解释；
- 出现重大监管、诉讼、债务、产品安全事件，影响尚无法量化；
- 流动性或偿债风险可能迫使公司增发、贱卖资产；
- 最新财报尚未披露，旧数据已经不足以代表当前经营；
- 重大并购、重组或业务转型导致历史数据失去可比性。

暂停状态必须列出恢复研究所需证据。

## 五、第一步：好公司八维分析

每个维度必须输出五项：

1. 核心问题；
2. 至少两项支持证据；
3. 至少一项反方证据；
4. 可观察指标；
5. 结论：`通过 / 存疑 / 不通过 / 中性不适用`。

不使用数字总分。

### 维度1：业务聚焦与战略一致性

**核心问题**：公司是否把资本和管理精力放在具有共同能力的业务上？

必查数据：

- 各分部收入、营业利润、资产和资本开支；
- 核心业务利润与自由现金流占比；
- 过去10年并购、处置和跨界投入；
- 亏损新业务累计投入及未来承诺。

判定规则：

- **通过**：核心利润来源清晰；各主要业务至少共享客户、品牌、渠道、技术、数据或供应链中的两项；过去5年不存在持续吞噬价值的无关扩张；
- **存疑**：新业务有协同逻辑但尚未证明回报，或重大并购仍处整合期；
- **不通过**：说不清主要赚钱方式；无关业务连续3年亏损或长期低于资本成本，管理层仍持续投入；
- **注意**：主业收入占比80%只能作为事实，不能单独决定结论。

### 维度2：企业文化、诚信与治理

**核心问题**：管理层在没人监督时，会不会正确对待客户、员工、供应商和股东？

必查证据：

- 历年承诺与兑现记录；
- 审计意见、监管处罚、财务重述；
- 关联交易、薪酬、激励和大股东资金往来；
- 产品安全、客户赔偿、供应商账期；
- 核心人员流失、接班安排和坏消息披露。

判定规则：

- **通过**：没有重大诚信污点；承诺大体兑现；关联交易透明合理；愿意披露坏消息；
- **存疑**：存在关键人物依赖、激励偏宽松或个别治理争议，但没有证据显示系统性侵害；
- **不通过**：重大欺骗、侵占、反复修改口径掩盖问题或系统性损害中小股东；
- 诚信不通过直接触发一票否决。

### 维度3：护城河及变化方向

**核心问题**：客户为什么不换、竞争者为什么难以复制、超额回报能持续多久？

逐项检查：

| 护城河 | 必须提供的证据 |
|---|---|
| 品牌/定价权 | 同类价格溢价、提价后量和份额变化、毛利率 |
| 转换成本 | 迁移成本、合同期限、流程嵌入、客户留存 |
| 网络效应 | 用户增长是否提高产品价值、双边网络密度 |
| 成本/规模 | 单位成本、采购、渠道、产能利用率相对同行 |
| 技术/工艺 | 专利不是充分条件，必须体现良率、性能、成本或认证优势 |
| 牌照/资源 | 稀缺性、期限、监管可撤销性 |

判定规则：

- **通过**：至少一条强护城河，并有两个以上量化证据；过去5年稳定或变宽；
- **存疑**：护城河存在但份额、价格溢价、留存或回报率出现混合信号；
- **不通过**：只能依靠价格竞争，或护城河出现不可逆侵蚀；
- 必须写出“什么能够摧毁这条护城河”。

### 维度4：国际化质量

**核心问题**：国际化是在增加长期价值，还是增加复杂性和风险？

必查数据：

- 海外收入、利润、资产、资本开支和现金流占比及5年变化；
- 自主品牌、代工、产能出海的结构；
- 海外ROIC与国内ROIC；
- 国家、客户、渠道和汇率集中度；
- 海外合规、制裁、关税和本地治理风险。

判定规则：

- **通过**：海外业务至少经历3年验证，利润与现金回报健康，ROIC高于资金成本，风险可控；
- **存疑**：收入增长但利润/现金流未验证，或国家与客户高度集中；
- **不通过**：连续价值毁灭、重大减值、持续低于资本成本且没有退出纪律；
- **中性不适用**：公司不需要国际化即可长期经营；不扣分，也不加分。

### 维度5：行业结构与竞争地位

**核心问题**：公司是否在真实竞争中持续胜出？

必查数据：

- 前三大竞争者、市场份额和3—5年变化；
- 公司与同行价格、毛利率、ROIC、库存和获客成本；
- 上游、下游议价权；
- 新进入者、替代品和政策变化；
- 行业供给退出、集中度和价格战历史。

判定规则：

- **通过**：份额或利润池占比稳定/提升，回报率优于同行，竞争优势不是靠长期降价维持；
- **存疑**：份额与利润率信号不一致，或新技术/新渠道尚未形成结论；
- **不通过**：连续3年以上份额和单位经济同时恶化，行业结构又没有改善路径；
- 必须用一句话说明“最优秀的竞争对手强在哪里”。

### 维度6：客户需求持续性与增长空间

**核心问题**：十年后谁还会付钱，付费人数、频次和客单价如何变化？

必须拆解：

```text
收入 = 客户数量 × 购买频次 × 客单价 × 公司份额
```

订阅/平台公司增加留存率和货币化率；制造业增加更新周期和保有量；银行增加客户资产、贷款需求和风险成本。

判定规则：

- **通过**：需求长期稳定或增长，且公司至少能通过量、价、频次、份额中的一项创造每股价值；
- **存疑**：行业成熟、高渗透、人口或代际形成压力，但更新、提价或份额仍可部分抵消；
- **不通过**：核心客户或使用场景结构性萎缩，公司没有定价、替代产品或市场扩张能力；
- 不得只引用TAM，必须说明公司如何获得利润。

### 维度7：分行业财务质量与资本回报

**核心问题**：利润是否真实、可持续，资产负债表能否穿越压力？

#### 所有非金融公司共同指标

| 指标 | 计算 |
|---|---|
| 每股收入/利润/FCF | 使用加权稀释股数，防止总量增长掩盖摊薄 |
| 现金转换率 | 5年累计经营现金流 ÷ 5年累计调整后净利润 |
| FCF转换率 | 5年累计自由现金流 ÷ 5年累计调整后净利润 |
| ROIC | NOPAT ÷ 平均投入资本，明确现金和商誉口径 |
| 杠杆 | 净债务/EBITDA、利息覆盖、短债/可用现金 |
| 营运质量 | 应收、存货、合同负债和应付相对收入变化 |
| 股本变化 | 5年稀释股数变化、回购注销、员工激励 |

参考判定，不机械跨行业套用：

- 5年累计经营现金流/调整后净利润 ≥ 0.8通常为健康；0.6—0.8需解释；<0.6且无合理营运周期解释为不通过；
- 5年平均ROIC显著高于资本成本并稳定为通过；仅略高为存疑；长期低于资本成本为不通过；
- 净债务/EBITDA <1.5倍通常健康，1.5—3倍需结合稳定性，>3倍必须压力测试；
- 五年稀释超过10%且没有相应每股价值增长，通常不通过。

#### 成熟制造/周期企业追加指标

- 中周期毛利率和营业利润率，不用峰值；
- 维持性与扩张性资本开支；
- 产能利用率、库存跌价、应收和客户集中；
- 原材料、汇率和海外工厂压力测试。

#### 银行/券商

- 5—10年正常化ROE及波动；
- 净息差/手续费率、成本收入比；
- 不良生成率、关注类贷款、拨备覆盖、信用成本；
- 核心一级资本充足率及监管缓冲；
- 资产结构、房地产和地方融资暴露；
- 券商使用中周期ROE，不能使用牛市峰值利润。

#### 保险

- 营运利润和自由盈余；
- 新业务价值及其假设质量；
- 内含价值、合同服务边际；
- 综合/核心偿付能力；
- 投资资产信用、权益、地产和利率敏感性；
- 代理人数量、产能、退保和继续率。

判定规则：

- **通过**：完整周期内每股价值增长、现金/资本质量健康、杠杆可控，无重要趋势恶化；
- **存疑**：整体健康但一个关键指标连续恶化，或行业周期尚未验证；
- **不通过**：利润与现金/资本长期背离、杠杆可能导致被迫融资、每股价值持续被摊薄；
- FCF收益率、PE、PB和股息率属于第二步，不得在本维度参与好公司判断。

### 维度8：管理层与资本配置

**核心问题**：公司赚到的钱如何分配，是否增加每股内在价值？

必须制作过去5—10年资本配置表：

| 用途 | 累计金额 | 结果 |
|---|---:|---|
| 主业再投资 |  | 增量利润、增量ROIC |
| 并购 |  | 商誉、减值、协同兑现 |
| 分红 |  | 分红率、稳定性、税后股息 |
| 回购 |  | 回购价格、是否注销、股本变化 |
| 偿债/现金 |  | 财务弹性变化 |
| 员工激励/增发 |  | 摊薄及业绩条件 |

判定规则：

- **通过**：资本优先流向高回报再投资；无高回报机会时分红或低价注销式回购；并购克制；每股价值增长；
- **存疑**：再投资回报平庸、回购价格偏高、激励宽松或接班尚未验证；
- **不通过**：反复高价并购、低价增发、高价回购、关联输送或长期囤积低收益资产；
- 回购只有在低于内在价值且注销或真正抵消摊薄时才计入股东回报。

## 八、第二步：好价格

只有A类和B类公司进入本步骤。

### 1. 建立正常化盈利基准

禁止机械采用“TTM与三年均值孰低”。Agent必须根据主类型重建正常化经营：

#### 稳定消费/平台

```text
收入 = 用户/销量 × 频次 × 价格 × 份额
经营利润 = 收入 × 正常化利润率
所有者收益 = 税后经营利润 + 非现金费用 - 维持性资本开支 - 正常营运资本投入
```

#### 成熟制造

- 使用中周期销量、价格、原材料和产能利用率；
- 区分维持性资本开支与扩张性资本开支；
- 海外工厂单独建模；
- 不能使用景气顶部利润对应的低PE。

#### 周期/资源

- 使用7—10年中周期价格、价差、开工率和利润率；
- 熊市检验资产负债表；
- 峰值利润只用于乐观情景，不进入基准。

#### 银行/券商

- 从期初每股净资产、正常化ROE、分红率和股本变化推演每股净资产；
- 银行纳入信用成本和资本约束；
- 券商使用中周期成交、投行和自营收益。

#### 保险

- 营运利润、内含价值和自由盈余分别建模；
- 压力测试投资收益、利率、信用损失、退保和偿付能力；
- 不直接把账面利润当作可分配现金。

### 2. 三情景统一要求

每家公司建立悲观、基准、乐观三个情景，分别给出5年和10年：

| 参数 | 悲观 | 基准 | 乐观 | 依据 |
|---|---:|---:|---:|---|
| 收入/客户增长 |  |  |  |  |
| 利润率/ROE |  |  |  |  |
| 再投资回报 |  |  |  |  |
| 分红率 |  |  |  |  |
| 净回购/稀释 |  |  |  |  |
| 终值倍数 |  |  |  |  |
| 税费 |  |  |  |  |

情景纪律：

- 悲观情景必须是合理压力，不是世界末日；
- 基准情景不得自动采用管理层或卖方预测；
- 乐观情景仍需符合市场容量、资本需求和竞争约束；
- 分红、回购和股本变化不得重复计算；
- 港股红利税、交易渠道税费和汇率影响必须按用户实际渠道核验并给出税前、税后两套结果；
- 所有计算保留完整精度，最终展示时再四舍五入。

### 3. 目标收益率倒算公式

以每股口径为主：

```text
P(r,n) = Σ[DPS_t ÷ (1+r)^t] + 终值_n ÷ (1+r)^n

终值_n = 正常化每股指标_n × 终值倍数
```

其中：

- `r`分别为10%、12%、15%、17.46%；
- `n`主要使用10年，同时计算5年；
- 普通公司终值指标可为EPS或FCF；
- 银行使用期末BPS×合理PB或剩余收益终值；
- 保险使用内含价值/营运利润/自由盈余的适用终值；
- 净回购通过未来稀释股数影响每股指标，不得再额外加一次回购收益；
- 如果使用总市值模型，必须最后除以同期预计稀释股数。

当前价格预期IRR通过求解下式获得：

```text
当前价 = Σ[DPS_t ÷ (1+IRR)^t] + 终值_n ÷ (1+IRR)^n
```

必须使用计算器或程序求解，禁止心算。

### 4. 主估值与交叉验证

| 类型 | 主模型 | 交叉验证 |
|---|---|---|
| 稳定消费/医药 | 所有者收益/FCF折现 | 正常PE、股息率、反向DCF |
| 平台成长 | 分阶段FCF/每股收益模型 | 反向DCF、PEG仅作辅助 |
| 成熟制造 | 中周期EPS/FCF + 股息 | 正常PE、EV/EBITDA、资产负债表 |
| 周期资源 | 中周期利润/NAV | EV/EBITDA、PB、周期分位 |
| 银行/券商 | 剩余收益或PB-ROE-Gordon | 股息折现、历史PB |
| 保险 | 内含价值/营运利润/自由盈余 | PB、股息、投资资产压力测试 |
| 资产经营/公用事业 | 分部DCF/NAV | 股息率、资产重置价值 |

PB-ROE交叉验证采用：

```text
合理P/B = (可持续ROE - g) ÷ (股权成本 - g)
```

只有在`g < 股权成本`且ROE、分红率可持续时使用。`g`必须与留存率和再投资回报一致。

禁止事项：

- 禁止用PR直接决定目标PE；
- 禁止把PE、PEG、PR、TRR、历史分位当作五个独立证据重复加权；
- 禁止用周期峰值利润计算“低PE”；
- 禁止只因为低PB就判断银行或保险便宜；
- 禁止选取最乐观模型作为最终价值。

如主模型与交叉验证的合理价值差异超过20%，必须解释；无法解释则降低置信度或停止给出买入价。

### 5. 安全边际

```text
安全边际 = 1 - 当前价格 ÷ 基准情景P10
```

必须同时输出：

- 当前价格相对P10的折价；
- 悲观情景5年、10年IRR；
- 悲观情景最大阶段性回撤估计；
- 利润下降与终值倍数压缩同时发生的结果；
- 股息削减后的现金回报。

行动参考：

- 初始建仓至少达到P12；
- 正常加仓优先达到P15；
- P17.46属于目标级机会，但仍受公司质量和仓位上限约束；
- 悲观情景5年总回报为负不自动否决，但必须说明永久损失概率和仓位折扣；
- 如果估值结果高度依赖终值倍数扩张，结论不得高于“观察”。

### 6. 固定价格输出表

| 项目 | 悲观 | 基准 | 乐观 |
|---|---:|---:|---:|
| 正常化每股收益/FCF/BPS |  |  |  |
| 5年累计税后股息 |  |  |  |
| 10年累计税后股息 |  |  |  |

### 7. 最强反方与最可能错误

估值完成后必须以聪明的非买方身份回答：

- 为什么市场只给当前估值；
- 哪个会计数字最可能误导；
- 哪个增长假设最脆弱；
- 如果股价5年不涨，最可能是什么原因；
- 本分析最可能错在哪里；
- 哪三个指标能最早证明分析错误。

## 十、组合执行门

### 1. 组合角色

每家公司只能选择一个主角色：

- 核心复利；
- 高增长；
- 稳定股息；
- 周期反转；
- 风险分散；
- 观察仓。

必须说明它替代谁，或为什么是新增独立角色。

### 2. 默认仓位上限

在没有用户特别调整时使用：

| 公司分类 | 首次仓位 | 正常上限 | 硬上限 |
|---|---:|---:|---:|
| A类 + 目标达成型 | 3%—5% | 10%—15% | 20% |
| A类 + 组合辅助型 | 2%—3% | 5%—8% | 10% |
| B类 | 1%—2% | 3%—5% | 8% |
| C类 | 0%—1%观察仓 | 2% | 2% |
| D类 | 0% | 0% | 0% |

任何单股超过20%必须单独完成集中度压力测试；25%为默认绝对硬约束，除非用户明确修改投资政策。

### 3. 分档建仓

默认按照最终目标仓位的累计比例执行：

| 价格 | 累计达到目标仓位的比例 |
|---|---:|
| ≤P12 | 25% |
| ≤P15 | 60% |
| ≤P17.46 | 100% |

“累计仓位”包含已有持仓，不能把每档金额重复相加。实际下单数量按交易单位向下取整，港币股票须注明汇率和交易费用。

### 4. 暂停加仓条件

每家公司至少设置3个公司特定指标，并包括：

- 最新财报使基准正常化利润下调超过10%；
- 核心护城河指标连续两个报告期恶化；
- 资产负债表、审计、监管或管理层发生重大变化；
- 价格下降但内在价值下降幅度更大；
- 组合相关风险已经超过上限。

价格下跌本身不是加仓理由。

### 5. 卖出与减仓规则

买入时写死条件，不写死永久绝对价格。

**必须卖出/退出审查：**

- 命中一票否决；
- 核心投资论文被事实破坏；
- 护城河不可逆恶化；
- 管理层诚信或重大治理问题；
- 财务风险可能造成永久损失。

**估值减仓审查：**

- 使用最新财报更新模型后，未来10年基准IRR低于6%；
- 同时存在质量相当、基准IRR高至少5个百分点的替代机会；
- 考虑税费、股息损失和再投资风险后仍值得切换；
- 或单股/相关风险超过组合硬上限。

估值高不自动清仓，必须使用更新后的内在价值和机会成本。

> 我愿意在___元买入___，因为它向___客户提供___，客户持续付费的原因是___。它最可靠的护城河是___，目前正在___。管理层在资本配置上的记录是___。基准情景10年税后IRR为___，悲观情景为___。我最可能错在___；如果___发生，我将停止加仓或退出。

无法在200字内写清楚，不买。

### 置信度

- 数据置信度：高/中/低；
- 生意质量确定性：高/中/低；
- 估值确定性：高/中/低；
- 关键缺失数据；
- 哪些结论是事实，哪些是推断。

### 数据来源与审计

- 关键来源逐条列出；
- 双来源误差记录；
- 计算工具和日期；
- 未解决的数据差异。

## 十三、Agent执行硬规则

### 必须做到

1. 先确认当前日期并刷新最新股价和财报；
2. 关键财务数据双来源核验；
3. 明确区分事实、计算、假设和判断；
4. 所有估值使用程序或计算器；
5. 输出5年和10年、悲观/基准/乐观；
6. 股息按用户实际税务和交易渠道计算；
7. 使用每股数据，纳入回购和稀释；
8. 将公司质量和价格分开下结论；
9. 给出明确买价、仓位、暂停和退出条件；
10. 写出最强反方和分析最可能错在哪里。

### 禁止事项

1. 禁止使用过期价格直接下单；
2. 禁止只引用卖方一致预期；
3. 禁止把TTM峰值利润当正常利润；
4. 禁止跨行业使用统一毛利率、ROCE或FCF标准；
5. 禁止把PE、PEG、PR、TRR重复当作独立证据；
6. 禁止因低PE、低PB或高股息单独认定便宜；
7. 禁止把市占率、品牌知名度直接等同护城河；
8. 禁止因国际化收入增长忽略海外利润和ROIC；
9. 禁止给没有数据支持的精确预测；
10. 禁止以“长期看好”“等待机会”代替价格和触发条件；
11. 禁止写死永久卖出价格；
12. 禁止为了得出“可以买”而反向调整增长和终值假设。

## 十五、框架自身的复盘规则

本框架不是永久不变。出现以下情况应修订版本：

- 连续三家公司在同一维度出现无法执行或明显误判；
- 实际投资结果与基准情景长期偏差，且来自同一个模型假设；
- 会计准则、税收、交易制度或监管环境重大变化；
- 组合目标或风险承受能力改变；
- 新证据表明某一硬门槛过严或过松。

每次修订必须说明：修改内容、修改原因、影响哪些历史结论。禁止为了证明过去买入正确而修改标准。
