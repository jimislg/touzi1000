## 框架定位：两个隔离的层次

**前三步 = 独立个股研究**（不因组合缺口降低标准）：
1. 公司所处细分市场的需求、利润池和范式风险是什么？
2. 它是不是一家值得长期持有的好公司？
3. 当前价格能否提供足够回报和安全边际？

**第四步 = 分两段，触发条件不同（v3.4.6 修正）**：
- **前四节（组合基线 / 机会成本 / 纳入前后成果 / 风险去重）**：只在**拟纳入/加仓/减仓/替换**时执行。第四步只评估边际组合效果，**不得反向修改前三步已冻结的市场三轴判断、公司分类、经营假设和估值参数**。第四步不合格的结论是"不纳入组合"，不是回头改前三步。
- **后两节（仓位与建仓表 / 暂停与退出）**：**无条件输出，任何结论都要给**。"不买"的标的给**预案版**（触发价 + 证据门 + 分档仓位 + 暂停 + 退出），"可买"的给**可执行版**。**不写预案版＝报告未完成，不得推送**——理由见 §6.2。

### 两种运行模式

- **快筛模式**：只执行第零步+第一步+否决检查，输出"继续/补数据/停止"资格卡；**用户确认后再进第二、三步**（符合郎刚"分析→确认→存档"习惯）。
- **完整研究模式**：用户明确要求时连续执行；第零步和第一步结束后自动执行内部闸门，只有命中停止条件才暂停。

### 可复现性边界

必须一致：数据截止日/币种/复权口径、历史财务与公式、标签、主类型与主估值模型、5/10年目标收益率、情景计算方法与税费口径、H档位、第四步组合基线、报告结构。
允许差异（必须逐项列依据）：未来增长率、正常化利润率、分红/回购、终值倍数、风险概率。禁止只给结论不公开假设。

## 0. 结论形成前的三道强制闸（v3.4.9，腾讯暴露）

**跑法**：`python3 scripts/precheck.py class|inputs|fx ...`，输出**原样贴进报告第一节**。任何一道 FAIL，不得进入报告写作。

**为什么放在最前面**：本技能原有自检全部在"交付前"（§10.4 / 交付清单）。**而腾讯这一轮的全部错误都发生在"交付之前之前"——在结论形成的那一刻。** 交付前的自检只能抓算术和格式，抓不到"框架装错了"，因为到那时框架已经是既成事实，改分类等于重写全文。**所以闸门必须前置到写第一个价格之前。**

### 0.1 分类是计数，不是判断

| 分类 | 规则原文 |
|---|---|
| A | 无核心"不通过"；核心"存疑" **≤1**；护城河与财务均明确通过；无否决项 |
| B | 无核心"不通过"；核心"存疑" **≤2**；护城河与财务不得同时存疑 |

**存疑数 = 1 时，A 与 B 的条件同时成立。** 此时必须判 **A**，因为 B 只是 A 的超集——**更宽的条件不等于更严格的标准**。

**腾讯实测（本轮最贵的一个错）**：核心六维只存疑 1 个（第 5 维），护城河与财务均明确通过 → **机械分类 = A 类**。我写成 B 类，理由是"第 5 维弱"。

**这个错的性质不是"数错了"，是"以为自己在保守"**：
- 选 B 时的心理是"要求更严一点更稳妥"；
- 但 B 类的仓位硬上限是 **8%**，A 类是 **20%**；
- 于是"保守地降一档"的直接后果是：把 **12.8% 判成超配 60%、建议卖出 48 万**。

**方向上是谨慎，后果上是激进。** 一个"更小心"的选择，产出了一个要卖掉好公司四成仓位的动作。**这类错误无法靠"再仔细一点"避免，只能靠计数。**

**硬规则**：
1. 报告必须写出「核心六维各自判定 + 存疑 N 个」这个计数，**N ≤1 且护城河/财务均通过 → 必须判 A**；
2. 要降 B，**只能**因为"存疑 = 2"或"护城河与财务不能同时存疑"或"命中最低硬规则"，**不得写"因为第 5 维弱"**；
3. `precheck.py class --claim X` 必须在报告写作前跑过，输出贴在分类结论旁。

### 0.2 输入清单：默认值不得静默生效

**腾讯实测**：唐朝法与四步法两版报告**全部按零持仓写**，直到用户说"**继续**加仓"才知道实持 12.8%、成本 404。

根因不是疏忽，是**报告模板里没有"缺失输入"这个位置**。模板有市场三轴、八维、H 档、仓位表，缺的输入不会显示为空白，会显示为一个默认值——**而默认值看起来和有依据的值一模一样。**

**硬规则**：报告第一节必须列全六项——总资金基数 / 本标的持仓市值 / 成本价 / 现价 / 可动用现金 / 汇率。缺项写成：

> 「未知（默认 X，若实际为 Y 则结论变为 Z）」

**禁止只写默认值不写这句话。** `precheck.py inputs` 缺项即 FAIL（exit 1）。

### 0.3 跨币种扰动自检

报表币 ≠ 交易币时（腾讯：RMB 报表 / HKD 交易），**H 档终值必须 ÷FXR 才能与 HKD 股息相加**。本轮的错：漏除 0.875 → H12 从 464.43 错成 410.41，两法差从 +53.0%（v3.4.10 修正后口径为 +63.2%）错成 +35.2%，**还把"方向相反"错读成"方向一致"**。

**判据**：把 FXR 在 ±3% 内取三点重跑，**两个价格必须同向变动，IRR 必须一格不动**。IRR 若随 FXR 变，说明汇率被塞进了现金流序列，而不是只换展示币种。

### 0.4 为什么必须前置：错误只在"与先验相反"时才被发现

**这是本轮最该记住的一条，也是前面三条闸门存在的理由。**

腾讯这轮共八处错误，逐个数它们的方向：

| 错误 | 错后的方向 | 谁发现的 |
|---|---|---|
| 零持仓假设 | 结论变成"不买"（更看空） | 用户 |
| 分类判 B（应为 A） | 仓位上限 8% → "该减 48 万"（更看空） | 用户 |
| capex 在第 5 维二次惩罚 | 分类更低（更看空） | 用户 |
| H 档终值漏 ÷FXR | H12 更小（更看空） | 我自己（复算时发现两个数太巧） |
| 分解标签"四步法倍数只有 79%" | 让 53% 的差显得合理（**消解了追问**） | 我自己（复算 k_B） |
| 用整体 PE 而非 SOTP | **原式矩阵说便宜 26.8%**（更看多） | **我自己，且只有这一处是我主动发现的** |
| 看空报告无仓位表 | 结论更薄（更看空） | 用户 |
| 两版报告未问持仓 | 结论按空仓（更看空） | 用户 |

**规律是可验证的：与"更看空"同向的六处，五处由用户指出；唯一一处与先验相反（整体 PE 说"便宜"）的，我自己立刻发现了。**

**这不是巧合，是检查机制的结构缺陷——我不会去查一个"结论符合预期"的数字。** 错误的方向如果和我的先验一致，它就不触发任何怀疑。

**硬规则（v3.4.9）**：

1. 报告必须在估值段之前，**明确写出自己当时的先验倾向**（偏贵 / 偏便宜 / 中性），并说明理由一句话；
2. 然后列出**所有"支持该先验"的计算步骤**，对每一处做反向扰动：关键参数往反方向推 20–30%（现金流口径、退出倍数、汇率、分类档位），看结论是否翻转；
3. **与先验同向的步骤是检查盲区**，必须逐个点名。腾讯的三处盲区是：FCF 用 992 而非 1,751、H 档终值 ÷FXR、分类降 B——其中两处实际是错的。
4. 报告必须写一句「**如果这个结论错了，最可能是哪一步错了**」。这句不是免责，是把检查成本交给读者——**因为我自己在这一步上是不可靠的。**

**诚实的部分**：这八处错误里，**没有一处是靠"我下次注意"能避免的**。前置闸门能拦的是可计数的（分类、输入、汇率），拦不住的是"我看不到自己没在看的地方"。所以第 4 条那句子，是这套机制里唯一对读者有用的东西。

## 分析流程（严格顺序，不可颠倒）

```text
第零步  研究准备：数据、能力圈、主类型、一票否决
    ↓
第一步  细分市场三轴：需求轴 / 利润池轴 / 范式风险 → 参数传导 + 风险去重表
    ↓  （三轴结论强制传导至后两步）
第二步  好公司八维分析（不打分，只判定）→ A/B/C/D
    ↓
        质量双重对标（茅台 + 最优秀直接竞争者，禁谈价格）
    ↓
第三步  好价格：估值审计门 → 正常化盈利 → 三情景+权重 → 概率加权期末财富
        → 经济价值区间（10%/12%资本成本）→ H10/H12/H15/H17.46
        → A/H双门槛 → 压力测试 → 最强反方
    ↓
        茅台收益对标（观察池闸门四选一）
    ↓
        若 A/B 类 → 触发唐朝估值法（tangchao-valuation，独立报告，含价格区间图）
    ↓
A/B类进入观察池；C/D类停止
    ↓（前四节仅拟交易时触发；后两节无条件输出）
第四步  组合适配：三重机会成本 → 纳入前后成果测算 → 股息路径 → 仓位与去重 → 结论四选一
```

## 第零步：研究准备

### 1. 输入信息（缺一不可）

| 字段 | 要求 |
|---|---|
| 公司 | 全称、代码、交易所 |
| 研究日期 | 精确到日 |
| 当前价格 | 价格 + 时间戳 + 币种 + 是否复权/除息 |
| 汇率 | 港股/海外必须注明汇率日期与来源 |
| **多上市地** | 如有A/H/其他上市地：换股比例、权利差异、各市场价格 |
| 当前持仓 | 股数、成本、市值；未知写"未提供" |
| 投资本金 | 默认 1,000 万元 |
| 比较基准 | 默认贵州茅台，可加同行龙头 |

### 2. 信息丰富度

A：≥5年完整财报+最新报告+行业竞争数据充分→正常分析；B：3—5年或分部缺失→所有推算打标，结论最高"中等置信"；C：<3年或关键指标不可得→"数据不足/观察"。信息丰富度只代表研究能力，不代表投资确定性。

### 3. 数据获取

**优先 `neodata-financial-search`**（自然语言查询行情/财报/汇率/研报）：

```bash
cd ~/.workbuddy/plugins/cache/cb_teams_marketplace/finance-data/*/skills/neodata-financial-search
python3 scripts/query.py --query "中国海洋石油（00883.HK）最新股价、市盈率"
python3 scripts/query.py --query "HKDCNY 港元兑人民币 实时汇率报价"   # 汇率单独查，四位有效数字
```

降级顺序：`westock-data`（需 `bash scripts/setup.sh`）→ 交易所/公司IR原文（A股用交易所+东财，港股用披露易+AAStocks，美股用SEC+StockAnalysis）→ 公开检索。**禁止**混合多来源拼装同一字段，禁止用训练数据回答可实时查询的问题。

### 4. 双来源核验

以下字段必须≥2个来源，其一尽量为原始公告：股价、总股本、市值、收入、归母净利润、扣非利润、经营现金流、资本开支、自由现金流、现金、有息负债、净资产、分红与回购注销、股本稀释、关键市场份额与海外收入。**先对齐定义/期间/币种/复权/含税/合并范围，再算误差**：

```text
误差率 = |来源A − 来源B| ÷ |来源A|
```
≤1% 视为一致（用原始公告值）｜1%—5% 标注差异并解释口径｜**>5% 回到原始报告核实，未解决前停止估值**。口径不同的数据不得直接算误差；只能得到区间时用区间并降置信度，不得制造伪精确。

### 5. 标签纪律

`[事实]` 原始披露 ｜ `[计算]` 明确公式得出 ｜ `[假设]` 未来预测输入 ｜ `[判断]` 结论 ｜ `[缺失]` 无可靠数据 ｜ `[争议]` 口径无法统一。严禁把假设写成事实，严禁用"预计""大概率"掩盖数据缺失。

### 6. 历史区间

默认10个完整财年（不足则≥5年）；周期公司至少覆盖一个完整景气周期（优先7—10年）；叠加最新中报/季报与TTM；对手至少比最近3年；用追溯调整后同口径数据。

### 7. 公司主类型（1个主类型 + 多个风险标签）

| 主类型 | 典型 | 主估值方法 |
|---|---|---|
| 稳定消费/医药质量型 | 茅台、东阿阿胶、迈瑞 | 所有者收益/FCF折现 + 正常PE |
| 平台与成长型 | 腾讯、泡泡玛特 | 分阶段FCF/每股收益模型 + 反向DCF |
| 成熟制造型 | 格力、福耀、宇通 | 中周期EPS/FCF + 股息 + 正常PE |
| 强周期/资源型 | 万华、中海油及资源品 | 中周期利润、资产负债表、EV/EBITDA或NAV |
| 银行/券商 | 招行、中信证券 | 正常化ROE、账面价值、剩余收益/PB |
| 保险 | 中国平安 | 营运利润、内含价值、投资资产压力测试 |
| 资产经营/公用事业 | 小商品城、长江电力 | 分部资产价值/现金流折现 + 分红能力 |

判型辅助决策树（判据优先级：周期波动性 > 分红结构 > 成长阶段）：金融/保险？→金融型；价格/需求年度波动>30%且重资产？→周期资源型；分红率>70%且ROE高位？→高分红强周期型（警惕大额分红抽干净资产造成的ROE假象）；利润1—3年暴增>50%？→成长型；其余→稳定质量型。

风险标签可多选：地产相关、监管、单一客户、关键人物、汇率、海外政治、技术替代、高杠杆、原材料、渠道库存、资本开支、并购整合。

### 8. 能力圈测试（≤200字）

1. 公司向谁收钱；2. 客户为什么持续付钱；3. 哪三个变量决定利润；4. 十年后大概率还在做什么。答不清→"能力圈不足"，停止。

## 一票否决与研究暂停

**永久否决（命中即D类，不进估值）**：监管/司法确认的重大财务造假、资金占用、利益输送且治理未重建；管理层持续系统性欺骗；商业模式依赖违法/不可持续补贴/后续投资者接盘；中小股东无法分享价值且控制股东长期侵占；竞争优势被不可逆摧毁。

**暂停（不是拉黑，停止给出买入价）**：审计否定/无法表示意见；关键数据双源差异>5%未解决；重大监管/诉讼/债务/产品安全事件影响不可量化；流动性或偿债风险可能迫使增发贱卖；旧数据已不代表当前经营；重大并购重组致历史数据不可比。暂停必须列出恢复研究所需证据。

## 第一步：细分市场三轴（先于公司分析，不可跳过）

目的不是找抽象"好赛道"，而是看清需求方向、利润池变化和范式风险，并逐项传导。**禁止用一个"顺风/逆风"标签代替三个维度。**

**定义与边界**：按主要产品/服务划分（"食品饮料"不是细分，"酱油"才是）；明确替代品边界（技术断代风险来源）、价值链位置、利润池停在哪一环节。

### 三轴必答

| 轴 | 必查 | 结论三选一 |
|---|---|---|
| **需求轴** | 5—10年规模与增速（量价拆分）、驱动变量（人口/渗透率/技术/政策/习惯）、**结构性vs周期性裁决（必答，不得默认周期论）** | 结构增长 / 稳定 / 结构下降 |
| **利润池轴** | 集中度CR3/CR5与头部份额变化、产能供需分层（禁止全行业平均掩盖分化）、进入退出壁垒、竞争要素演变（价格→技术→服务→生态）、利润池扩大/被夺走向 | 改善 / 稳定 / 恶化 |
| **范式风险** | 替代品与技术断代、内卷与价格战烈度、监管税收政策、十年后细分市场存续与规模 | 低 / 中 / 高 |

**结构性机会**：新场景/新客户/新技术/政策红利；利润池迁移方向（量化或方向性证据）；谁最有能力吃下——不预设是目标公司。

**固定句式**：
> 该细分市场的需求轴为___，利润池轴为___，范式风险为___。最强竞争要素是___，最大结构性挑战是___。这些结论分别传导至销量/客户、价格、利润率、再投资、终值和情景概率如下：___。

### 参数传导表（硬性）

| 市场结论 | 第二步证据要求 | 第三步参数传导 |
|---|---|---|
| 需求结构增长 | 证明公司能获得增量，不得只引用TAM | 可反映到销量/客户，**不得自动提高终值倍数** |
| 需求稳定 | 正常验证份额、价格和复购 | 使用正常化量价与利润率 |
| 需求结构下降 | 客户需求与竞争地位各≥2项反证 | 下调销量/份额假设，增加结构下行情景 |
| 利润池改善 | 证明由供给退出/议价权/价值迁移驱动 | 可反映到利润率或ROIC，避免与增长重复计算 |
| 利润池恶化 | 解释价格战、成本转嫁、上下游挤压 | 下调利润率、再投资回报或情景权重 |
| 范式风险高 | 必答下一代技术/监管结构中的卡位 | **禁用历史PE中枢直接做终值；无卡位证据时乐观情景按悲观处理** |

### 终值纪律

需求结构下降或利润池恶化时，基准终值倍数不得高于三者最低：当前倍数、历史中周期合理倍数、由成熟期增长和资本回报支持的倍数。当前利润处于周期极端时先用正常化盈利再比较倍数。需求增长不得自动推导倍数扩张。终值占总价值比例过高必须披露并加敏感性。

### 风险去重表（同一风险不得四处重复惩罚）

| 风险 | 收入/利润率已反映 | 终值已反映 | 情景权重已反映 | 仓位再折扣 | 去重结论 |
|---|---|---|---|---|---|
| （示例）长期利差收窄 | 已下调正常化利润率 | 已用较低终值倍数 | 不再重复降权 | 仅处理金融暴露相关性 | 无重复 |

第四步仓位折扣只处理模型无法吸收的尾部风险、流动性、治理不确定性和组合相关性。

纪律：市场结论不替代公司判断（结构下降市场仍有好公司）；**禁止为支持买入结论改判三轴**；行业数据双来源核验，禁止只引用券商TAM（TAM非决策关键时标注"非决策关键数据"用区间）；行业判断标注[事实]/[计算]/[估计]/[争议]。

## 第二步：好公司八维分析

每维五项输出：核心问题 / ≥2项支持证据 / ≥1项反方证据 / 可观察指标 / 结论（通过/存疑/不通过/中性不适用）。**不使用数字总分。** 市场输入：需求结构下降时维度5和6各给≥2项反证；范式风险高时护城河维度必须回答卡位。

| # | 维度 | 核心问题 | 关键判定 |
|---|---|---|---|
| 1 | 业务聚焦与战略一致性 | 资本与管理精力是否放在具有共同能力的业务上 | 通过：核心利润来源清晰；主要业务共享客户/品牌/渠道/技术/数据/供应链中≥2项；近5年无持续吞噬价值的无关扩张。主业占比80%只是事实，不单独决定结论 |
| 2 | 企业文化、诚信与治理 | 没人监督时会不会正确对待利益相关方 | 通过：无重大诚信污点、承诺大体兑现、关联交易透明、愿披露坏消息。**诚信不通过→一票否决** |
| 3 | 护城河及变化方向 | 客户为什么不换、对手为什么难复制、超额回报能撑多久 | 逐项查：品牌定价权/转换成本/网络效应/成本规模/技术工艺/牌照资源。通过：≥1条强护城河+≥2个量化证据，近5年稳定或变宽。**必须写出"什么能摧毁它"** |
| 4 | 国际化质量 | 国际化在增加价值还是复杂性与风险 | 通过：≥3年验证、利润现金健康、ROIC高于资金成本。不需要国际化的判"中性不适用"，不加分不扣分 |
| 5 | 行业结构与竞争地位 | 是否在真实竞争中持续胜出 | 通过：份额或利润池占比稳定/提升、回报率优于同行、不靠长期降价。**必须说明"最优秀的竞争对手强在哪里"** |
| 6 | 客户需求持续性与增长空间 | 十年后谁还会付钱 | 收入=客户数×频次×客单价×份额。**不得只引用TAM** |
| 7 | 分行业财务质量与资本回报 | 利润是否真实可持续，资产负债表能否穿越压力 | **PE、PB、股息率、FCF收益率属于第三步，不得在本维度参与好公司判断** |
| 8 | 管理层与资本配置 | 赚到的钱如何分配，是否增加每股内在价值 | 必须做近5—10年资本配置表（再投资/并购/分红/回购/偿债/激励增发）。**回购只有低于内在价值且注销或真正抵消摊薄时才计入股东回报** |

### 维度7 工具清单（按行业取用，禁止跨行业机械套用）

**非金融公司**：每股指标用加权稀释股数；5年累计经营现金流÷调整后净利润（≥0.8健康、0.6—0.8需解释、<0.6不通过）；FCF转换率；ROIC显著高于资本成本；净债务/EBITDA（<1.5健康、1.5—3结合稳定性、>3必须压力测试）；营运质量；5年稀释超10%且无相应每股价值增长通常不通过。
**成熟制造/周期追加**：中周期毛利率与营业利润率（不用峰值）、维持性vs扩张性资本开支、产能利用率、原材料/汇率/海外工厂压力测试。
**银行/券商**：5—10年正常化ROE、净息差、不良生成率、拨备覆盖、核心一级资本充足率、地产与地方融资暴露；券商用中周期ROE不用牛市峰值。
**保险**：营运利润与自由盈余、NBV及假设质量、内含价值、偿付能力、投资资产敏感性、代理人产能与继续率。

| 分类 | 规则 | 后续动作 |
|---|---|---|
| **A 核心复利公司** | 无核心"不通过"；核心"存疑"≤1；护城河与财务均明确通过；无否决项 | 进入第三步，可作核心候选 |
| **B 优秀但有条件** | 无核心"不通过"；核心"存疑"≤2；护城河与财务不得同时存疑；风险可监控 | 进入第三步，明确条件与折扣 |
| **C 普通/看不清** | 核心"存疑"≥3，或护城河与财务均存疑 | 不投入新增资金，不进第四步；估值仅作研究参考 |
| **D 否决** | 任一核心维度不通过，或命中结构性否决 | 不投资 |

## 第三步：好价格（只有A/B类进入）

### 0. 估值口径与版本审计门（未全过不得输出正式经济价值与H档位）

0. **前置闸（写作之前，v3.4.9 无条件）**：`scripts/precheck.py class` 分类计数 + `inputs` 六项输入清单 + `fx` 跨币种扰动，三个输出原样贴进报告第一节；任一项 FAIL 不得开写。**同时写出自己的先验倾向与"如果这个结论错了最可能哪一步错"。**
1. **先锁定估值对象**：列明纳入估值的业务/资产/负债/表外义务及按零/负值/另行处理的项目；中途不得在"核心业务/核心生态/全公司"间切换口径，切换必须从头重跑；
2. **四座勾稽桥**：分部→合并；税前→所得税/少数股东/归母；归母÷稀释股本→EPS；经营现金流→维持性资本开支+营运资本→所有者收益/FCF。任一桥无法勾稽或差异>1%且无法解释→"无法定价"；
3. **四种EPS分栏**：年报/TTM/正常化/预测不得混用；引用PE必须写清价格日期、EPS截止期与种类，并验证 股价÷EPS=PE；
4. **三项恒等式**：股价÷EPS=PE；股价×稀释股本=市值；分部加总±抵销=合并；
5. **主模型必须有独立交叉验证**，差异>20%必须拆解原因，无法解释→停止输出正式买价；
6. **所有计算用程序并保留输入表**，禁止文字中心算；
7. **版本漂移归因**：新旧内在价值或任一买价变化>10%→输出"旧值—新值—变化额—归因"表（覆盖估值对象/基准盈利/增长率/利润率/税率/稀释/分红/终值）；
8. **旧价格线自动冻结**：新报告发布后旧报告标"已被复核替代"；
9. 审计门未全过可输出"研究草案/情景敏感性"，但**不得给正式经济价值或H档位**；仓位还必须通过第四步。

### 1. 正常化盈利基准（禁止机械采用"TTM与三年均值孰低"）

- **稳定消费/平台**：收入=用户/销量×频次×价格×份额；所有者收益=税后经营利润+非现金费用−维持性资本开支−正常营运资本投入
- **成熟制造**：中周期销量/价格/原材料/产能利用率；区分维持性与扩张性资本开支；海外工厂单独建模；**不得用景气顶部利润对应的低PE**
- **周期/资源**：7—10年中周期价格、价差、开工率、利润率；熊市检验资产负债表；**峰值利润只进乐观情景**
- **银行/券商**：期初BPS+正常化ROE+分红率+股本变化推演；银行纳入信用成本与资本约束
- **保险**：营运利润、内含价值、自由盈余分别建模；压力测试投资收益/利率/信用/退保/偿付能力；不把账面利润当可分配现金

### 2. 三情景 + 概率加权期末财富

悲观/基准/乐观 × 5年与10年，逐项列依据：收入或客户增长、利润率/ROE、再投资回报、分红率、净回购或稀释、终值倍数、税费、**情景权重（不是事实，标注为判断）**。

纪律：悲观是合理压力非世界末日；基准不得自动采用管理层或卖方预测；乐观仍须符合市场容量与竞争约束；**逐项执行第一步参数传导表**；分红/回购/股本变化不得重复计算；港股红利税与汇率按用户实际渠道核验，税前税后两套结果；计算保留完整精度。

**概率加权期末财富（辅助指标，禁止直接加权各情景IRR）**：
```text
概率加权期末财富 = Σ（情景权重 × 该情景期末总财富）
概率加权等效CAGR =（加权财富 ÷ 初始投入）^(1/年数) − 1
```
同时输出"悲观权重+10个百分点"敏感性。只有三个主观情景时不输出伪精确P(达成目标)；用"情景加权目标覆盖率"和"永久损失情景权重"。**禁止把三情景权重冒充统计概率。**

### 3. 目标收益率倒算（每股口径，程序求解禁止心算）

```text
P(r,n) = Σ[DPS_t ÷ (1+r)^t] + 终值_n ÷ (1+r)^n    终值_n = 正常化每股指标_n × 终值倍数
当前价IRR：解 当前价 = Σ[DPS_t ÷ (1+IRR)^t] + 终值_n ÷ (1+IRR)^n
```
r = 10%/12%/15%/17.46%；n主用10年同时算5年。银行用期末BPS×合理PB或剩余收益；保险用EV/营运利润/自由盈余适用终值；净回购通过稀释股数影响每股指标，不得再加一次回购收益；总市值模型最后除以同期预计稀释股数。

### 4. 经济价值区间与H档位（两组不同概念）

| 档位 | 基准情景要求 | 含义与动作 |
|---|---|---|
| **经济价值区间** | 保守经营现金流 + 统一资本成本 | 判断价值范围与安全边际；**保守经济价值取区间下沿** |
| **H10 回报门槛价** | 10年年化10% | 仅持有/机会成本参考，不等于内在价值 |
| **H12 初始关注价** | 10年年化12% | 最低新增资金门槛，可进入第四步小仓审查 |
| **H15 优秀机会价** | 10年年化15% | 正常仓位候选门槛 |
| **H17.46 目标机会价** | 10年年化17.46% | 目标级机会，仍须通过第四步 |

**统一资本成本规则**：默认基准折现率=10%；**B类、强周期、高杠杆或高范式风险=12%**；所有公司输出±1个百分点敏感性。`安全边际 = 1 − 当前价格 ÷ 保守经济价值`。H档位不得称为内在价值，H10不得作为唯一安全边际锚。

#### 4.1 H 档反解的三数纪律（v3.4.3 新增，恒隆暴露）

**反解出一个 H 档价格，不等于可以说"这只股票值这个价"。** 每报一个 H 档，必须同时给出三个数，缺一个就是口径不明：

| # | 数 | 算法 | 恒隆 H12 实测 |
|---|---|---|---|
| 1 | **反解价** | 按期末倍数折现回今天 | **4.35** |
| 2 | **买入隐含倍数** | 反解价 ÷ 当前 BPS | 4.35 ÷ 26.64 = **0.163** |
| 3 | **退出倍数** | 假设的期末倍数 | **0.232**（= 当前 PB，"不给溢价"） |

**为什么必须三个都给**：恒隆的档位表原本只写"PB 不变（0.232）"，读者会以为全篇没有倍数假设。实际买入端是 0.163、退出端才是 0.232——**"倍数不变"只对退出端成立，中间那 42% 的修复被标签藏掉了。**

**配套三条**：

1. **`买入隐含倍数 ≠ 退出倍数` 且偏离 >10% → 必须给退出倍数敏感性表。** 恒隆：退出 PB 取 0.158 / 0.18 / 0.20 / 0.232 / 0.35 时，H12 分别是 **3.71 / 3.89 / 4.07 / 4.35 / 5.35**。
2. **终值 ≈ 现价时必须声明"含价格回归"。** 当期末 BPS 零增长且退出倍数 = 当前倍数时，**终值必然等于现价**（恒隆 26.64×0.232 = 6.18 vs 现价 6.19）——这是构造出来的，不是市场共识。此时 H 档回答的是"买得比现价便宜、十年后股价回到今天，能不能赚 12%"，**它的一部分收益来自价格回归，不是股息。**
3. **H 档不得替代"这只股票值多少"的判断。** 上面三条加起来意味着：H12 对退出倍数高度敏感，而退出倍数是我假设的。**报告必须写出"我认可的是哪一档退出倍数、为什么"，不能只贴四个数字。** 恒隆：我认可 0.158–0.20（3.71–4.07），因为家族持股 60%、不卖资产、不私有化、无行业拐点——**4.35 那一档数字好看，是因为它假设了一个我不相信的退出条件。**

#### 4.1.1 BPS 有增长时："终值 ≈ 现价"不成立（v3.4.4 新增，成都银行暴露）

**4.1 第 2 条只在 BPS 零增长时成立。** 一旦标的的 BPS 在增长，终值必须用**期末 BPS**、股息必须用**逐年序列**，否则会把"增长"误读成"价格回归"：

| | 恒隆（BPS 零增长） | 成都银行（BPS +116%） |
|---|---|---|
| 当前 BPS | 26.64 | **21.98**（2026Q3） |
| 期末 BPS（第 10 年） | 26.64 | **47.53** |
| 终值 = 期末 BPS × 退出倍数 | 6.18 | **43.12**（= 47.53 × 0.907） |
| 终值 vs 现价 | 6.18 vs 6.19 → **含价格回归** | 43.12 vs 19.94 → **差 +116%，不含价格回归** |
| 若误用当前 BPS 算终值 | 正确（本来就零增长） | 20.75 vs 19.94 → **假"价格回归"，会漏报 116% 的净资产增长** |

**规则三条**：
1. 调用 `hurdle()` 必须传 `bps_end`（期末 BPS）、`dps_list`（逐年股息序列）、`sens_mults`（退出倍数档位）。
2. 报告必须显式写出「期末 BPS X（当前 Y，+Z%）→ 终值 W，与现价差 ±N%，构成/不构成价格回归」。
3. **只有 BPS 零增长时，"终值 ≈ 现价"才是结构；BPS 有增长时，终值高于现价是应该的，不是异常。**

**成都的 H12 = 20.57 之所以干净**：买入隐含 PB **0.936** > 退出 PB **0.907**，内含 **−3.1%**（收缩），是全库第一个"不需要倍数修复就能达到 12%"的 H 档——**它的 12% 全部来自 BPS 从 21.98 涨到 47.53 与每年 30% 派息，一分不靠估值修复。**

#### 4.1.2 市值里含大额投资资产时：H 档必须给两档，且资产按【今天价值直加】（v3.4.5 新增，v3.4.11 重写）

**`h_price()` 只算「每股经营溢利 × 退出倍数」，一分投资资产都不给。** 触发条件：投资类资产（上市股权 + 联营/合营 + 投资性物业）**占市值 >20%**。

```
腾讯 H12（经营业务）= 464.42 HKD          ← 只算游戏/广告/支付/云
投资 9,030.6×85% + 净现金 153.3 = 7,829.3 亿 → 每股 98.40 HKD  ← 今天是这个价
腾讯 H12（含资产）  = 464.42 + 98.40 = 562.82 HKD
```

**为什么是「直加 98.40」而不是「折现 10 年」——NPV=0 原则**：

```
若一块资产的预期总回报 = 折现率 r，其现值恒等于今天的公允价值，与年限无关：
      98.40 × 1.12¹⁰ ÷ 1.12¹⁰ = 98.40     ← 任何 r 都不动
```

所以直加隐含的假设是「这块资产赚到 12%」——**这是最中性、最不偏不倚的假设**。唐朝法 SOTP 用的也是 `INV_TOTAL×0.85 + 净现金` 直加。**两法必须同这一口径，否则会在「资产时点」这个开关上人为制造分歧。**

**❗ 禁止只折现、不给增长。** `98.40 ÷ 1.12¹⁰ = 31.68` 等价于假设这块资产**总回报 0%**：先按 85% 折价、再零增长、再折现十年——**三重惩罚**。腾讯这一处错了 **66.72 元/股**（H12 从 562.82 掉到 496.10）。

若确实要折现，**必须同时给增长率并写出数值**：

```
g_inv = 0%  → 31.06 元（隐含总回报 0%，❌ 无依据）
g_inv = 4%  → 45.98
g_inv = 8%  → 67.06
g_inv = 12% → 96.48  ← 与直加数学恒等（NPV=0）
```

**判别法（两问）**：① 我给这块资产的增长率写了多少？没写 = 默认 0 = 错；② 代进 `V×(1+g)^n÷(1+r)^n` 后，它隐含的总回报是多少？若显著低于 r，说明我在做无依据的悲观假设。

**❗ 464.42 不能直接和股价比**：那是「经营业务的价」，383.60 是「整只股票的价」（含 98.40 资产）。上一版写「现价低 17.4%」就是拿这两个硬比——苹果比橘子。

**规则五条**：

1. **触发**：投资类资产占市值 >20% → 两档制，并写明两档各答什么问题（经营业务值多少 / 买这一股要求 X% 该付多少）。
2. **折扣与唐朝法 4.4.7 同口径**（上市股权 90–100%、联营/合营 60–80%），两法必须同一个折扣。
3. **资产按今天价值直加**；如需折现必须同时给 `g_inv` 并写进报告。
4. **分解资产口径差之前，先确认两法口径真的不同。** 若两法都直加，就不存在「资产时点差」这一格——把它算进去等于自己造假分歧（腾讯曾因此多出一格 65.42 元的假差）。**同口径下还差 >30%，那才是真分歧。**
5. 两档结论相反 → 按唐朝法判据三处理（不买）。

**腾讯实测（2026-11-01 二次复核）**：经营业务 464.42（不可与股价比）／含资产 **562.82**，现价 383.60 低 **31.8%**，10 年 IRR **17.83%**。**但这个 17.83% 只在「capex 全部是资产」时成立**：同一套假设换 FCF 口径，H12 = **339.07**、IRR **9.99%**。**闸门 3 判 capex 占净利 74% 不过 → 该信的是 9.99%。**

**这个案子给的两层教训**：① 两档不是为了调和分歧，是把「我方模型漏算了什么」写在明面上；② **但「补上一块漏算」时，补法本身也可能补错方向——直加是对的，折现只对一半（另一半是增长率）。方向更保守 ≠ 更正确。**

#### 4.1.3 H 档之间的间距是久期，不是精度（v3.4.11 新增，腾讯暴露）

**腾讯 H12 562.82 → H15 458.38，要求回报只差 3 个点，价格差 18.6%；纯经营口径 464.42 → 359.98 差 22.5%。** 这不是算错，是久期的必然：

```
(1.12/1.15)¹⁰ = 0.7677 → 数学下限：低 23.2%
含资产口径实测 458.38/562.82 = 0.8144 → 低 18.6%
差的 4.6pct 来自固定金额资产（98.40，久期为 0）稀释了间距

终值占价格 76.8%、加权久期 7.98 年
  · 边际（H12 处 12%→13%）每 1pct = 6.8%（±38 元）
  · 平均（H12→H15 跨 3pct）每 1pct = 6.2%（±35 元）
（纯经营口径：终值占 93.0%、久期 9.67 年，边际 ≈ 8.2%）
⚠ 引用"每 1pct 移动多少"必须说清是边际还是平均——边际随 r 升高而下降。
```

**四档间距是自洽的（含资产口径）**：H10→H12 每 pct 6.8%、H12→H15 6.2%、H15→H17.46 5.9%——逐档略降因 hurdle 越高、短久期股息权重越大。**一个"算错"不会这么整齐。**
**换年限也自洽**：3 年 −6.3% / 5 年 −10.2% / 7 年 −13.7% / 10 年 −18.6% / 15 年 −25.4% / 20 年 −31.1%，随久期单调递增、近乎同比例。**所以跨标的比较间距没有意义**（年限不同）。

**规则四条**：

1. **结论句只能用 IRR 表达**（「现价对应 10 年 IRR X%」），价格档位只作坐标。报告必须同时给「现价 IRR」。
2. **禁止用「现价刚好等于 H15」「离 H12 只差 X%」作判断依据**——hurdle ±1pct 就移动 6.8%（腾讯 ±38 元，H12 处边际值），这种"贴线"是坐标重命名，不含信息。
3. **引用 H 档做阈值时（「跌到 X 就买」），必须同时写该价对应的 IRR 和 hurdle 判断的不确定度（腾讯：±1pct = ±6.8%，H12 处边际值）**，并说明这是一个区间而不是一个点。
4. **跨标的比较 H 档间距没有意义**：间距由年限和终值占比决定（腾讯实测 3 年 −6.3% / 10 年 −18.6% / 20 年 −31.1%），不同标的的年限不同，间距不可比。

#### 4.1.4 同一指标只允许一个"当前值"（v3.4.12 新增，郎刚「文档里有很多版本」暴露）

**腾讯这一份报告里同时存在四个 H12：464.42（经营业务）／562.82（含资产，采用）／496.10（零增长折现，错）／495.48（漏净现金，错）。郎刚的问法不是"数字是多少"，是"我该信哪个"。**

**规则三条**：

1. **正文只写当前值，且只写一处"定义式"的完整值**；其余引用可省略小数但必须同值。
2. **历史版本必须满足**：① 集中放在标注「历史／已作废」的段落（修订记录、对照表、`11.2b` 这类小节）；② 每个旧值旁标「❌ 错」或加删除线；③ **正文任何位置不得出现未标注的旧值。**
3. **多脚本算同一指标时，指定唯一权威脚本**（腾讯：`分析脚本/四档最终值.py`），报告写明「若与别处冲突，以此脚本输出为准」；其余脚本标"历史存档"，不得再被引用为数据来源。

**判别法（可机械执行）**：全文搜这个数。若同一指标出现在两个以上位置、且有一处**没有**作废标注或口径说明，就是漏洞——**不是"读者应该能分辨"，是"我没给读者分辨的依据"。**

**为什么这条比算术更重要**：算术错是一次性的，版本混乱是**持续的**——读者每次引用都要重新判断信哪个，而判断依据（哪版是当前版）恰好只有作者知道。**《百年孤独》里马孔多的居民因为失眠症忘记事物的名字，需要在每样东西上贴标签——报告的多版本问题就是没贴标签。**



#### 4.1.5 退出倍数法的结构性缺陷，与「两段式」替代（v3.4.13 新增，郎刚「我需要更加贴合实际的算法」）

**H 档（`P(r) = 股息现值 + EBIT_n × 退出倍数 ÷ FXR ÷ (1+r)^n + 资产`）有三个结构性问题，全部与算术无关：**

| # | 缺陷 | 后果 | 判别法 |
|---|---|---|---|
| ① | **中间期只算股息** | 留存现金被推到第 n 年一次性变现，人为制造「终值占 77%」 | 每股股息 ÷ 每股维持性 FCF。腾讯 = 17.5%，即 82.5% 现金流被推后 |
| ② | **终值用 EBIT × 倍数** | 倍数公式里 **第 n 年之后的 capex 一分不扣**，等于假设 capex 到终点就消失。腾讯：2036 年 capex 4,923 亿/年，其永续现值 **516 元/股**，而 15× EBIT 的公式里它是 0 | 算一遍「第 n 年的 capex ÷ r ÷ 股数」，看这个数有没有在终值里被扣掉 |
| ③ | **「capex 是成本还是资产」被做成二选一** | 只能给 339 或 563，无法表达「一半是防守性保护费、一半是真投资」 | 问：这家公司的 capex 里，有没有「不投就掉队」的成分？有 → H 档表达不了 |

**触发条件（任一）**：capex ÷ 折旧 > 2 倍；或 capex ÷ 净利 > 50%；或公司处于「不投就掉队」的技术军备期。

**替代算法：capex 三分法 + 两段式**

```
维持性 capex = 折旧（永久要花，维持现有产能）
防守性 capex = 扩张 capex × χ     （χ = 不投就掉队的比例，也是成本）
进攻性 capex = 扩张 capex × (1−χ) （按增量 ROIC ρ 计价）

P(r) = 维持性FCF ÷ (r − g)                    现有业务永续价值
     + 进攻capex × (ρ/r − 1) × 年金(r, n)      进攻投资的净现值
     + 非经营性资产（按今天价值直加，见 4.1.2）

维持性FCF = OCF − 维持性 capex − 其他维持性支出 − 扩张 capex × χ
ρ = r 时该项为 0（投了不创造也不毁灭价值）；ρ < r 时毁灭价值
```

**规则六条：**

1. **χ 必须来自外部证据，不得由现价反解后再回去算 IRR。** 这是本条的**最硬约束**——用现价解出 χ，再用这个 χ 算出现价 IRR = r，是**循环论证**，永远得到「刚好合理」。χ 的来源：行业对照（超大规模云厂商维持性+防守性通常 40–60%）、公司披露的产能利用率、折旧年限变化。
2. **必须报 χ 的区间（至少 0%/50%/100% 三个点）和对应的现价 IRR 区间**，不给单点。**结论的稳健性判据是「区间是否跨过门槛」，不是「中位数是多少」。**
3. **H 档保留，但降级为「最乐观情形的上界」**，不得作为决策依据。若仍要引用 H 档数字，必须同时写出「该倍数隐含的永续 capex 现值」。
4. **禁止承诺「换更精细的模型 → 价格区间更窄」。** hurdle 间距由资产久期决定，与模型无关：腾讯 H 档久期 8.0 年（12%→15% 差 −18.6%），两段式久期 9.1 年（差 **−20.9%**），**换模型后间距更大而不是更小**。久期越长、模型越「实际」，对 hurdle 越敏感——**这是长久期资产的定义，不是算法缺陷。**
5. **决策表述从「价格门槛」改成「IRR 门槛」**：不写「跌到 303 就买」，写「现价 IRR 10.61%；要 15% 需跌到 305；要 18% 需 257」。价格档位只是 IRR 的坐标。
6. **必须给一个「一年内可验证」的单一指标**，把 χ 和 ρ 变成可观测的经营问题。腾讯：2027 年 AI 相关收入能否覆盖 1,418 亿 capex × 12% ≈ 170 亿。

**腾讯实测（2026-11-01）**：

| χ（防守性比例） | 价格（r=12%, ρ=12%） | 现价 383.60 的 IRR |
|---|---:|---:|
| 0%（最乐观） | 435.0 | **13.39%** |
| 50%（基准） | **335.9** | **10.61%** |
| 100%（最悲观） | 236.9 | **7.37%** |

**结论的稳健部分：无论 χ 取多少，现价 IRR 都在 7.4%–13.4%，没有一种假设给出 15% 以上。** 这比「H 档说 17.83%、FCF 全扣说 9.99%」有用得多——后者是硬币的两面，前者是硬币本身。

**反解可用来「读市场」，不可用来「算自己」。** 现价 383.60 反解出的 χ≈25%、ρ≈11.5% 是一句关于**市场预期**的陈述（「市场认为 1/4 的 AI capex 是防守性的」），不是估值输入。**两者混用就是循环论证。**

#### 4.1.6 H 档必须还原成现金流：同一终值验伪 + 退出倍数反解（v3.4.14 新增，郎刚「464 怎么实现 12%、359 怎么实现 15%」）

**郎刚的问法是最实的一问：报告说「要求 12% 时该付 464、要求 15% 时该付 359」，那这两句话具体怎么实现？公司要做成什么样？** 这个提问暴露了 H 档输出方式的一个毛病——**只给价格、不给路径，读者拿到的是一句无法检验的话。**

**规则一：必须写清「几成来自股息、几成来自第 n 年那一次成交」。**

```
H 档价格 = 股息现值 + 终值现值 + 非经营性资产
腾讯 H12（经营业务口径）：464.42 = 32.32（7.0%）+ 432.10（93.0%）
腾讯 H15（经营业务口径）：359.98 = 28.25（7.8%）+ 331.73（92.2%）
```

**93% 押在第十年一次成交上**——这句必须写在价格旁边。不写，读者会以为 12% 是「每年挣 12%」。

**规则二：同一终值验伪（这条可以机械执行，是 bug 探测器）。**

同一组 (g, 退出倍数) 下，各档的终值必须**完全相同**，因此：

```
price(r) × (1+r)^n − 股息按 r 复利到 n 年的终值  ≡  同一个终值
腾讯：464.42×1.12^10 = 1,442.42 = 1,342.04 + 100.37   ✓
      359.98×1.15^10 = 1,456.32 = 1,342.04 + 114.28   ✓
残差 13.90 = 股息再投利率差（100.37 vs 114.28），必须能对上
```

**判别法：若两档算出的「×(1+r)^n − 股息复利终值」不相等，就说明两档不在同一条曲线上（g 或退出倍数被改过而没同步）——那是 bug，不是观点。** 这一条比残值拆解更早生效，因为它只需要两档数字，不需要拆解表。

**规则三：退出倍数必须当自变量报一张表，不能只给一个倍数。**

**「便宜 X%」这四个字只有在倍数假设被看见时才有意义。** 腾讯实测（含资产口径，要求 12%）：

| 退出倍数（税前 EBIT） | 12% 的应付价 | 现价 383.60 的 IRR |
|---:|---:|---:|
| 8.27×（市场今天给的） | **368.95** | 11.38% |
| 8.8×（现价自身反解的） | 384.22 | 12.03% |
| 12× | 476.40 | 15.35% |
| 15×（H 档默认） | **562.82** | 17.83% |

**倍数从 8.27× 到 15×，12% 的应付价从 369 涨到 563——194 元、+53%。「便宜 31.8%」的 179 元里没有一元来自经营，全部来自「市场改主意」。** 报告若只报 562.82 与「便宜 31.8%」，读者记住的必然是后一句。

**规则四：反解「现价 + 要求回报 → 需要几倍」，与市场当前倍数并列。**

```
现价 383.60 + 要求 12% → 需要退出 8.78×
市场今天给的是 8.27×
→ 结论句应写成「现价离 12% 线约 4%（368.95），差的是 0.5 倍估值，不是 30% 的价格」
```

**规则五：口径不得混用——① 列（经营业务价）不是股价。**

```
① 经营业务价 464.42 不含投资组合；股价口径的 12% 线 = 464.42 + 98.40 = 562.82
若股价真跌到 464.42，IRR 是 14.80%（白送 98.40 的资产），不是 12%
```

**「464 实现 12%」是一句反事实陈述**——只有剔除投资组合单独买经营业务时才成立。**报告写 ① 列时必须紧邻一句「此列不可与股价直接比」。**

**腾讯实测的收敛（值得复用的现象）**：EBIT 口径 + 市场倍数 8.27× → 12% 线 **368.95**；两段式 χ=25%、ρ=12% → 12% 线 **385.45**。**两个结构完全不同的算法（退出倍数 vs capex 三分法）只差 0.3%，现价 383.60 就落在这条线上。** 其经济含义是**「AI capex 的净现值 = 0」**——市场既没说 AI 是第二曲线，也没说钱打水漂。

> **这条收敛修正了一次表述错误**：我此前分别说「贵 26.4%」（唐朝法 FCF）和「便宜 31.8%」（H 档）——**两个都是口径的极端，而市场共识在中间。** 当两个独立算法在同一个价格上收敛、且该价格的经济含义能一句话说清时，**那个含义比任何单一口径的价差都更接近真相。**

**决策含义（腾讯 2026-11-01）**：现价恰好坐在 12% 的临界点上，**没有余量**。A 类目标达成型要「12% 以上且留余量」→ 留余量的价格是 **335.95**（两段式 χ=50%）或 **303.52**（capex 全成本）。**结论仍是 128 万不动，但理由第四次升级：不是"贵 26.4%"，是"一分余量都没有"。**

**规则六：主句只能是现价 IRR，不能是「低于几条线」（v3.4.15 新增，郎刚「可是现在股价只有 384」→「你直接用更准确的描述胜过补警告」）。**

**第一次我写错了改法**：原文「现价 383.60 低于全部四档」，我在旁边加了一个 ⚠️ 读法警告去解释「不等于便宜」。**郎刚一句话否掉：「你直接用更准确的描述胜过补警告。」** —— 加警告等于承认主句是错的，然后要求读者自己绕过去。**主句错了就改主句，不要打补丁。**

**根因**：四档（腾讯 392.32–651.36）全部建立在「退出倍数 15× + capex 第 n+1 年起归零」上，是**上界**。拿上界当分母去比现价，必然算出「便宜」。**错误不在结论，在问题本身——「现价比某档低多少」不是一个估值问题。**

```
✗ 错：现价 383.60 低于全部四档，隐含 10 年 IRR 17.83%，现价相当便宜。
✓ 对：唯一能和股价直接比的数是——现价 383.60 的 10 年 IRR = 12.05%
      （两段式 χ=25% 385.45 / 市场 8.27× 口径 368.95）。踩在 A 类 12% 门槛上，零余量。
      四档全在现价之上，但四档回答的不是「公司值多少」，是「若 n 年后按 15× 接盘
      且 capex 归零，今天该付多少」——上界，不是价值。
```

**两条可机械执行的规范**：

1. **主句必须是现价 IRR，不得是「现价低于 / 高于 X 档 / 离 X 线多近」。** 「低于 N 档」最多作从句，且必须紧接一句「这 N 档是上界」。
2. **章节标题与列定义必须自带口径定语。** 腾讯 3.2 节标题由「四档」改为「四档**上界**」；② 列定义由「该付多少钱」改为「**在 15× 接盘且 capex 归零的前提下**该付多少钱」。**读者只看标题就误会的地方，正文救不回来。**

**推广（比本条更重要）**：禁则 34 说的「H 档点位不能做买卖判断」，这里扩到**任何多点位的相对位置**——「四档全在现价之上」和「现价刚好等于 H15」是同一类幻觉，都是拿**假设的位置**冒充**价值的高低**。

**顺带一条算术纪律**：同一组数字之间的差额，**只允许一个基数**。腾讯 17.83% 与 12.05% 差 **5.8pct**（17.83 − 12.05），不是 7.2pct（7.2 是 17.83 − 10.61）。**我在同一轮的两份文件里用了两个基数——比算错更难查，因为两个数都"对"。**

### 5. 压力测试与永久损失

**永久损失定义**：经营性（正常化每股价值基础难以恢复的下降）；投资性（保守正常化+保守退出下累计分配+可实现价值<成本）；市场价格回撤≠永久损失。**禁止预测精确的"未来最大回撤"**。
第三步至少测试：①盈利不变、倍数压缩30%；②盈利下降20%且倍数压缩30%；③一个公司特定严重情景。历史最大回撤仅作参考事实。

行动参考：进入第四步的新增资金候选原则上"现价≤H12"；正常仓位优先H15；悲观5年总回报为负不自动否决，但必须说明永久损失情景权重与仓位折扣；**估值高度依赖终值倍数扩张时结论不得高于"观察"**。

### 6. A/H 多上市地双门槛（v3.4 硬规则）

同公司同经营假设，分别计算A/H的IRR、税前税后股息率。`A/H折价率 = 1 − H人民币等值价 ÷ A价`。默认规则：
1. **H股至少较A股折价25%才获得相对价格资格**（25%是用户默认门槛，报告仍须解释红利税资本化、派息率、流动性支持的个别合理折价）；
2. **H股绝对价格同时必须≤自身H12/H15/H17.46档位才获得相应行动资格**；
3. 折价率只是第二道参考，**买入决策永远锚定H股绝对价格和税后人民币回报**；
4. **折价扩大若仅因A股上涨，H股IRR不变，不构成买入触发**（禁止把折价扩大当买入信号）；
5. A股也必须单独达到自身档位；**A、H均不达标则两地都不买**；
6. A、H均达标时，优先选税费/汇率/流动性调整后人民币IRR更高者。
税费口径：港股通红利税20%；A股个人持股>1年免税。

### 7. 最强反方（估值完成后必答）

市场为什么只给当前估值；哪个会计数字最可能误导；哪个增长假设最脆弱；股价5年不涨最可能是什么原因；本分析最可能错在哪里；哪三个指标能最早证明分析错误。

## 串联唐朝估值法（v3.4.2 修订：全类型双向强制）

### 触发条件（2026-10-25 郎刚定，无条件）

**郎刚原话**：「以后新股票都是唐朝+四步法一起做，如果已经有四步法了就跟唐朝法对比，反之就跟四步法对比，**一定要两个都有，拿来做验证**。」

- **任何进入完整研究模式的标的都必须两份齐全**，不按 A/B/C/D 分级豁免。C/D 类也要两份——**两法同时否决才是最硬的否决**；只被一把尺子否决，说服力不够。
- **双向触发**：先做四步法 → 必须补唐朝法；先做唐朝法 → 必须补四步法。缺哪份补哪份，然后按 `tangchao-valuation` 5.1 的三条判据对比。
- **只出一份时**，结论必须标注「**单尺子结论，不构成仓位建议**」，并主动报出缺的是哪一份。
- 快筛模式（只出资格卡）不触发；用户只要求做前三步时，提示"须配唐朝法"但不得静默省略。

### 为什么要有第二把尺子

v3.4 的锚是**"我要的回报"**（10%/12% 资本成本 IRR 倒算）；唐朝法的锚是**"市场给的替代收益"**（1÷无风险收益率 × 安全边际）。两者不是同一件事。

- 两套买点差得远 → 说明估值对假设极度敏感，**此时不该重仓**；
- 两套买点收敛 → 说明这个价格在两种逻辑下都成立，**置信度上升**。

在低增长稳定股（茅台、格力、陕煤）上两者会收敛；在**高增长高估值**标的上会严重背离（唐朝法给出极高容忍度）。背离本身是信息，不是错误。

### 边界（硬规则）

| 事项 | 谁主导 |
|---|---|
| 公司质量判定、A/B/C/D 分级 | **v3.4 前三步**，唐朝法不得参与 |
| 经济价值区间、H10/H12/H15/H17.46 | **v3.4**，唐朝法**不得覆盖、不得改名、不得修改** |
| 买点 / 下单价 | 取两者**较低者** |
| 卖出纪律（DCF(6%) 减仓线、150% 上限） | **唐朝法**（v3.4 此块缺失）。经验线只是唐朝法报告里的辅助参考，**不参与任何取值**，更不参与本框架决策 |
| 仓位、资金来源、组合适配 | **v3.4 第四步**，唐朝法不涉及 |

### 分歧处理

1. **两套买点差 > 30%**：报告必须并列展示，不合并、不平均；归因到**分子端**（利润锚不同）还是**分母端**（折现率不同）；结论只给方向，禁止写"贵 X%"这样的精确折价率。
2. **唐朝法买点低于本框架**：以唐朝法为下单价（更严格）。
3. **唐朝法买点高于本框架**：**仍以 H 档位为下单价**。唐朝法的高买点只作"不必等那么低"的参考，**绝不构成放宽买入价的理由**。
4. **数据口径必须一致**：两套报告用同一价格日期、同一财报期、同一股本。不一致则先对齐再比较。
5. **分歧幅度对应的动作，唯一出处是 `tangchao-valuation` 5.1 判据三**（<10% 收敛；10–30% 正常分歧，取较低价为下单价；>30% 或拆不干净 → **仓位打五折**并写"估值不可靠"；**方向相反 → 不买**）。**本节只保留边界与归因要求，禁止在这里另写一套阈值**——两处各写一套必然先后过期。

### 卖出纪律的冲突说明（必须写进报告）

本框架禁止事项第 11 条"禁止写死永久卖出价格"，与唐朝法"合理估值 ×150% 卖出"看似冲突。**处理口径**：

- 唐朝卖点是**动态触发线**（随三年后利润更新移动），不是永久价；
- 只作**减仓触发**（减持至观察仓），**不作清仓指令**；
- 减仓后的资金去向、是否换仓，一律走第四步；
- 报告不得写"XX 元以上永远卖出"。

### 输出纪律

- 两份**独立文件**，不混写，命名统一为 **`{股票简称}-{YYYYMMDD}-{技能名}.md`**（股票在前、日期居中、技能名在末，日期取数据截止日）：
  - `{股票简称}-{YYYYMMDD}-三步法.md`（本框架）
  - `{股票简称}-{YYYYMMDD}-唐朝估值法.md`（唐朝法，含价格区间图）
- 本框架报告的第 5 节末尾只用**一段话**引用唐朝法结论（买点区间 + 与 H 档的差异 + 下单价裁决），**不复述其计算过程**；
- 唐朝法报告必须含**价格区间图**（由 `tangchao-valuation/scripts/priceband.py` 生成）。

#### 三条防伪纪律（v3.4.3 新增，恒隆暴露）

1. **每份报告的第一顺位买入价，必须是本方法自己的答案。** 本框架写 **H12**，唐朝法写 **DCF(12%)**。**"对比后下单价"只能出现在接口节，且必须同时写出两个数字。** 恒隆的反例：两份报告的结论位都写"下单价 = min(3.47, 4.35) = 3.47"，读者会以为两个方法独立算出了同一个数——**那是把对比规则的输出塞回了各自结论位，不是验证。**
2. **两法差异的拆解禁止手写，必须由 `tangchao-valuation/scripts/gate.py` 的 `decomp()` 产出，且以 `assert run_gate(...)` 收尾。** 分量必须带公式，残值由脚本算（**脚本没有"残值"入参**）。
3. **禁止在 pct 空间拆解。** pct 不可加，会自己凑成整。恒隆的"−25.4pct + 5.2pct = −20.2pct"数字完全对得上，因为它是凑的；换到金额空间（1.99 − 1.12 = **+0.87 元**）立刻露馅。**先在金额空间算完，再折算成 pct 写报告。**

## 第四步：组合适配与成果测算（有条件触发）

### 1. 输入（不完整只给方向性分析，不给可下单仓位）

组合快照（日期/持仓/市值/成本/现金/币种）、人民币总资产与剩余年数、拟成交价与目标仓位、**资金来源**（新增资金/现金/股息再投资/卖出某持仓）、5与10年期限、分红是否再投资、税前100万年股息目标。

### 2. 三重机会成本（空集顺位）

①商业质量基准：贵州茅台；②组合机会成本：现有持仓中质量合格、达新增门槛、未触上限、风险调整后预期回报最高者；③观察池可执行候选；④低风险基准（币种与期限匹配）。**第2、3项为空时机会成本降为低风险资产**；茅台只有在自身达标且未触上限时才是实际替代方案。不得忽略继续持有现金的选择权。

### 3. 纳入前后成果测算（用已冻结的个股情景输入）

| 指标 | 纳入前 | 纳入后 | 边际变化 | 目标 |
|---|---|---|---|---|
| 第5年/第10年期末资产 | | | | ≥2000万 / ≥5000万 |
| 组合XIRR（禁止用个股IRR简单加权代替） | | | | 记录 |
| 概率加权期末财富/等效CAGR | | | | 辅助 |

### 4. 组合角色与股息路径

角色唯一：核心复利/高增长/稳定股息/周期反转/风险分散。必须说明替代谁或是新增独立角色；卖出融资须列税费、股息损失、放弃的上行与增量回报。
股息表：税前年股息（**100万元按税前名义固定管理，是唯一目标**）、适用税率与渠道、**税后实际到手（逐持仓按注册地与渠道计算，只披露不另设80万目标）**、覆盖率、前五大来源占比、压力削减后股息。高股息率不自动加分，必须验证FCF、派息覆盖与增长能力。

### 5. 仓位规则与风险去重

| 分类与回报 | 首次仓位 | 正常上限 | 硬上限 |
|---|---:|---:|---:|
| A类 + 目标达成型 | 3%—5% | 10%—15% | 20% |
| A类 + 接近目标型 | 2%—4% | 8%—12% | 15% |
| A类 + 组合辅助型 | 2%—3% | 5%—8% | 10% |
| B类 | 1%—2% | 3%—5% | 8% |
| C/D类 | 0% | 0% | 0% |

单股>20%必须单独集中度压力测试；**25%为默认绝对硬约束**。第一步风险已入模型的不重复"降一档"；仓位折扣只处理模型无法吸收的尾部/流动性/治理/相关性，并完成风险去重表。

#### 5.1 口径：1,000 万基数 + 绝对金额 + 独立分析（v3.4.8 新增，郎刚定）

**郎刚原话**：「就每次分析就站在 1,000 万的总资金下，该公司可以配置多少，所有公司的总和可以超过 1,000 万，每次都是独立分析。」

**四条硬要求**：

1. **基数固定 1,000 万**（人民币等值）。所有仓位必须**同时给百分比与绝对金额**（例：10%–15% = 100–150 万），**只给百分比＝不合格**。
2. **独立分析，不做组合加总约束。** 每份报告都假设手上是 1,000 万新钱，**不得因为"你已经持有 X%"而压低本报告的目标配置**。
3. **总和允许超过 1,000 万**（18 个 A 类标的按 10–15% 给 = 180%–270%）。这不是算错，这是**理想权重（ideal weight）**。
4. **必须区分两个概念并写明**：
   | 概念 | 谁负责 | 报告给不给 |
   |---|---|---|
   | **理想权重** | 单标的报告 | **必须给**（本标的该配多少） |
   | **实际权重** | 组合层裁剪 | **不给**（需跨标的排序，属另一类工作） |

**裁剪排序依据（写进报告，供用户自己切）**：**分类 → 该价 IRR → 证据门进度**。

**为什么这条重要**：旧口径（组合加总约束）会把"你已经有了"变成"你不该再要"。腾讯实测——因为 12.8% 超过（误判的）B 类上限 8%，报告结论变成"该减 48 万"。**那是拿一个错误的分类去否定一个正确的仓位。** 单标的报告回答不了组合问题，就不要假装能回答。

#### 5.2 分类判定必须按规则算，不得用"某维不满分"降级（v3.4.8，腾讯暴露）

**规则原文**：A 类 = 无核心"不通过" + 核心"存疑" **≤1** + 护城河与财务明确通过 + 无否决项。

**腾讯实测**：核心六维（2/3/5/6/7/8）里只有第 5 维一个存疑，无"不通过"，护城河强、财务中上 → **按规则就是 A 类**。而我判了 B 类，理由是"第 5 维是弱"——**把"≤1"读成了"0"**。

**硬规则**：
- 分类必须**逐维列表打勾**后按规则机械得出，**不得由整体印象或某一维的观感决定**；
- 报告必须写出「核心六维中存疑 N 个」这个计数，**N ≤1 就必须判 A**，除非有否决项；
- 若确要降到 B，**必须写明"存疑数已达 2"或"命中否决项"**，不能写"因为第 5 维弱"。
- **A 类内部还要定回报类型**（目标达成型 10–15%/20% ｜ 接近目标型 8–12%/15% ｜ 组合辅助型 5–8%/10%），**这一步才是主观判断的地方，前一步不是。**

**一个 12.8% 在 B 类（硬上限 8%）是超配 60%、在 A 类目标达成型（10–15%）是区间中位。分类错一档，动作完全反向。**

#### 5.3 资本配置维度的去重边界（v3.4.8，腾讯暴露）

**第 5 维只判四件事**：① 历史再投资回报（每 1 元留存收益创造了多少市值）② 有无乱并购/大额减值 ③ 有无大股东侵占与财务造假 ④ **分配政策是否可信（有规则、可预期、不随意砍半）**。

**不属于第 5 维、不得在此扣分的**：
- **capex 该不该花、花得有没有效** → 归第 3 维（客户需求）与第 7 维（成长性），估值影响全部体现在**第三步的 FCF 口径**里；
- **当期回购金额下降** → 若同期资本开支上台阶，那是**再投资决策**，不是分配能力问题；只在"无规则、不可预期"这一点上扣分；
- **投资组合不披露逐笔** → 归第 6 维（治理），**不得在两维各罚一次**。

**判据一句话**：**同一笔 capex，只能罚一次——罚在 FCF 里，不能又在分类里罚。**（对应第 1 节风险去重表）

**腾讯实测的完整链条**：capex 占净利 74% → 已在第三步把 FCF 从 1,751 打到 992（这是第一次罚，正确）→ 若再以"资本配置弱"降为 B 类（第二次罚）→ 若再以"回购砍半"减仓（第三次罚）。**同一个变量罚三遍，结论必然过度看空。**

### 6. 分档建仓 / 暂停 / 退出

#### 6.1 双表制：机械档 vs 实际档（v3.4.6 新增，腾讯暴露）

**两张表都要给，缺一张就是不完整。**

| 表 | 价格来源 | 回答什么 | 效力 |
|---|---|---|---|
| **表 A · 机械档** | 只用本方法 H 档位（≤H12 25%｜≤H15 60%｜≤H17.46 100%） | "只做四步法会怎么做" | 对照用，**不是下单依据** |
| **表 B · 实际档** | **双方法取低**（唐朝法判据三）+ 证据门 | "我实际会怎么做" | 下单依据 |

**为什么必须两张**：腾讯现价 383.60 已在 H12（562.82）之下，**表 A 说"现在该买 25% 目标仓"，表 B 说"到 303.52 才动第一笔"——两表差 46.1%。** 只给一个数，读者无法判断这个数是"方法的结论"还是"我加过安全边际后的结论"，也无法判断两法背离被定价了多少。

**两表价差必须显式写出百分比**，并注明差的原因（判据三档位：<10% 收敛 / 10–30% 取低 / >30% 打五折 / 方向相反不买）。

#### 6.2 预案版建仓表：结论为"不买"时**照样要给**（v3.4.6 新增，郎刚质疑"四步法里都没有仓位和建仓策略"）

**旧规则的问题**：第四步原为"仅拟交易时执行"，于是**结论为观察池/不买的报告全部跳过了仓位与建仓表**——神华、宋城、恒隆、汾酒、腾讯五份连续缺失，越看空的报告越薄。

**这不是省事，是把报告变成一次性消费品**：触发条件散在正文里，不成表，下次价格到了必须整份重做，而且重做时人已经忘了当初为什么设这个价。

**规则：结论四选一之后，无条件输出「预案版五件套」——**

1. **仓位上限**：引 §5 表（A/B/C 类各自的首次/正常/硬上限），**禁止各处自创数字**；若本标的触发仓位折扣，写明折扣后数值与折扣理由。
2. **分档表**：表 B 至少三档，每档写 `触发价 | 该价 IRR | 证据门 | 累计仓位 | 占总资产`。
3. **证据门**：**价格门之外必须有证据门**（3–5 项可观测、可验证的公司特定指标，带当前值）。理由见 6.3。
4. **暂停加仓条件**：≥3 项触发即停，与 §6.8 一致。
5. **退出条件**：买入时写死的论文退出 / 目标降级 / 机会切换三条。

**标注纪律**：预案版表头必须写「**预案，非下单指令**」；结论由"等待"转"纳入"时，须更新触发价（因为分母可能已变，见 6.3 第三条）。

#### 6.3 证据门的三个判据（港股/腾讯实测）

- **只满足价格、不满足证据 → 一手都不买。** 价格下跌而证据全反，通常说明**是基本面把公司跌下来的**，那时 H 档自己也会下移——**你买的不是便宜，是"便宜的定义刚被改写"。**
- **只满足证据、不满足价格 → 也不买，但要重算。** 证据改善（capex 回落 / FCF 恢复）会让 H12 上移，**建仓价跟着上移不算追高，是分母修复后门槛自己的位移。**
- **证据门必须是可观测的量化项**，禁止写"经营改善""capex 合理化"这类无法证伪的表述。腾讯的四项：季度 capex 连续两季环比 −15%、季度 FCF 连续两季 >500 亿、全年回购 ≥600 亿 HKD、应占联营转正。

#### 6.4 已持仓标的：先问四项数据，再谈加不加（v3.4.7 新增，腾讯暴露）

**触发场景**：用户问"要不要加仓/减仓/继续持有"——**"加仓"这个词本身就说明有持仓。此前的报告若按零持仓写过，前提就是错的，必须重做第四步，不是在旧结论上加一句"不建议加"。**

**四项必问数据（缺一项，边际分析就是空算）：**

| # | 数据 | 腾讯实测 |
|---|---|---|
| 1 | 持仓市值 / 可投资总资产 = **仓位%** | 128 万 / 1,000 万 = **12.8%** |
| 2 | **成本价**（用来判断是浮盈还是浮亏） | **404 HKD** |
| 3 | 浮亏/浮盈幅度 | **−5.05%** |
| 4 | 可动用现金比例 | **60%** |

**仓位必须放回分类体系里对照，同一数字会有相反结论**：腾讯 12.8% 在 **B 类（硬上限 8%）是超限 60%、该减**，在 **A 类目标达成型（10–15%）是区间中位、不动**。

> **v3.4.8 更正**：本例原写"两套体系两个结论 → 回到 A 还是 B 的分歧"，**但分歧不该靠讨论解决，要靠规则算**。按 5.2，腾讯核心六维只存疑一个 → 规则写的是"≤1 即 A"，**A 类结论是算出来的，不是选出来的**。写成"选择权在你"是错的，它把一次计算变成了偏好问题。

**加仓三个前置条件，必须同时满足**：① 仓位在目标区间内且未到上沿；② 价格 ≤ 双方法取低；③ 证据门达标（价格越临界、证据要求越高）。**腾讯 ①过 ②不过 ③不过 → 结论是"不动"，不是"减仓"。**

#### 6.5 "加仓摊低成本"是数学幻觉（v3.4.7，必须给这张表）

**成本高于现价时，无论加多少钱，均价只能无限逼近现价，永远到不了下面。** 腾讯实测（成本 404、现价 383.60）：

| 加仓 | 仓位 | 总投入 | 新均价 |
|---:|---:|---:|---:|
| 383.60 加 22 万 | 15% | 157 万 | 401.01（−0.74%） |
| **303.52 加 22 万** | 15% | 157 万 | **386.07（−4.43%）** |
| 383.60 加 72 万 | 20% | 207 万 | 396.66（−1.82%） |
| 472 万（→60%） | 60% | 607 万 | 387.95（−3.99%） |
| **∞** | 100% | ∞ | **383.60（极限）** |

**再给对称性（但先核对，别照抄旧数）**：加 22 万后，涨到 H12 多赚多少、跌到唐朝法价多亏多少，必须现场重算。腾讯 2026-11-01 复核：H12 = **562.82**（含资产），上行 **+46.7%（多赚 10.3 万）**、下行 **−20.9%（多亏 4.6 万）**，**不对称**；而 FCF 口径 H12 = 339.07 时又变小。**同一个数在两种口径下方向相反，说明对称性根本不稳。**

**⚠️ 这个"不对称"更不能当加仓理由**：它在 24 小时内被我算错过两次、方向相反（562.83 → 495.48 → 562.82），**一个自己都拿不稳的数，不构成新的买入依据**。核心结论不依赖对称性——见下。

**结论：加仓没有降低风险，只是等比例放大敞口；"亏损率改善 0.5pct"是分母变大的视觉效应。** 加仓唯一的正当理由是"边际回报够高"，**绝不能是"摊低成本"**——后者是行为金融里最贵的四个字。

#### 6.6 加仓的边际标准必须严格于建仓（v3.4.7）

**风险不对称**：建仓时最坏是"没买、少赚"；加仓时最坏是"在超配基础上加倍、双倍亏损"。

所以：**已持仓标的的加仓决策，不得使用最宽松口径的名义 IRR。** 腾讯现价四步法 10 年 IRR **15.01%**（EBIT 口径，够 13% 门槛）／**8.00%**（FCF 口径，闸门 3 要求的那个），唐朝法情景加权只有 **5.38%**，两法方向相反 → **不能拿 15.01% 作为加仓依据**。

**规则**：加仓只看①期望值口径（情景加权）②证据门 ③仓位合规，**不看"主口径 IRR 过线"**。主口径过线只能说明"如果从零开始，这个价格可以考虑"，与"在 12.8% 基础上再加"是两件事。

#### 6.7 减仓不能只等价格：区分纪律档与价格档（v3.4.7）

**仓位超限的修正，本质是风险控制，不是择时。** 但也不能无视行为成本，所以给三档：

| 档 | 触发 | 说明 |
|---|---|---|
| **A 纪律档** | 仓位 > 硬上限 | 理论应立即执行。**但若减出的钱无更好去处（现金已 60%），只是把股票风险换成现金风险** → 可暂缓 |
| **B 价格档** | 反弹 ≥ 成本价 或 ≥ H12 | **推荐档**：不要求立刻认亏，但把动作绑在可执行条件上，而非无限期挂着 |
| **C 破位档** | 跌破情景加权线且证据仍为 0 | 减至正常上限以下 |

**必须点破"等回本再减"是处置效应**，并给一个测试：**"如果它再跌 20%，你会不会减？如果不会，那'等回本'就只是拖延。"**

#### 6.8 分档与暂停

**分档**：≤H12累计25%｜≤H15累计60%｜≤H17.46累计100%（含已有持仓，不重复相加；下单按交易单位向下取整，港股注明汇率与费用）。
**暂停加仓（≥3项公司特定指标）**：正常化利润下调>10%；护城河指标连续两个报告期恶化；资产负债表/审计/监管/管理层重大变化；价格下降但经济价值下降更多；组合相关风险超上限。**价格下跌本身不是加仓理由。**
**退出（买入时写死条件，不写死永久绝对价格）**：
- 论文退出：一票否决/论文被破坏/护城河不可逆恶化/诚信治理问题/财务永久损失风险；
- 目标降级：预期回报显著低于组合目标/角色不再成立/税前股息可持续性下降/风险超上限；
- 机会切换：原论文未破坏时，新标的质量不得更低、悲观不得更差，扣摩擦后**概率加权等效10年CAGR至少高3个百分点**才进入换仓审查；两边置信度低时门槛5个百分点或不换；论文破坏/诚信/超限时不适用3pct门槛，直接按风险退出。
不再使用统一"6%阈值"；估值高不自动清仓，必须比较继续持有/换仓/现金三方案。

**第四步结论四选一**：纳入组合（价格/仓位/资金来源/预期成果）｜等待价格｜保留观察但不纳入｜移出观察池。

## 标准报告模板（硬骨架 · 固定 12 节，v3.4.16）

> **v3.4.16 起因（2026-11-01 郎刚质疑）**：「为什么你的四步法每次格式都不一样，比如买入价格的划分」。
> 查库实测 14 份四步法报告：**H10/H12/H15/H17.46 四档固定档位只在平安那份完全缺失；双表制（表 A / 表 B）14/14 未执行；1,000 万基数绝对金额缺 12/14；镜子测试缺 10/14；最强反方缺 7/14。** 规则一直写着，但过去只有一句"输出顺序"——**没有固定编号、没有必备字段、没有执行载体**，于是每份报告都按"这次要回答哪个问题"重排章节，14 份长出 14 种结构。
> **这跟 §0 三道闸的教训同构**：有脚本处（`precheck.py`）一次没漏，靠自觉处（报告骨架）14 份全漏。**不是能力问题，是执行载体问题。**
> **交付前必须跑**：`python3 scripts/report_lint.py <报告.md>`，R1–R13 任一 FAIL 不得交付。

#### 5.4.1 「买入价划分」统一口径（v3.4.16，直接回应"每次划分都不一样"）

**四步法只认一套档位：H10 / H12 / H15 / H17.46。任何报告不得以自创档替代它。**

允许在 H 档之外另提价格（恒隆「我认可的 0.158–0.20」、平安旧档案「三梯队 50/45/40」、汾酒「gate.py hurdle() 产出值」），但必须三件事同时做：

1. **标注「自创档，非 H 档」**，写清是谁的判断、依据在报告哪一节；
2. **写出它与最近 H 档的差**（金额 + 百分比）；
3. **表 A（机械档）只能用 H 档**；自创档只能进表 B，且该行注明来源。

**为什么**：自创档一旦混进表 A，读者就无法分辨"这是方法的结论"还是"我加过判断的结论"——这正是 §6.1 双表制要解决的事。**实测 14 份里只有 1 份写了双表。**

## Agent 执行硬规则

### 必须做到

1. 确认当前日期并刷新最新股价、汇率与财报；
2. 估值前锁定估值对象；建立四座勾稽桥；四种EPS分栏并验证三项恒等式；
3. 关键数据先对齐定义再双来源核验；
4. 三轴分析先行并逐参数传导，完成风险去重；
5. 区分事实/计算/假设/判断/缺失/争议；
6. 所有估值用程序并保留输入表；
7. 输出5年与10年、三情景及权重敏感性；先加权期末财富再反推等效CAGR，**不得直接加权IRR**；
8. 个股股息给税前税后口径；第四步以税前100万为唯一目标、税后仅披露；
9. 用每股数据并纳入回购与稀释；
10. 市场、公司、价格、组合**分别**下结论；
11. 独立交叉估值差异>20%必须解释；新旧价值变化>10%必须归因并冻结旧价格线；
12. 审计门通过后才可输出经济价值与H档位；第四步前四节通过后才可输出**可执行版**仓位；**预案版仓位表无条件输出**（v3.4.6）；
13. 写出最强反方和最可能错误；
14. 前三步结论先行并冻结，第四步不得倒推修改；
15. 只有A/B类进入观察池和第四步；
16. 经济价值默认10%/12%资本成本并输出±1pct敏感性；
17. A/H两地上市执行双门槛（折价≥25% + 绝对档位）；
18. 非人民币资产同时输出本币IRR和人民币IRR，并对期末汇率做升值/稳定/贬值三种压力；
19. 每季度更新剩余所需CAGR，但不得用目标落后提高风险预算；
20. 主动换仓执行3个百分点默认摩擦门槛；
21. **A/B 类必须串唐朝估值法**：前三步出 A/B 结论后，加载 `tangchao-valuation` 出独立报告（含价格区间图）；下单价取两者较低者；唐朝法**不得覆盖 H 档位**；两套买点差 >30% 时必须归因到分子端/分母端且只给方向。

### 禁止事项

1. 禁止使用过期价格直接下单；2. 禁止只引用卖方一致预期；3. 禁止把TTM峰值利润当正常利润；4. 禁止跨行业机械套用统一指标；5. 禁止把多个高度相关估值指标重复加权；6. 禁止因低PE、低PB或高股息单独认定便宜；7. 禁止把市占率或知名度直接等同护城河；8. 禁止忽略海外利润、ROIC和政治风险；9. 禁止给没有数据支持的精确预测；10. 禁止以"长期看好"代替价格和触发条件；11. 禁止写死永久卖出价格；12. 禁止为了得出"可以买"而调整增长和终值；13. 禁止静默切换估值对象；14. 禁止混用四种EPS；15. 禁止在审计失败时输出正式定价；16. 禁止用大行业冒充细分市场；17. 禁止为了支持买入而改变三轴判断；18. 禁止把H档位称为内在价值或只用H10算安全边际；19. 禁止用个股IRR简单加权代替组合XIRR和期末财富；20. 禁止在第四步为组合达标修改前三步参数；21. 禁止给A/B以外公司建立正式仓位；22. 禁止预测精确的未来最大回撤；23. 禁止把A/H折价扩大本身当买入信号；24. 禁止将港股统一按20%税率或税后80万元处理（税后逐持仓计算）；25. 禁止直接加权各情景IRR或把三情景权重冒充统计概率；**26. 禁止只出一份报告就给仓位建议（v3.4.2，郎刚定）——唐朝法与本框架必须都在，缺一份时结论一律标注"单尺子结论，不构成仓位建议"并说明缺哪份、补齐要多久；存量未配对标的一律标注"待第二把尺验证"，不得加仓；两法结论方向相反时，唯一允许的结论是"不买，等下一期数据消解分歧"，禁止以"哪个方法更适合这家公司"事后合理化选择。**
27. **禁止只给仓位百分比、不给绝对金额**（v3.4.8，郎刚定）——基数固定 **1,000 万**，必须写"10%–15% = 100–150 万"。**禁止用"组合加总已满"压低单标的的目标配置**（单标报告给理想权重，组合裁剪是另一类工作，总和允许超 1,000 万）。**禁止把分类规则里的"存疑 ≤1"读成"0"**：核心维度存疑 1 个即为 A 类，要降 B 必须写明"存疑 ≥2"或"命中否决项"。
28. **禁止在分类上用"看起来更严格"代替计数**（v3.4.9，腾讯暴露）：A 类要求存疑 ≤1、B 类要求 ≤2，**存疑 =1 时两者同时成立，必须判 A**。选 B 不是保守——B 的仓位硬上限 8% vs A 的 20%，"降一档求稳"的实际后果是把 12.8% 判成超配 60%、建议卖出四成仓位。**方向上的谨慎，后果上的激进。** 降 B 只能因为"存疑 =2"或"护城河与财务不能同时存疑"，不得写"因为某维弱"。
29. **禁止把默认值当有依据的值用**（v3.4.9）：持仓、成本、现金、基数、汇率五项缺失时，**必须写"未知（默认 X，若实际为 Y 则结论变为 Z）"**，不得静默采用零持仓/零成本。腾讯两版报告都按零持仓写，用户实持 12.8%、成本 404。
30. **禁止只在交付前自检**（v3.4.9，本轮最根本的一条）：本案例八处错误**全部发生在结论形成那一刻**，交付前的自检只抓到格式和算术。**必须前置：分类计数 → 输入清单 → 先验倾向 + 反向扰动 → 才允许写第一个价格。** 且报告必须写「如果这个结论错了，最可能是哪一步错了」——因为八处错误里我自己只发现了一处（且是唯一与先验相反的那处）。
31. **禁止只折现、不给增长率地把非经营性资产压进 H 档**（v3.4.10 立，**v3.4.11 改写——上一版这条写反了**）：非经营性资产（投资组合、联营、闲置土地）进入 H 档有两条合法路径：**① 按今天价值直加**（隐含假设「它的总回报 = 折现率」，NPV=0，中性）；**② 给增长率后再折现** `V×(1+g_inv)^n÷(1+r)^n`（g_inv=12% 时与①数学恒等）。**禁止的只有路径③：折现但不给增长**——那等价于假设它零回报。腾讯：`96.48÷1.12¹⁰=31.06` 属路径③，把 H12 从 **562.82 压到 496.10（−66.72 元）**；而上一版禁则 31 正是要求这么做的，**所以这条规则本身把一次"更严谨"的改动锁成了错误**。**判别法：写出你给这块资产的 g_inv。没写 = 默认 0 = 路径③ = 错。**
32. **禁止用「(终值+累计股息)÷现价 再开 n 次方」冒充 IRR**（v3.4.10）：那是把股息当成第 n 年一次性到账、且不计再投资，**系统性低估约 0.4 个点/10 年**。腾讯三情景：该算法给 12.45%，真 IRR 二分求解给 **12.79%**。凡是"现价对应 IRR"「情景 IRR」都必须二分求解 `P = Σ DPS_t/(1+r)^t + 终值/(1+r)^n`。**判别法：把股息项挪到第 0 期，看结果变不变——真 IRR 会变，伪 IRR 不变（它只除以 PX 一次）。**
33. **禁止在报告里只给一档 H 价**（v3.4.10）：口径一旦有两维（EBIT/FCF × 经营业务/含投资资产），就必须给矩阵，不许挑最好看的那一格写进结论。腾讯：H12 从 **339.07**（FCF 口径）到 **562.82**（EBIT 口径），**同一只股票同一天差 66%（224 元/股）**；只贴 464.42（经营业务口径）等于把「capex 算不算成本」和「资产算不算数」两个开关一起藏起来。
35. **禁止用「现价反解出的参数」回头算现价 IRR**（v3.4.13，两段式算法的自我陷阱）：两段式的 χ（防守性比例）、ρ（增量 ROIC）**一旦由现价反解得到，就不能再拿去算现价的 IRR**——那是把 ①「现价隐含什么」和 ②「现价值不值」当成同一个问题，结果永远等于折现率 12%。**正确用法**：χ 从外部证据取（行业对照、公司披露），ρ 从可验证的经营数据取，然后算出价格，再与现价比。**反解只用于「读市场预期」和「找出可证伪的命题」**（腾讯：现价隐含 χ≈25%/ρ≈11.5% → 验证方式「AI 收入能否覆盖 170 亿」）。判别法：**如果这个参数是我用现价算出来的，就不能用它反驳现价。**

34. **禁止用 H 档的点位做买卖判断**（v3.4.11，腾讯"现价刚好等于 H15"暴露）：H 档间距 = 久期 × hurdle 差，腾讯 10 年期、终值占 93%、久期 9.7 年 → **hurdle 每 1pct 移动价格 7.5%**。所以「现价恰好落在 H15 上、差 0.06%」这类观察**不含任何信息**：要求 14.5% 时价 416、15.5% 时价 393，同样"巧合"。**判贵贱只能用现价 IRR，不能用"离哪条线近"。** 且任何「跌到 X 就买」的阈值，必须同时写该价的 IRR。详见 4.1.3。

36. **禁止把「单一退出倍数下的 H 档价差」直接写成"便宜/贵 X%"**（v3.4.14，郎刚「464 怎么实现 12%」暴露）：H 档的分子里钉着一个退出倍数，**换掉它，"便宜 X%" 就换个数字**。腾讯：倍数 8.27×（市场当前）→ 12% 线 368.95、现价只贵 4.0%；15× → 562.82、现价"便宜 31.8%"。**同一个现价、同一句 12%，两个结论差 194 元。** 要求：报 H 档价格时**必须并列一张「退出倍数 → 应付价 → 现价 IRR」表**，并写出「这个便宜里有多少来自倍数修复」；只说倍数不改的结论句不得单独出现。判别法：**把退出倍数换成市场当前值，重算一遍——若结论从"便宜"翻成"贵"，那么原结论描述的是我的假设，不是这家公司。**

37. **禁止把①列（经营业务价）当股价用**（v3.4.14，同轮）：① 列剔除了非经营性资产，**股价里含着它**。腾讯 ①12 = 464.42，股价口径 12% 线 = 562.82（差 98.40）；**若股价真跌到 464.42，IRR 是 14.80% 而不是 12%**——白送了 98.40 的资产。① 列出现的每一处，必须紧邻「此列不可与股价直接比」。**同时禁止反向犯**：拿①列被稀释后的间距（18.6%）去论证间距机制，机制要纯经营口径（22.5%）。

38. **禁止省略「同一终值验伪」**（v3.4.14）：多档 H 档价格必须满足 `price(r) × (1+r)^n − 股息复利终值 ≡ 同一终值`。腾讯：464.42×1.12¹⁰ − 100.37 = 359.98×1.15¹⁰ − 114.28 = **1,342.04**。**两档之差不等于股息复利差 → 两档不在同一曲线上（g 或倍数没同步），是 bug。** 这条比残值拆解更早生效，因为它只要两档数字，不需要拆解表。**并且必须写明「几成来自股息、几成来自第 n 年一次成交」**（腾讯 7% / 93%），否则读者会把年化理解成"每年挣到"。

39. **禁止交付未经骨架闸的报告**（v3.4.16，郎刚「为什么你的四步法每次格式都不一样」）：每份四步法报告交付前**必须跑 `python3 scripts/report_lint.py <报告.md>`，R1–R13 任一 FAIL 不得交付**，且必须把 lint 输出贴在 §12。实测 14 份存量报告 **PASS 0**：双表制 14/14 缺、1,000 万绝对金额 12/14 缺、镜子测试 10/14 缺、最强反方 7/14 缺、H 档四档 1/14 缺。**"报告写完"不等于"报告合规"——没有 lint 输出的报告，一律视为草稿。**

40. **禁止用自创档替代 H 档、禁止把自创档混进表 A**（v3.4.16）：四步法档位只有 **H10/H12/H15/H17.46** 四个。另提价格（旧档案三梯队、gate.py 产出值、"我认可的区间"）必须 ① 标「自创档，非 H 档」② 写出与最近 H 档的金额差与百分比 ③ **只能进表 B**。平安 11-01 直接用「50/45/40」而四档一个没算、恒隆 10-31 用「我认可的 0.158–0.20」替换 H12 却不标注——**两处都是把判断伪装成方法。**

41. **禁止自创章节编号与节名**（v3.4.16）：固定 §1–§12（见「标准报告模板（硬骨架）」）。标的不适用某节时写「本节不适用 + 原因」，**不得删节、不得合并、不得把 §5 改叫「第三步·估值」**。存量报告实测混用四种风格（〇一二三 / 0.1.2. / §0 §1 / 无编号），导致跨标的横向对比与机械查漏都无法进行——**格式不统一的第一受害者是"能不能发现漏项"，不是美观。**

- **新增 4.1.6 规则六（写过两遍，第二遍才对）**：第一版要求「同段写清假设」——被郎刚一句**「你直接用更准确的描述胜过补警告」**否掉。**加警告是承认主句写错了；主句错就改主句。** 最终规范：① 主句必须是现价 IRR，不得是「现价低于 X 档」；② 章节标题与列定义必须自带口径定语（腾讯 3.2 由「四档」改为「四档上界」，② 列由「该付多少钱」改为「在 15× 接盘且 capex 归零的前提下该付多少钱」）。
- **顺带抓到一处算术错**：17.83% 与 12.05% 差 **5.8pct**，不是 7.2pct（7.2 = 17.83 − 10.61）。**同一组数字的差额在两份文件里用了两个基数——比算错更难查，因为两个数都「对」。** 已规定：同一差额只允许一个基数。
- **禁则 34 的推广**：不只「H 档点位不能做买卖判断」，**「四档全在现价之上」这个事实本身也不能做判断**——都是用**假设的位置**冒充**价值的高低**。判贵贱只用现价 IRR。
- **赔率账（本轮新增的决策语言）**：现价 384 买入 → 上行到 435（χ=0%）**+13.4%**、下行到 336（χ=50%）**−12.4%**、到 303.52 **−20.9%** → **1:1，A 类要 2:1**；且仓位 128/150 万已在区间 56%。**加仓线 336、重仓线 303.52。**
- **一句话留给以后的自己**：**「384 是市场和我算得一样准的价格，不是市场算错了的价格。」** 报告里凡是出现「低于 N 档」，都必须能接上这句话的下半句。
