# 股票池经营驱动力拆分

日期：2026-10-07。讨论底稿，不是估值、评级或调仓建议。

## 本次修正

上一版把经营地域、公司质量和股东回报混在同一分类里，未直接回答：国内经济继续偏弱，公司的利润为什么还能维持或增长？本版改用用户提出的经营驱动力维度，允许公司跨类，优先拆核心业务，不强行给整个集团贴唯一标签。

使用上一轮已确认的当前28家公司名单，A/H合并；历史扩展6家单列；美的不纳入。依据上一轮公司公告与工作底稿，本轮重点复查腾讯、迈瑞、安踏、茅台及部分消费公司的2026中报。未逐家公司重新做全部审计，不声称本轮确认每个细分行业处于上行。名单、网站、价格线、SOP、原评级均未修改。

## 四个主要维度与一个必要补充

1. 国内优势业务、需求相对抗压：必要消费、基础服务或高黏性使用需求，使经营较少依赖收入和信用扩张。没有公司完全经济免疫；需求稳定也不保证价格、利润和股价稳定。
2. 全球竞争与外部需求对冲：已实现的海外或最终海外需求，可以分散国内影响。海外利润和现金权重未核时，不认定集团已对国内不敏感；国内客户出口与直接海外销售须区分。
3. 国内经济敏感：利润明显受信用、地产、广告预算、高端消费或可选耐用品影响。优秀龙头也可能在此类，但敏感程度不同，不等于坏公司或必须等待复苏才能盈利。
4. 国内结构性上行：需求渗透、份额集中、新产品或业务效率改善，有机会抵消宏观弱势。分清行业需求上行、公司抢份额和渠道铺货；增长不等于现金改善。
5. 补充全球周期：全球商品或产品价格驱动，既不是国内复苏，也不是经济抗压。

## 第一维度：国内优势业务、需求相对抗压

| 公司/业务 | 判断 | 不可省略的边界 |
|---|---|---|
| 中国移动基础通信 | 本池最清晰的候选之一；连接与基本通信需求相对稳定 | 资费、竞争、算力投入和资本回报仍可影响利润 |
| 长江电力存量水电 | 本池最清晰的候选之一；资源成本与基础电力需求 | 用电量、电价、来水和债务不是常数，不等于公司控制定价 |
| 海天家庭调味业务 | 相对抗压，不列绝对防守；低单价、高频、渠道优势 | 餐饮业务受影响更大，渠道竞争与库存可影响整体盈利 |
| 腾讯社交生态/部分成熟游戏 | 高黏性生态是抗压基础；仅业务层面判断，不把整个集团列入最强防守 | 广告和支付与国内经济相连，游戏也非必需消费，AI投入另算 |

跨类：农夫包装水、伊利基础营养需求也有抗压成分，但价格、份额、行业成熟与集团其他业务可能削弱盈利抗压，不能仅按销量必需性判为稳定现金牛。康臣疾病需求偏刚性，但公司份额、治疗替代及医保政策另有风险。

## 第二维度：全球竞争与外部需求对冲

| 公司 | 对冲机制 | 不能误读为国内经济免疫 |
|---|---|---|
| 福耀玻璃 | 全球车厂、生产与供货体系，工艺认证和份额 | 全球汽车周期、车厂议价和资本投入仍有影响 |
| 迈瑞医疗 | 国际装机、渠道、设备与耗材；国际业务已有较大规模 | 国内医院采购与医保影响仍然真实存在 |
| 宁德时代 | 全球动力/储能客户、技术与供应链能力 | 国内新能源汽车和储能仍重要；海外布局不等于海外利润已占主导 |
| 宇通客车 | 出口渠道、产品与本地化服务 | 国内公交采购、海外项目回款和本地化投入仍须验证 |
| 扬农化工 | 全球农业供应链，部分需求由海外农药市场驱动 | 全球农药供需、品种价差与扩产，比出口标签更影响利润 |
| 小商品城 | 国内市场服务国际采购与贸易，最终需求有外部来源 | 不等于海外生产企业；关税、贸易结算和资本占用重要 |

其中福耀、迈瑞的全球经营分散特征相对清晰；其余是不同程度的对冲，不一概认定“国内影响小”。迈瑞2026H1国际收入增长13.67%，占比约53%，国内收入下降1.61%，说明国外业务能对冲国内压力，但不能证明整个集团不受国内影响。[迈瑞2026中报](https://static.cninfo.com.cn/finalpage/2026-08-29/1225529856.PDF)

跨类：腾讯国际游戏属于此维度；泡泡、名创已有海外业务，但国内外零售周期及股东现金须各自验证；携程国际平台也有对冲作用，中国用户出境仍不能算完全独立于国内收入的需求。

## 第三维度：国内经济敏感，按传导机制区分

| 传导机制 | 公司 | 判断边界 |
|---|---|---|
| 地产、新房、装修 | 华润置地、伟星新材 | 敏感较直接；华润开发与商场租赁分开，伟星新房与存量装修分开 |
| 信用、资产价格、居民金融活动 | 招商银行、中国平安 | 国内经济敞口较强；银行信用成本与寿险经营/投资端不混用 |
| 企业广告预算 | 分众传媒 | 预算与消费品牌投放相关；份额和效率改善可能抵消部分压力 |
| 高端或可选消费 | 贵州茅台、东阿阿胶、格力电器 | 品牌与现金优势不等于经济免疫；茅台需求及渠道、阿胶终端动销、空调更新及地产需求分别看 |
| 成熟消费与可选旅行 | 伊利股份、携程集团 | 中等/混合敏感，不与地产开发风险等量齐观；液奶价格和产品结构、旅行预算及国际平台分别看 |

茅台属于“强品牌但需求与价格仍敏感”，不属于“下行也不受影响”。2026H1归母净利润同比下降1.95%，是反对绝对免疫标签的当期证据，不据一个半年直接断言护城河毁损。[茅台2026半年报](https://static.cninfo.com.cn/finalpage/2026-08-15/1225475868.PDF)

跨类：安踏主品牌/FILA的可选消费、腾讯广告/支付、海天餐饮业务，都有此维度。分类评价的是盈利传导机制，不是新增资金或卖出资格。

## 第四维度：国内结构性上行，已实现证据与候选分开

| 公司/业务 | 可以抵消弱宏观的驱动力 | 状态与反证 |
|---|---|---|
| 安踏其他品牌中的户外业务 | 户外需求、品牌渗透与份额扩张 | 有公司增长证据，但不能将其他品牌全部增长归为户外行业扩张，亦不能把全集团视为同速增长 |
| 农夫山泉茶饮料 | 茶产品结构、渠道与份额增长 | 相对包装水更有结构增长特征；市场总量、动销和公司份额增长尚须拆开，不能永久外推 |
| 康臣肾科业务 | 慢病治疗需求、诊疗覆盖与公司渗透 | 结构增长候选；疾病人数不直接等于公司收入，医保/治疗替代/税率重要 |
| 恒瑞创新药 | 创新品种放量、研发转化与海外授权 | 结构增长候选；海外一次性首付款、潜在里程碑不等于经常性现金 |
| 泡泡玛特国内IP业务 | IP渗透、产品创新及用户覆盖 | 待验证耐久，不能按单次爆品或开店断言市场持续上行；海外业务另看 |
| 名创优品新业务/产品结构 | IP商品与新业务的增长机会 | 待验证；新店增收不等于同店、利润和市场需求共同上行 |

安踏2026H1主品牌收入增长4.8%，FILA增长6.1%，其他品牌增长44.2%；这直接说明应拆品牌看，而不是统一贴“国内复苏”或“国际品牌”标签。数据证明公司各品牌增长不同，不单独证明整个户外市场同比增长44.2%。[安踏官方2026H1业绩](https://ir.anta.com/en/news_detail.php?id=167844)

腾讯AI广告效率可另作结构增长观察点：2026Q2营销服务收入增长22%，公告称AI推荐及投放工具提供支持。这是当前公司经营证据，不证明广告行业总预算正在增长；算力现金投入也不能忽略。[腾讯2026中报](https://www.tencent.com/wp-content/uploads/2026/08/E700_IR.pdf)

泡泡、名创的海外零售收入和国内新业务增长，不足以确认股东现金耐久。本轮不把两家公司从“候选”升级为已验证的结构复利。[泡泡2026中期公告](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0820/2026082000354_c.pdf)、[名创2026H1公告](https://www.sec.gov/Archives/edgar/data/1815846/000110465926103582/tm2624284d1_ex99-2.htm)

## 必要补充：全球周期，不硬塞进四类

| 公司 | 驱动力 | 风险 |
|---|---|---|
| 中国海洋石油 | 全球油价、资源成本、储产和资本投入 | 不押国内复苏，不代表抗全球衰退或分红稳定不变 |
| 万华化学 | 全球化工供需、MDI竞争力与新项目 | 技术/成本优势与全球产品价格周期共存；海外比例不能代替中周期自由现金 |

## 历史扩展六家

- 三花：全球客户对冲国内影响；热管理/机器人结构机会另证，汽车与设备周期仍存在。
- 紫金：全球资源周期，不归国内抗压。
- 神华：主要国内能源需求与煤价周期，股息作用另在第四步验证。
- 宁沪：国内交通收费现金，成熟业务相对抗压，但交通量、收费期限、改扩建和债务仍会影响股东现金；不按地方国企身份推定财政依赖。
- 港交所：成交、融资及中国资产风险偏好，兼有国际业务；不是工业出海或绝对抗压。
- 东鹏：国内渠道扩张、份额及产品渗透，结构增长候选，不能把全国化公司增长直接当细分行业增长。

## 对投资研究的用途

重点问题改为：“在国内宏观不改善的假设下，靠什么维持或提升每股可分配现金？”第一类可能服务股息与稳定，第二类分散国内需求，第四类提供潜在增长；第三类仍可投资，但不能把宏观恢复作为未加验证的基准；全球周期必须用中周期而非景气峰值。

每家公司只保留三项轻量检查：主要增长源；宏观不改善时该增长源是否仍成立；利润是否转成投入后的股东现金。无需新增综合打分或重复重估全部价格线。
