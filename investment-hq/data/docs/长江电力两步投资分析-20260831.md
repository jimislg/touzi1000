# 长江电力两步投资分析

> 数据截止：2026-08-31；2026-08-28收盘28.05元。

## 结论

公司质量B+：不可复制的梯级水电资产、低边际成本和长期电力需求使经营持续性强；但无自主定价权、高杠杆、来水与资本配置限制回报。现价性价比C：28.05元基准十年IRR约6.0%，当前不买。

## 好公司

- 2025收入862.42亿元、归母利润345.03亿元、经营现金流605.63亿元、EPS1.4101元。
- 2025全年DPS为1.00元，由中期0.21元和期末0.79元组成，派息率70.92%；不是只分0.79元。
- 2026H1收入379.29亿元、归母利润147.56亿元、扣非142.94亿元；境内六座梯级电站发电量1327.44亿千瓦时、同比+4.81%。
- 财务并非无风险：2025资产负债率58.27%、财务费用93.71亿元，稳定股息依赖持续经营现金流和低融资成本。
- 与茅台比较：水电资源稀缺性与经营寿命极强，但无提价权、资本密集且利润受来水影响，不应按茅台估值。

## 好价格

基准假设为EPS年增4%、派息率70.92%、期末18倍PE。现价5年/10年IRR约5.4%/6.0%。反推十年买入价：8%回报23.2元，10%回报19.3元，12%回报16.1元。

执行：≤23元累计2%，≤19元累计4%，≤16元累计5%上限。当前不买。原25/23/20元建仓表作废。

## 主要风险

流域来水和气候波动、综合电价下降、电力市场化、高杠杆、低回报抽蓄或海外并购、重大安全和生态事件。
