# 中国移动两步投资分析

> 数据截止：2026-08-31；H股2026-08-28收盘79.40港元，A股97.86元。港股通股息按20%税率测算。

## 结论

公司质量B：高质量成熟现金牛，适合后期股息发动机，不承担本金快速做大的主任务。现价性价比C：H股79.40港元的基准十年IRR约6.4%，A股因约42%溢价排除。

## 好公司

- 护城河：频谱、全国网络、渠道、客户规模和监管牌照形成高壁垒，但没有消费品式定价权。
- 财务：2025收入10501.87亿元、归母利润1370.95亿元、EPS6.35元、自由现金流820亿元；DPS5.27港元、派息率75%。
- 最新变化：2026H1归母利润789.34亿元、同比-6.3%，自由现金流539亿元；应收账款由997.62亿元升至1222.39亿元，91天以上账龄恶化，是最重要预警。
- 与茅台比较：需求更刚性、当期股息更高，但定价权、资本强度、增长和股东导向明显弱于茅台。

## 好价格

基准假设为EPS年增2%、派息率75%、期末11倍PE、港股通股息税20%。现价5年/10年IRR约7.2%/6.4%。反推十年买入价：8%回报68.4港元，10%回报56.9港元，12%回报47.5港元。

执行：只选H股；≤68港元累计2%，≤57港元累计5%，≤48港元累计8%上限。当前不买。

## 主要风险

传统通信低增长、资费监管、政企和云业务长账龄应收、AI算力资本开支不能转化为足够ROIC、国企政策目标影响资本配置。
