# 中国经济周期与关注公司景气定位

**数据截止：2026-08-30**  
**主要观察窗口：2025年报、2026年半年报及2026年7月宏观数据**

## 一、结论先行

中国目前不是全面复苏，也不是所有行业同步衰退，而是处于：

> **地产与居民信用收缩的中后段、总需求下行接近底部但尚未确认反转；同时制造出海、AI、储能、资本市场和部分创新产业处于结构性上行。**

可以称为“**K型周期**”：

- 地产、传统消费、民间投资、价格敏感型制造继续下行；
- 高技术制造、设备更新、AI算力、储能、创新药、资本市场交易景气上行；
- 消费内部也分化：白酒、家电、传统广告偏弱，情绪IP、运动品牌龙头和旅行体验仍有局部增长。

因此，不能再使用“消费股”“制造股”这样的大类标签，而要同时判断：

1. 行业处在什么周期；
2. 公司是否凭借份额、国际化或新品穿越行业周期；
3. 利润增长来自真实经营、汇率、投资收益还是一次性项目；
4. 股价是否已经提前反映上行。

## 二、中国经济处于什么周期

### 1. 总需求：仍在下行，尚未确认底部反转

| 指标 | 最新状态 | 周期含义 |
|---|---:|---|
| 2026H1 GDP | +4.7%；Q1 +5.0%，Q2 +4.3% | 增长边际放缓 |
| 2026年7月社零 | +0.6% | 商品消费明显偏弱 |
| 1—7月社零 | +1.2% | 消费尚未形成强复苏 |
| 7月制造业PMI | 49.2 | 制造业环比收缩 |
| 7月制造业新订单 | 48.5 | 需求弱于生产 |
| 1—7月固定资产投资 | -6.7% | 总投资下行 |
| 1—7月民间投资 | -9.4% | 企业信心与回报预期偏弱 |

证据来源：[国家统计局上半年经济数据](https://www.stats.gov.cn/sj/xwfbh/fbhwd/202607/t20260715_1964121.html)、[7月社零](https://www.stats.gov.cn/xxgk/sjfb/zxfb2020/202608/t20260817_1965052.html)、[7月PMI](https://www.stats.gov.cn/sj/zxfbhjd/202607/t20260731_1964253.html)、[1—7月固定资产投资](https://www.stats.gov.cn/xxgk/sjfb/zxfb2020/202608/t20260817_1965054.html)。

### 2. 房地产：仍在深度下行，只出现局部价格企稳

2026年1—7月：

- 新建商品房销售面积下降11.8%；
- 销售额下降13.1%；
- 新开工面积下降24.0%；
- 房企到位资金下降20.3%；
- 一线城市房价局部企稳，但二三线城市仍然下降。

房地产仍是居民资产负债表、地方财政、银行信用和耐用品消费的主要拖累。[房地产数据](https://www.stats.gov.cn/sj/zxfb/202608/t20260817_1965053.html)、[70城房价解读](https://www.stats.gov.cn/xxgk/jd/sjjd2020/202608/t20260817_1965046.html)。

### 3. 价格：生产资料再通胀，但不是全面需求复苏

7月CPI同比仅上涨0.5%，PPI同比上涨3.5%。PPI上涨主要集中于能源、有色、化工等上游，7月制造业出厂价格指数却只有47.8，说明成本上涨尚未顺利传导到广泛终端需求。

因此当前更接近“**上游价格修复+下游需求偏弱**”，而不是典型的全面再通胀繁荣。[CPI](https://www.stats.gov.cn/sj/zxfbhjd/202608/t20260809_1965008.html)、[PPI](https://www.stats.gov.cn/sj/zxfbhjd/202608/t20260809_1965007.html)。

### 4. 结构性景气：高技术、装备制造和资本市场上行

7月高技术制造业PMI为53.3、装备制造业为51.4，而消费品行业PMI只有47.8。设备工器具购置投资仍增长9.0%，信息传输业投资增长26.0%。

香港市场上半年日均成交额增长17.8%，IPO融资额增长92.1%，说明资本市场处于明确的交易景气上行期。[PMI结构](https://www.stats.gov.cn/sj/zxfbhjd/202607/t20260731_1964252.html)、[香港市场2026H1](https://www.hkexgroup.com/Media-Centre/Insight/Insight/2026/HKEX-Insight/Hong-Kong-Markets-H1-2026-Update?sc_lang=zh-HK)。

## 三、行业周期地图

| 行业 | 当前周期 | 判断 |
|---|---|---|
| 房地产、建材、家装 | 深度下行 | 销售、新开工、资金均未企稳 |
| 高端白酒 | 下行 | 商务需求和渠道利润收缩，直营替代批发 |
| 白色家电 | 下行分化 | 国内换新支撑有限，出口走弱；美的好于格力 |
| 传统品牌广告 | 下行接近底部 | 广告主预算仍谨慎，收入尚未恢复 |
| 银行 | 下行后段/弱修复 | 净息差继续收窄，但财富管理和优质银行营收修复 |
| 保险 | 早期修复 | 新业务价值和权益投资改善，仍受长端利率约束 |
| 证券、交易所 | 明确上行 | 成交量、IPO、互联互通放量 |
| AI、游戏、数字广告 | 上行 | AI提升广告效率，游戏产品周期向上，但资本开支激增 |
| 动力电池、储能 | 强上行 | 出货、产能利用率、龙头份额同步提高 |
| 汽车整车 | 下行 | 价格战、换代和研发投入压低盈利 |
| 汽车零部件 | 分化/弱上行 | 全球份额与单车价值提升可抵消整车周期 |
| 客车 | 后周期高位 | 国内销量承压，出口和新能源结构仍上行 |
| 化工 | 周期反弹 | 价格与销量回升，但产能和原料波动仍大 |
| 创新药 | 结构上行 | 创新药收入和出海授权增加，传统仿制药继续出清 |
| 医疗器械 | 底部修复 | 国内采购拖累减弱，海外增长支撑，利润尚未转正增长 |
| 运动服饰 | 行业弱、龙头上行 | 大众消费偏弱，但多品牌和国际化龙头继续夺份额 |
| 潮玩IP | 结构性上行、区域分化 | 国内逆势扩张且门店效率提升；海外正由线上流量红利切换到线下门店和本地化基建 |
| 旅游OTA | 国内降速、国际上行 | 旅行需求仍有韧性，国内合规整改压低利润率 |
| 电信运营商 | 稳定防御 | 传统通信成熟，算力增长，现金流和分红稳定 |
| 外贸综合服务 | 上行但现金波动 | 市场租赁、贸易平台和跨境支付增长，受贸易政策影响 |

## 五、对当前组合执行的含义

### 1. 不应按原目标仓位机械补满

原目标组合中茅台25%、安踏8%、泡泡玛特7%，直接消费暴露达到40%。其中茅台处于下行；泡泡玛特国内业务逆势扩张，但海外仍在验证门店效率与本地化能力；安踏虽上行但仍受中国消费环境约束。

因此现阶段不应因为公司质量高，就立即把三者全部补到目标仓位。

### 2. 当前更适合优先研究的三类资产

1. **结构性上行且护城河较强**：腾讯、宁德时代；
2. **底部修复且估值仍可控**：招商银行、中国平安、迈瑞医疗；
3. **防御现金流**：中国移动。

香港交易所、万华化学虽然经营上行，但均为高周期资产。越到上行阶段，越不能因利润增速高而追高。

### 3. 应等待经营拐点而非只等股价的公司

- 茅台：批发渠道降幅收窄、核心产品批价和渠道库存稳定、净利润重新增长；
- 格力：收入恢复正增长，海外业务止跌；
- 分众：收入与扣非利润同时转正；
- 东阿阿胶：核心系列收入与经营现金流同时改善；
- 理想：交付、毛利率、自由现金流三者同时修复。

## 六、最重要的纪律

> **行业上行不等于可以买，行业下行也不等于必须卖。**

- 上行期容易出现峰值利润和估值透支，例如万华、港交所；泡泡玛特则要把国内结构性增长与海外建设期成本分开估值，不能只看合并利润增速；
- 下行期才可能出现最好的买价，但必须区分“周期下降”与“护城河损坏”，例如茅台和格力；
- 你的目标是5年2倍、10年5倍，要求年化收益分别约14.87%和17.46%。多数防御型公司只能降低组合回撤，不能单独完成目标；高增长公司也必须在有安全边际的价格买入。

## 七、需要持续跟踪的宏观拐点

只有以下四项至少三项连续三个月改善，才可以认为中国总需求进入比较可靠的上行周期：

1. 制造业新订单指数持续高于50；
2. 社零增速恢复至4%以上且不依赖单一补贴品类；
3. 民间固定资产投资转正；
4. 商品房销售额降幅收窄至5%以内，并伴随居民中长期贷款改善。

在此之前，组合应保持“结构性上行+防御现金流+等待深度价格”的配置思路，而不是押注全面消费复苏。

## 数据局限

- 宏观数据与公司财报存在时间差，周期判断是概率结论，不是精确择时信号；
- 部分公司利润受汇率、会计口径、投资收益和并表影响，本文优先参考扣非利润及经营现金流；
- 本文只判断经营周期，不代表当前股价具有安全边际，买入价仍需单独倒算。
