## 一、结论

**买点 3.242 HKD｜卖点 9.726 HKD｜现价 4.425 高 36.5% → 不买。**

| 项 | 值 | 说明 |
|---|---:|---|
| 常态利润（取法一） | 39.944 亿元 | FY2026 归母，当年值 |
| 三年后净利（g=5%） | 46.24 亿元 | |
| 合理 PE | 17.41× | 动态锚 5.745%，见 §四 |
| 合理估值（三年后） | 804.88 亿元 → **税后 643.90** | 港股通 20% 打在分子 |
| 合理估值（每股） | **6.484 HKD** | 现价比它低 31.8% |
| **买点（合理估值 × 50%）** | **3.242 HKD** | |

**一句话**：按原教旨，现价贵 36.5%。但这句话有一个前提必须先说清楚——**唐朝法不给账上现金估值**，而波司登账上有 156 亿元净现金（占市值 35.5%）。把这个开关打开，买点从 3.242 跳到 4.301，现价只贵 2.9%。**这个标的的结论，一半取决于你怎么看那 156 亿。**

## 二、取法判定（v5.5 的核心动作）

v5.5 把「用哪种常态利润」变成必须先回答的问题，判据只有一句（原书第 20 章老唐自述）：**当前利润是不是周期位置给的假象。**

| 检验项 | 事实 | 判定 |
|---|---|---|
| 十一年净利同比 | +39.5%、+57.1%、+59.4%、+22.6%、+42.1%、+20.6%、+3.7%、+43.7%、+14.3%、+13.7% | **无一年为负** |
| 最低增速年 | FY2023 +3.7%（疫情尾声），不是崩塌 | 通过 |
| 当前利润位置 | FY2026 39.944 亿 = 历史最高，但由十一年单调增长堆出来 | **非周期顶部** |
| 外生价格依赖 | 羽绒服售价由公司定（品牌定价），羽绒原料成本波动可由提价与产品结构对冲 | 不随商品周期摆动 |
| 天气风险 | 暖冬影响销量，但属随机扰动而非周期；连续两年暖冬 FY2026 仍 +13.7% | 不构成周期 |

**判定：取法一（稳定型）——当年利润推三年，买点 ×50%、卖点孰低。**

> 反例对照：如果这是海天（注塑机，2022 年营收 −23.2%）或陕煤（煤价随宏观大幅波动），就要走取法二用十年平均。波司登不是——它的问题是**增速在降**（+43.7% → +14.3% → +13.7% → FY2027H1 +4.5%），不是**利润在摆**。这两件事在唐朝法里对应完全不同的处理：前者影响 g，后者影响用不用当年值。

## 三、三大前提（筛子，不过就放弃）

| 前提 | 事实 | 判定 |
|---|---|---|
| **利润为真** | 净现比 FY2024 235% / FY2025 112% / FY2026 159%；三年平均 FCF 51.39 亿 = 三年平均净利 35.27 亿的 **146%** | 通过。FCF 高于净利，靠的是负营运资本（应付账款 86.88 亿，无息占用供应商资金） |
| **利润可持续** | 连续 31 年销量第一；羽绒服复购周期长但品牌心智稳固；FY2027H1 中期业绩连续 9 年创同期新高 | 通过。但要标注：主品牌 FY2027H1 收入 **+0.2%**，可持续性正在被测试 |

三条全过 → 可以估价。

## 四、估值过程

### 4.1 合理 PE：动态锚 17.41×

| 项 | 值 | 来源 |
|---|---:|---|
| 历史正常利率锚 | 3.83% | 近 10 年 10Y 国债 2.82% 与 AAA 企业债 3.83%，取较大 |
| 安全上浮 | ×1.5 | 郎刚 2026-11-20 裁定 |
| 要求回报 r_eff | **5.745%** | |
| 合理 PE | **17.41×** | 1 ÷ 5.745% |

> 原书字面是「用当下 1/r」，动态锚是偏离原书的实践口径，已在 SKILL v5.3 标注。

### 4.2 三年后净利：g = 5%

| 依据 | 数值 |
|---|---:|
| 券商一致预期 FY2027–29 | 平安 42.9/45.8/48.8 亿（+7.3%/+6.8%/+6.5%）；申万 42.7/45.7/48.5 亿 |
| FY2027H1 实际 | 营收 +1.97%、归母 +4.46%、**主品牌 +0.2%**（上年 +8.3%）、门店净减 145 家（−4.0%） |
| 采用 g | **5%**（低于一致预期 1.5–2.3pct） |

三年后净利 = 39.944 × 1.05³ = **46.24 亿元**

### 4.3 从合理估值到买点

```
三年后合理估值 = 46.24 × 17.41 = 804.88 亿元
税后（港股通股息 20%）      = 804.88 × 0.80 = 643.90 亿元
买点 = 643.90 × 50%         = 321.95 亿元 = 3.242 HKD/股
卖点 = min(643.90×150%, 39.944×50) = min(965.85, 1997.2) = 965.85 亿元 = 9.726 HKD
```

> **为什么税打在分子**：1/r 的估值隐含「利润全部分给股东」，而这笔分红对港股通投资者要扣 20%，所以分子先砍 20%，PE 不变。这与 A 股长期持有（免税）的差别是：同一家公司、同一份财报，A 股口径买点 4.053 HKD（高 9.2%），港股通口径 3.242 HKD（高 36.5%）。**20% 的税让买点下降 20%。**

### 4.4 cash_ratio = 1.0（不打折）

三年平均 FCF/净利 = 146% > 1，净利本身已是自由现金流的下界。不需要按原书陕煤案例打八折——那是给「净利含水分」的公司用的，波司登相反，现金流比利润还多。

> 谨慎项：FY2027H1 经营现金流 −19.9 亿（同比恶化 83%），是旺季备货 + 赎回理财买存货所致。9 月末是备货峰值，全年 OCF 仍可能转正，但要盯。

## 六、净现金口径对照（附录，不改买点）

这是本次分析最需要说清楚的一段。唐朝法原教旨**不剥离净现金**，但波司登的现金占比高到不能装作看不见：

| 项 | 金额（亿元） | 出处 |
|---|---:|---|
| 现金及现金等价物 | 29.770 | 年报 |
| 定期存款（流动 34.807 + 非流动 13.900） | 48.707 | 年报附注 |
| 其他金融资产（流动 81.357 + 非流动 5.729） | 87.086 | 年报附注 14；管理层确认是银行理财/结构性存款 |
| 减：计息借贷 | −9.570 | 年报附注 |
| **净现金** | **155.99** | 已抵押存款 4.034 亿受限，不计 |
| 占市值 | **35.50%** | 439.45 亿元 |
| 税前净利息收入 | 3.39 | 经营溢利 52.94 → 税前 56.33 |

**剥离后买点（同一把尺子，只换现金口径）：**

| 净现金处理 | g=3% | g=5% | g=7% |
|---|---:|---:|---:|
| 不剥离（原教旨） | 3.060 | **3.242** | 3.431 |
| 全额加回 | 4.445（低 0.4%） | 4.615（低 4.1%） | 4.792（低 7.7%） |
| 八折加回 | 4.130（高 7.1%） | **4.301（高 2.9%）** | 4.478（低 1.2%） |

**结论翻转**：不剥离是「贵 36.5%」，八折加回 g=5% 是「贵 2.9%」，全额加回 g=3% 是「便宜 0.4%」。**同一个公式、同一份财报，只换一个开关，结果从「贵三成」变成「基本持平」。**

**为什么唐朝法会这样**：它不给现金估值，但现金产生的 3.39 亿利息收入又计入利润、被打八折、再扣 20% 税。等于对账面 156 亿现金只给了 `3.39×(1−28.2%)×(1−20%)×17.41 = 33.9 亿` 的估值——**账面 156 亿，只算 34 亿，隐含 78% 的折扣**。这不是算错（现金只赚 2.2%，而你要求 5.745%，现金确实是拖累），而是框架里没有「净现金」这个开关。

> 按纪律，本报告**不修改唐朝法口径、不用剥离结果当买点**。上面的表只作披露，让你知道 3.242 这个数字里有多少来自「现金不算钱」。

## 七、风险与盯盘

**先说不买的理由**（不只是「贵 36.5%」这一条算术）：

1. **主品牌停滞**。FY2027H1 波司登主品牌收入 57.30 亿，同比 **+0.2%**（上年同期 +8.3%）。增量来自雪中飞（+9.1%，毛利率 47%）、贴牌（+5.9%，毛利率 18.4%）、线上（+11.3%）——**都是低毛利或低单价的口子**。这是「用毛利率换收入」的结构。
2. **毛利率首次跌破 50%**。FY2027H1 49.3%（−0.7pct）。公司归因于贴牌占比上升与女装毛利率 −11.9pct，但结果是整体盈利结构在稀释。
3. **高端化没跑通**。AREAL（Kim Jones 联名，2,000–5,999 元）天猫月销不过百件；同期 399 元平价羽绒服（山姆、胖东来、北大文创）卖到断货。中间价格带被两头挤。
4. **暖冬是基准情景**。国家气候中心定调 2026/27 全国气温总体偏高、前冬冷后冬暖、超强厄尔尼诺。双 11 那波爆单是寒潮与大促窗口重叠，属需求前置。
5. **门店在减**。3,502 家，较财年初净减 145（−4.0%），其中自营 −100。渠道从「铺得多」转向「开得好」是对的，但短期是收入拖累。

**盯这四个数**（任一变化都会改结论）：

| 指标 | 当前 | 阈值 |
|---|---|---|
| 派息率 | 77.8%（公告 80.2%） | 提到 90%+ 或特别分红 → 现金开始分配，四步法结论可能翻 |
| 主品牌收入增速 | +0.2%（FY2027H1） | 回到 +5% 以上 → g=5% 假设坐实 |
| 全年毛利率 | 57.2%（FY2026） | 跌破 55% → 合理价下修到 4.4 附近（见 §五 敏感性） |
| 净现金去向 | 156 亿 | 出现大额并购/理财规模首次下降/首次特别分红 |

## 八、方法边界（三句话）

1. **这是「不该买」，不是「该卖」**。现价距卖点 9.726 还有 120% 空间，离卖点极远。
2. **唐朝法在这里的最大不确定性不是 g，是净现金**。g 从 3% 到 7% 买点只动 12%；现金口径一换买点动 33%。**参数敏感性小于口径敏感性**，这在别的标的上不常见。
3. **不构成仓位建议**。唐朝法原教旨不给仓位、不算 IRR、不折现；配对结论见同目录《波司登-20261128-四步法.md》。
