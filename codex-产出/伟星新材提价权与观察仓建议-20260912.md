# 伟星新材提价权与观察仓建议

> 研究日期：2026-09-12  
> 财报截止：2026年半年报  
> 行情截止：2026-09-11收盘，8.21元  
> 决策边界：以下是观察仓确认草案，尚未写入正式观察名单，不涉及买入或仓位调整。

## 一、结论

**伟星新材有品牌溢价和成本传导能力，但没有得到充分验证的持续主动提价权。**

它更接近“原材料上涨时能够转嫁成本、需求疲弱时能够少降价”的公司，而不是茅台那种能够主动提价并基本不损失销量的公司。

**建议纳入零持仓研究观察仓，但当前不买。** 原因是公司质量达到B+，值得等待；但8.21元对应基准10年IRR约5.17%，不符合当前把本金做大的目标。

## 二、把“提价权”拆开看

| 能力 | 判断 | 证据 |
|---|---|---|
| 品牌溢价 | 强 | 2025年PPR毛利率54.92%，显著高于PE的30.23%和PVC的26.83%；消费者为品牌、安装、试压和售后付费 |
| 成本传导 | 中等偏强 | 2021年原材料上涨时，公司披露零售业务提价基本能够覆盖原材料涨幅；工程业务则按订单定价 |
| 弱需求下稳价 | 中等 | 2024年零售核心产品价格总体稳定，但部分市场和产品为拓展市场进行了调整；2025年目标仍是“保持价格体系相对稳定”，而不是提价 |
| 超过成本的主动提价 | 弱、未验证 | 公司曾披露上市以来PPR最大一次价格调整发生在2012年，之后基本没有大幅调整；长期利润更多依靠份额、结构、服务与成本，而不是连续提价 |
| 提价后不丢销量 | 暂无证据 | 2025年PPR收入下降15.20%、毛利率下降1.55个百分点；2026H1 PPR收入又下降4.55%、毛利率下降1.40个百分点至56.13% |

### 关键辨析

伟星的护城河是真的，但核心不是“管子不可替代”，而是：

1. 水管占装修总成本很低，漏水造成的损失却很高，消费者没有必要为几十或几百元差价承担风险；
2. 消费者通常缺乏鉴别能力，水电工、工长、家装公司和经销商的推荐影响很大；
3. “星管家”将产品、安装、试压和售后组合起来，降低了质量责任不清的风险；
4. 全国3万多个网点和50多家销售公司，让竞争者不仅要复制产品，还要复制渠道管理和服务执行。

因此，伟星可以长期保持相对同行的价格溢价。但日丰、金德、公元、中国联塑等也能提供合格产品，消费者又不是高频主动购买者，所以伟星并没有垄断式提价权。

## 三、财务证据对提价权的约束

- 2025年制造业收入53.50亿元、销量37.47万吨；2024年分别为62.22亿元、39.88万吨。按统一口径计算，混合产品收入/吨由约1.56万元降至约1.43万元，下降8.49%。由于产品组合不同，这不能直接等同于PPR降价，但足以说明2025年不存在全产品线的普遍提价。
- 2026H1 PPR收入8.90亿元，同比下降4.55%；成本下降只有1.40%，毛利率因此下降1.40个百分点至56.13%。这更像用高毛利承受需求压力，而不是通过提价扩大单位利润。
- 2026年1月公司仍明确表示需求疲弱、行业价格战激烈，经营目标是通过产品和服务增强竞争力、使价格体系逐步稳定。管理层自己的表述也是“稳价”，不是“提价”。

**判断：伟星的定价权应记为“B级有限定价权”。** 若估值模型把利润增长建立在持续涨价上，会高估公司；基准模型只应采用2%—3%的长期增长，其中主要来源应是份额、产品组合和同心业务，而不是单价持续上涨。

### 升级条件

1. PPR收入连续两个报告期止跌或恢复增长；
2. PPR毛利率稳定在55%左右，且不是依靠原料价格单独下降；
3. 扣非净利润恢复增长，经营现金流继续覆盖扣非利润和资本开支；
4. 松田程实现盈亏平衡，净水、防水等业务没有持续吞噬现金；
5. 价格达到5.01元以下才重新研究，达到4.12元以下才竞争正式资金。

### 降级条件

1. PPR收入和扣非利润连续两期双位数下降；
2. PPR毛利率跌破50%，或需要普遍降价才能维持份额；
3. 经销渠道库存、返利或应收明显恶化；
4. 高分红开始依赖持续消耗净现金；
5. 同心业务与并购投入扩大，但三年内不能证明增量ROIC。
