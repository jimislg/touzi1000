# 《两步分析法：好公司与好价格》批判性审阅与融合建议

审阅对象：`两步分析法：好公司 + 好价格（v2.0）`

## 总结论

文档的方向正确，已经完成三个重要进步：废除伪精确总分、坚持先公司后价格、把管理层和资本配置单列。但它目前仍不是可以直接执行的最终模型，核心原因是：

1. “好公司”部分存在跨行业统一阈值和过度刚性的通过规则；
2. “茅台对标”混合了公司质量与当前估值，破坏了两步分离；
3. “好价格”仍由PR、ROE、PEG等经验倍数主导，没有真正由目标收益率倒算；
4. 买入时固定静态卖出价格，会忽略企业内在价值增长和基本面变化；
5. 缺少组合相关性、仓位上限和分档部署的执行门。

因此建议：保留第一步的大部分结构，重写第七维财务规则、茅台关卡和整个第二步。

## 二、必须修正的部分

### 1. “任何维度不通过即终止”过度刚性

八个维度并非同一性质。国际化是条件项，聚焦也必须结合业务协同性；它们不能与诚信、财务安全享受相同否决权。

建议分层：

- 硬门槛：诚信治理、护城河、竞争地位、需求持续性、财务安全；
- 条件项：聚焦、国际化；
- 比较项：茅台机会成本；
- 最多两个“存疑”规则可以保留，但必须说明存疑是否相关。例如“国际化未验证”和“海外ROIC存疑”实际上是同一个风险，不能伪装成两个独立问题。

### 2. 聚焦度的“主业收入超过80%”阈值不可靠

收入占比不能识别战略一致性，也不能衡量利润和资本投入。腾讯、美的等多业务公司可能共享品牌、渠道、技术或用户网络；单一业务公司也可能把大量资本投入无关项目。

应改看：核心业务利润与自由现金流占比、各业务是否共享能力、过去十年增量资本投向及回报。

### 3. Terry Smith七指标不能跨行业统一使用

当前“七项至少六项达标”的规则会错误排除很多好公司：

- 银行和保险无法用普通制造业的ROCE、经营现金流/营业利润、净负债/EBITDA分析；
- 零售、汽车玻璃、家电等行业毛利率低于40%并不代表没有护城河；
- 高分红成熟企业股息覆盖率可能低于2倍，但分红仍可持续；
- FCF收益率包含股价，是估值指标，应放在第二步，不属于财务健康；
- 经营现金流会受到预收、库存、应付款和金融资产变化影响，单年比例不能机械判断利润真假。

建议：第七维只评估财务质量，不混入价格；再按消费/制造/周期/银行/保险/平台分别设指标。

### 4. 茅台对标混淆了两步

第一步的茅台比较表包含“当前PR分档”，把估值提前带入公司质量判断。与此同时，“茅台对标不过关就不买”会造成两个问题：

- 可能持续增加单一股票集中度；
- 忽略其他公司对行业、监管、客户和现金流风险的分散价值。

建议拆开：

- 第一步只比较商业模式、定价权、需求持续性、资本强度、现金质量、治理和可预测性；
- 第二步再比较“新公司当前预期年化回报”与“当前价格买入茅台的预期年化回报”；
- 最终必须说明新标的是替代茅台，还是给组合增加不同风险来源。

文档中“郎刚重仓持有茅台25%”属于需要随持仓更新的事实，不能写成永久模型参数。

### 5. PR公式不能作为主定价模型

文档使用：`目标PE = 合理PR × ROE百分比整数`。该公式没有显式包含增长期限、分红、资本开支、风险和目标回报。

例如同样20% ROE的公司，一个能够把利润以20%回报率再投资，另一个已经停止增长，公式会给出相同PE；这显然不合理。ROE还可能因为高杠杆、回购或高分红缩小净资产而被动上升。

结论：PR可以做快速相对筛选，但不能决定重仓买入价，更不能宣称完成了目标收益倒算。

### 6. PB-ROE与PEG模型也需要降级

`合理PB = ROE / 股权成本`只是在零增长、特定分红假设下的近似。更完整的逻辑应考虑可持续增长率和分红率。PEG又高度依赖短期增长预测，无法表达增长持续年限、自由现金流和竞争风险。

两者均只能交叉验证，不能成为唯一主模型。

### 7. 目标收益率不能留到最后再决定

框架的任务就是根据个人目标倒算价格，但文档暂时建议10%—12%。这与既定目标不一致：

- 5年2倍需要14.87%年化；
- 10年5倍需要17.46%年化。

应当同时给出合理价值、优秀买入价和17.46%目标达成价，不能把10%—12%包装成已经满足最终目标。

### 8. 压力测试只有“利润下降10%”远远不够

不同公司要使用不同压力源：

- 消费品：销量、价格、渠道库存和品牌份额；
- 制造业：销量、毛利率、汇率、资本开支和海外产能；
- 银行：净息差、不良生成、信用成本和资本充足率；
- 保险：投资收益、权益市场、利率、退保和新业务价值；
- 平台：监管、竞争、用户时长、货币化率和资本开支。

压力测试必须同时考虑利润下降与估值压缩，而不是只把EPS乘以90%。

### 9. 不应在买入时“定死静态卖出价”

如果企业利润和内在价值持续增长，同一个绝对价格几年后可能从高估变成合理。机械按照PR>1.5清仓，还会制造不必要的交易、税费和再投资风险。

买入时应该写死的是卖出条件，而不是永久卖出价格：投资论文破坏、管理层诚信问题、资产负债表失控、价格严重高于更新后的内在价值、或出现明显更好的机会。估值和卖出参考价至少随年报更新。

### 10. 缺少组合执行门

单家公司通过两步之后，还必须检查：替代谁、组合相关性、首次仓位、正常上限、极端上限、分档买入和暂停条件。否则每家公司单看都好，组合却可能集中暴露于同一个中国内需、地产信用或监管风险。

## 三、融合后的主框架

```text
第零步：信息质量 + 能力圈 + 类型标签 + 一票否决
    ↓
第一步：好公司八维分析
    1. 业务聚焦与战略一致性
    2. 企业文化、诚信与治理
    3. 护城河及变化方向
    4. 国际化质量（条件项）
    5. 行业结构与竞争地位
    6. 客户需求持续性与增长空间
    7. 分行业财务质量与资本回报
    8. 管理层与资本配置
    ↓
茅台质量对标：只比较公司质量，不比较价格
    ↓
第二步：好价格
    正常化所有者收益 → 三情景经营预测 → 分行业主估值模型
    → 现金流和股息总回报 → 反解10%/12%-15%/17.46%三档价格
    → 公司特定压力测试
    ↓
茅台收益对标：比较同一价格时点的预期回报和风险
    ↓
组合执行门：角色、替代关系、相关性、仓位、分档买入、暂停/退出条件
```

## 四、真正的收益率倒算公式

对于能够预测现金分配的公司，最大买入价应来自未来股东现金回报的折现：

```text
最大买入价 P(r)
= 未来持有期现金股息与净回购的折现值
+ 持有期末正常化价值的折现值
```

其中 `r` 分别使用：

- 10%：合理价值参考；
- 12%—15%：优秀买入价；
- 17.46%：十年五倍目标达成价。

再用PE、PB-ROE、股息率、历史分位、PR等做交叉验证。如果交叉验证与现金回报模型差异很大，必须解释，不能取自己喜欢的结果。

## 五、建议采用的最终纪律

1. 好公司判断不使用总分，但保留硬门槛和存疑项；
2. 财务指标必须按行业切换，禁止统一七指标机械通关；
3. 茅台比较分成质量比较和收益比较，不混在同一步；
4. PR、PEG、PB-ROE降级为辅助工具；
5. 买入价必须显式包含目标收益率、股息、回购、稀释和终值；
6. 写死卖出条件，不写死永久卖出价格；
7. 每次研究必须输出数据日期、事实/估计标记、双来源核验和模型假设；
8. 每个买入档必须对应累计仓位和暂停条件。

## 最终评价

这份v2.0可以吸收约三分之二：第一步的结构已经基本成熟；需要重写的主要是财务统一阈值、茅台硬门槛、PR主定价和静态卖出规则。完成这些修改后，它才会成为真正服务于“好公司 + 好价格 + 目标收益率”的执行模型。
