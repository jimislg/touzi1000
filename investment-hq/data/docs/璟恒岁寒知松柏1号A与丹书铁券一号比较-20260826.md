# 璟恒岁寒知松柏1号A与丹书铁券一号比较研究报告

> 研究日期：2026-08-26  
> 资料口径：用户提供的雪球产品截图、基金经理雪球公开年度总结及近期发言、公开产品资料。合格投资者专属月报正文未取得，未把标题摘要当作完整披露。  
> 一句话结论：岁寒知松柏的十年总成绩更高、记录更长，但收益高度集中在2019—2020年；丹书铁券最近五年更稳定、最大回撤更低、费率更有利，也没有看到岁寒产品已公开使用的融资与收益互换风险。若二选一，我仍选丹书铁券；岁寒知松柏只适合作为第二管理人，而不是更保守的替代品。

---

## 第一步：同口径业绩比较

| 指标 | 璟恒岁寒知松柏1号A | 丹书铁券一号 | 判断 |
|---|---:|---:|---|
| 成立时间/时长 | 2016-09-21，约9.92年 | 约7年355天 | 岁寒记录更长 |
| 成立以来展示收益 | +425.98% | +252.08% | 岁寒更高 |
| 成立以来展示年化 | 约+18.21% | +17.12% | 岁寒略高 |
| 历史最大回撤 | -26.88% | -22.07% | 丹书更稳 |
| 2021—2025复合年化 | **+9.96%** | **+25.81%** | 丹书显著胜出 |
| 2026年至8月下旬 | -7.96% | -0.84% | 丹书胜出 |
| 2026年内最大回撤 | -21.55% | -17.39% | 丹书胜出 |
| 展示规模 | 3.31亿元 | 6.22亿元 | 均不构成明显容量压力 |
| 固定费率 | 约1.02% | 约1.03% | 基本相同 |
| 业绩报酬 | 超过年化5%部分的20% | 高水位利润的10%，无门槛 | 高收益阶段丹书更便宜 |
| 衍生品/融资 | 合同允许；经理公开披露实际使用跨境收益互换和借币 | 公开策略口径为纯多头、无杠杆、无衍生品 | 丹书更保守 |

最重要的反差不是18.21%对17.12%，而是收益路径：岁寒知松柏在2019年上涨49.05%、2020年上涨120.80%，两年净值乘数达到3.291倍；但2021—2025五年合计只增长60.79%，年化9.96%。计入2026年至8月下旬后，从2021年初至今的展示年化约7.19%。

因此，岁寒知松柏的长期成绩是真的优秀，但“18.21%可以继续复制”的证据弱于丹书铁券。丹书铁券2021—2025五年展示收益约3.15倍，而且五个年度均为正，当前更接近持续创造收益的记录。

## 第二步：费用后的真实差异

公开平台的产品净值通常已经扣除基金层面的固定费用，但单客户业绩报酬是否已经完整反映在展示净值中，必须用投资者实际份额净值和合同确认。不能在没有确认前机械重复扣费。

若沿用此前的压力测试假设——截图收益完全未扣固定费用和业绩报酬、长期持有至赎回、没有中途分配——则：

- 岁寒知松柏成立以来18.21%的展示年化，估算扣费后约15.35%；
- 丹书铁券成立以来17.12%的展示年化，估算扣费后约14.5%—14.9%；
- 岁寒知松柏最近五年9.96%的展示年化，估算扣费后约8.12%；
- 丹书铁券最近五年25.81%的展示年化，估算扣费后约22.81%。

同一年度毛收益下的近似到手收益如下（忽略税费和计提时点差异）：

| 年度毛收益 | 岁寒知松柏 | 丹书铁券 |
|---:|---:|---:|
| 10% | 约8.18% | 约8.07% |
| 15% | 约12.18% | 约12.57% |
| 20% | 约16.18% | 约17.07% |

毛收益约11.1%以下时，岁寒的5%门槛略有优势；高于约11.1%后，丹书10%的提成明显更便宜。对于追求5年2倍、10年5倍的高目标，丹书的费率结构更有利。

## 第三步：2019—2020年的超额收益能否复制

2020年公开总结显示，收益并非单纯押中指数，而是来自多只个股：被市场怀疑造假的扫地机公司、长期持有的汽车股、家具股、地产股及通信股等先后贡献。基金经理确实展示了财务识别、逆向买入和忍受波动的能力，这是实打实的选股阿尔法。

但它也具有明显不可复制性：

1. 多个重仓股在同一年同时发生基本面验证和估值修复；
2. 汽车、地产、扫地机器人等行业恰逢风格与产业催化共振；
3. 2019—2020两年贡献了长期净值的大部分跃升，此后五年收益显著降速；
4. 当前规模、市场认知和流动性环境都不同于早期，原有预期差更难重复。

合理的未来基准不能用18.21%，更不能用2020年的120.8%。在未取得完整月度净值和当前仓位前，我对其未来五年扣费后年化的保守估计是8%—12%，乐观情景13%—16%。这意味着5年2倍不是基准情景，10年5倍更不能作为可承诺目标。

## 第四步：雪球报告和发言的一致性审计

### 值得肯定

- 方法长期一致：A/H两地选股、低估值、财务分析、治理结构、较高股息、高仓位、不依靠市场择时；
- 披露较坦率：2018年承认能力圈和选股错误；2023年列出制药装备、电控电源及收益互换的具体损失；2026年承认最近三年业绩不好、家庭变化一度影响研究；
- 利益绑定：公开表示本人、家庭及公司同事有较大跟投；
- 不迎合热点：2025年没有追逐AI、创新药和黄金有色的热点，也没有在复盘中伪装成提前看对。

### 我认为必须警惕

1. **它不是简单的保守价值基金。** 产品合同允许期货、场内外期权、融资融券和跨境收益互换；经理2023年披露收益互换成本超过6%、融资与汇率合计拖累约1个净值点，2026年又披露将借美元改为借离岸人民币。这增加融资成本、汇率、交易对手和监管风险。
2. **近期发言有明显的乐观锚定。** 2026年5月称组合平均PE约10倍、股息率近5%、多数公司利润增长约10%，并认为“三年翻倍”。但10%利润增长加5%股息，若估值不扩张，理论总回报约15%，三年约1.52倍；三年翻倍需要年化约26%。差额必须依赖显著估值修复或更快增长，不能称为自然结果。
3. **“等待”既可能是纪律，也可能是锚定。** 在持续亏损后仍认为没有做错、等待补涨，只有在持仓基本面逐项验证后才是价值投资；如果只是因为价格低而不承认行业和竞争格局变化，就会成为价值陷阱。
4. **能力圈存在已验证的薄弱点。** 他在2020年公开承认，对行业和产品专业知识只做一般程度了解，更依赖财务和管理层判断；2023年又承认曾被两位有企业家情怀的老板和高研发投入打动，随后利润率不及预期并造成损失。这说明“从财报看懂公司”并不能替代产业、产品和竞争研究。
5. **关键人物风险高。** 研究、决策和对外沟通高度依赖李育慧本人；公开承认个人家庭变化曾影响研究，是坦诚的优点，也是必须计入的运营风险。
6. **规模曲线不能被误读。** 截图显示规模从约4.5亿元降到3.31亿元，但这既可能来自净值下跌，也可能来自赎回，不能直接断言“资金撤离”。应要求管理人拆分净申赎与投资损益。

## 第五步：与丹书铁券的最终选择

| 维度 | 更优者 | 原因 |
|---|---|---|
| 长期累计成绩 | 岁寒知松柏 | 记录更长、累计收益和展示年化略高 |
| 最近五年持续性 | 丹书铁券 | +25.81%年化对+9.96%年化 |
| 回撤控制 | 丹书铁券 | 历史和2026年内回撤均更低 |
| 费用 | 丹书铁券 | 达到目标收益所需的高收益区间，10%提成更便宜 |
| 策略复杂度 | 丹书铁券 | 未见岁寒已公开使用的借币、收益互换与汇率敞口 |
| 透明与自省 | 岁寒知松柏略优 | 公开复盘时间长，错误披露相对具体 |
| 对5年2倍目标的当前证据 | 丹书铁券 | 最近五年达到，岁寒最近五年未达到 |
| 对10年5倍目标的可靠性 | 均不足 | 两者均不应承诺未来17.46%扣费后年化 |

**二选一：丹书铁券一号。** 这是基于持续性、回撤、费用和策略简单度，而不是否定岁寒知松柏的历史能力。

如果为了降低单一基金经理风险而同时配置两只，我建议在“私募基金这部分资金”内部按丹书70%、岁寒30%起步，而不是把整个1000万元按此比例投入。岁寒的30%是管理人分散仓，不是因为它更保守；两只产品都偏A/H价值股，与用户自选组合仍有较高重叠，不能视为真正的资产类别分散。

对于“每年100万元可持续股息”的目标，两只私募都只能通过分红或赎回转化为现金流，不能替代自主高股息组合的直接分红。因此即使选择私募，也不宜把全部投资本金交给私募管理。

## 第六步：认购岁寒知松柏前的五个硬问题

1. 提供2016年以来逐月、复权、扣除全部费用后的投资者实际净值，并说明业绩报酬是否已反映；
2. 披露最近24个月月末股票净仓位、总敞口、收益互换名义本金、最高杠杆和融资币种；
3. 披露跨境收益互换的交易对手、保证金追缴规则、汇率是否对冲及2022—2026年各年融资成本；
4. 披露当前前十大、港股比例、行业集中度，以及2026年亏损前三大归因；
5. 将规模从约4.5亿元降至3.31亿元拆分为投资损益、申购、赎回和分红。

任何一个问题不回答，都不能把它定义为“比自主投资更保守”。
