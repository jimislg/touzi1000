# 股票池方向分类：全球竞争力与现金回报

日期：2026-10-07。性质：讨论用分类底稿，不是估值报告、正式评级或调仓指令。

本次依据用户提出的方向：不重仓押纯内需复苏，重视出海、全球竞争力、现金流、分红回购和产业龙头。未提供具体政策文件，因此不确认该政策的内容或逐行业影响。分类表达经营敞口与研究优先级，不以宏观偏好替代个股三步法。

## 范围与边界

当前投资平台本地配置31个证券条目，合并中国移动、海天、中国平安的A/H后为28家公司。以此为主池；历史扩展监控名单另有三花、紫金、神华、宁沪、港交所、东鹏6家，单列，不自动重新纳入当前主动池。美的继续排除。理想汽车仅发现历史报告/缓存，未在上述当前及扩展名单中，不冒充当前池成员。

名单读取自当前本地配置，不代表实时行情或真实成交台账已核验。本轮不计算持仓权重、不采用旧买价、不修改平台。财务证据主要使用2026中报/Q2及近两日研究底稿；没有声称完成全部关键数据独立双源或正式定价审计。

## 如何分类

只问四个问题，不打主观综合分：

1. 不发生国内全面复苏，公司自身的需求、份额、产品结构能否支持盈利？
2. 海外是有收入、有利润、有现金的生意，还是品牌所有权、授权一次性或管理层规划？
3. 扣除维持与增长投入后，是否还有能归属于股东的现金？
4. 管理层会分红、低价净注销回购，还是把钱投向回报未证实的项目？

海外分部利润未披露时写待核，不根据收入占比自动认定海外高回报。国内需求不等于国内复苏下注；产业龙头也不等于高资本回报。以下五组不是SOP的A/B/C/D，方向匹配不自动改变公司质量、审计状态或新增资金资格。

地方财政依赖按实际付款主体、财政项目收入占比、应收回款和账期识别，不按国企身份判断。医院采购或医保支付也不能直接等同地方财政项目收入。此次名单没有单独确认出典型的地方财政项目依赖型公司；这不代表相关回款风险已排除。

## 对目标的含义

1. 研究主线：先核全球竞争与可分配现金，特别是福耀、迈瑞、宁德；腾讯按“国内平台+全球游戏+AI资本预算”研究，不能给它纯出海标签。
2. 品牌出海：安踏、泡泡、名创分别拆地域利润、租赁/并购投入与归母现金，不合并成一个“出海消费篮子”。
3. 国内好生意可以保留：茅台、海天、农夫等只要自己的需求、份额、提价/成本、资本回报足以成立，无需依赖全面复苏；尚未证明的公司不能借此解除闸门。
4. 对国内信用/地产/广告预算依赖大的公司，不把政策反弹或估值修复作为主要新增理由；既有持仓动作仍需第四步比较，不因新主题自动换仓。
5. 10年5倍与税前年息100万元仍按原目标；回购不算可用股息。方向正确、现金充裕或高分红，都不保证当前价格达到目标回报。

不可忽略的新集中风险：出口公司可能共同暴露全球需求、关税、汇率与海外本地化投入；海油、紫金、神华可能共振于资源价格；多个国内品牌共振于消费预算。看起来跨行业，并不等于风险独立。方向分类只影响研究时间分配，不自动修改仓位上限、A/H25%门槛或质量标准。
