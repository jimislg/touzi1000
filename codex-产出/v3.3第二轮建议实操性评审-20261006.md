# v3.3第二轮建议实操性评审

评审日期：2026-10-06

## 总结

这份建议抓到了六个真实执行问题：税后现金披露、经济价值折现率、特殊风险仓位约束、多上市地选择、比较基准边界、流程复杂度。整体值得吸收，但不能原样照抄。

| 建议 | 结论 | 处理方式 |
|---|---|---|
| 税前/税后股息并列 | 采纳 | 保留税前100万元目标，增加税后实际到手，不固定为80万元 |
| 资本成本标准化 | 修改后采纳 | 解决不可复现，但不采用机械的行业固定表 |
| 范式风险仓位硬规则 | 修改后采纳 | 高范式风险设上限；需求与份额双降应暂停，而非仅减半 |
| A/H等多上市地规则 | 强烈采纳 | 税后总回报决定选择，绝对价格决定买入，折价只作解释变量 |
| 直接竞争者选择标准 | 采纳 | 默认利润池最大者，可增列资本回报最高者，最多两名 |
| 最佳可加仓持仓边界 | 修改后采纳 | 无合格持仓时直接比较低风险资产；茅台不自动成为可投资替代 |
| 接近目标型仓位 | 采纳 | 已在上一轮确认，应补齐 |
| 分段暂停确认 | 不设为强制 | 改成自动快筛闸门，并提供可选“两阶段模式” |
| H12措辞统一 | 采纳但纠正方向 | 应写“现价≤H12”或“IRR≥12%”，不能写“价格≥H12” |
| 风险去重示例 | 采纳 | 增加一个已填示例即可，不增加更多表 |

开头平安A/H的48.0港元、40.6港元及20%公平折价属于个案结论，必须留在平安报告并按当日价格、税务渠道和模型复核，不应直接写进通用SOP。

## 一、税前100万元与税后到手现金

建议指出的披露缺口成立，但不应改变用户已经明确的目标口径。

应保留：

> 第10年税前年股息目标为100万元，按名义固定金额管理。

第四步股息表增加：

| 指标 | 当前 | 第5年 | 第10年 |
|---|---:|---:|---:|
| 税前年股息 |  |  |  |
| 适用税率与渠道 |  |  |  |
| 税后实际到手股息 |  |  |  |
| 税前100万元目标覆盖率 |  |  |  |

不建议写死“税后不低于80万元”。原因是A股、港股通、港股账户、不同注册地公司和不同分红性质的税负并不统一；20%不能作为所有港股股息的通用税率。应按用户实际持有渠道逐项计算。

结论：增加税后披露是实操改进；把80万元升级为第二目标没有必要。

## 二、经济价值的资本成本

“统一资本成本”没有默认规则，确实会破坏复现性。但建议中的固定行业表也过于机械：同属平台成长、制造或金融，公司杠杆、现金流稳定性、币种和治理风险可能完全不同。

建议采用简化的统一规则：

```text
默认基准折现率 = 10%

B类、强周期、高杠杆或高范式风险：基准折现率 = 12%

所有公司同时输出基准折现率±1个百分点的敏感性
```

例外只能基于明确证据，并在输入表中解释。经济价值取敏感性区间，不取一个精确点值；安全边际相对区间下沿计算。

这样比按七种公司类型各给一个看似精确的数字更简单、更容易复算，也避免8%—9%的低折现率把长期价值抬得过高。H10/H12/H15/H17.46仍独立作为目标回报买价，不与经济价值混用。

## 三、特殊风险的最低仓位硬规则

“风险去重”不等于取消所有硬约束。建议保留一条窄而明确的底线：

- **范式风险高且下一代卡位尚未验证**：公司最高只能列B类，硬上限4%；若核心盈利模式可能被替代，则降为C类，仓位为零；
- **需求结构下降且公司份额连续两个报告期下降**：触发研究暂停或C类复核，不应只是把仓位减半；
- 已经进入现金流、终值和情景权重的普通经营风险，不再机械重复降仓。

原建议第二条若只“硬上限减半”，可能让基本面和竞争地位同时恶化的公司仍进入组合，处罚反而偏轻。

---

## 四、同一公司多上市地选择规则

这是本轮建议中最值得加入SOP的一条，直接影响真实下单。

建议新增以下规则：

1. 使用完全相同的公司经营、盈利、终值和股本假设；
2. 分别计算各上市地的交易币种IRR、人民币IRR、税前股息率和税后股息率；
3. 纳入红利税、资本利得税、交易费、汇率、流动性、最小交易单位及渠道限制；
4. 买入判断锚定各上市地的绝对价格和H档位；
5. A/H折价、ADR折价等只用于解释相对价格，不得代替绝对回报测算；
6. 折价扩大若只来自较贵上市地上涨，而便宜上市地价格不变，则便宜上市地IRR不变，不构成新增安全边际。

### 不应固化“公平折价=20%”

20%的红利税率不等于股票公平折价20%。税负只作用于应税分红现金流，公平折价还取决于派息率、分红增长、持有期、终值实现方式、汇率、流动性和交易渠道。只有基于某家公司完整税后现金流模型算出的折价，才能称为该公司在该渠道下的公平折价。

因此，平安案例可以作为示例，但48.0、40.6港元和20%不进入通用规则。

## 五、最优秀直接竞争者的选择

建议采纳，并限制最多两名以控制工作量：

1. 默认选择与目标公司处于同一利润池、可比业务占比足够高且利润池份额最大的竞争者；
2. 若该公司只代表规模、不代表质量，再增加一名五年平均ROIC/ROE或每股价值增长最高的竞争者；
3. 无法找到真正可比公司时写“无直接可比”，不得为了填表强行选择。

“市场份额第一”不如“利润池份额第一”有用，但利润池数据不可得时，可退回收入或保费等规模口径并注明局限。

---

## 六、最佳可加仓持仓的边界

建议指出的空集问题成立，但“茅台→低风险资产”的自动顺位仍不够严谨。茅台只有在其自身满足A/B、达到相应H档且未触及仓位上限时，才是真实可执行的机会成本。

建议顺位：

1. 当前组合中质量合格、价格达到新增门槛且未触及上限的持仓；
2. 观察池中已经完成前三步和第四步、可立即执行的候选；
3. 与资金币种和期限匹配的低风险资产或现金。

若前两项为空，机会成本直接降为低风险资产。茅台继续作为质量与公开回报参考，不自动视为可加仓对象。

## 七、接近目标型仓位

这是明确缺项，直接补齐：

| 公司分类与回报 | 首次仓位 | 正常上限 | 硬上限 |
|---|---:|---:|---:|
| A类+目标达成型 | 3%—5% | 10%—15% | 20% |
| A类+接近目标型 | 2%—4% | 8%—12% | 15% |
| A类+组合辅助型 | 2%—3% | 5%—8% | 10% |
| B类 | 1%—2% | 3%—5% | 8% |

最终仓位仍受组合相关性、资金来源、外币风险和压力测试约束。

---

## 八、复杂度与流程闸门

对复杂度的担忧完全正确，但“第零步+第一步后必须暂停等用户确认”不宜成为所有任务的硬规则。它会增加往返时间，也可能让批量筛选和已经明确授权的完整研究变慢。

建议设置两种运行模式：

### 快筛模式

- 只执行第零步、第一步和否决检查；
- 输出一页资格卡：继续 / 补数据 / 停止；
- 用户确认后才进入第二、三步。

### 完整研究模式

- 用户明确要求完整研究时连续执行；
- 第零步和第一步结束后自动做内部闸门；
- 命中停止条件才暂停，未命中则继续，不增加一次机械确认。

更重要的减负方式是把1200行文档拆为：核心规则、研究模板、第四步组合模板、Agent提示词和修订记录。减少一次执行需要加载的规则，而不是继续往正文加表。

## 九、两个小项

### H12措辞

若指价格，正确表达是：

> **当前价格≤H12。**

若指回报，正确表达是：

> **当前价格对应的基准10年IRR≥12%。**

“价格达到≥H12”方向相反，会在价格越贵时反而判为达标，必须避免。

### 风险去重表示例

建议增加一个已填示例，但不写入未经复核的平安具体数值：

| 风险 | 收入/利润率 | 终值 | 情景权重 | 仓位 | 去重结论 |
|---|---|---|---|---|---|
| 长期利差收窄 | 已下调正常化利润率 | 已使用较低终值倍数 | 不再重复降权 | 仅处理金融暴露相关性 | 无重复 |

一个示例足够，不必为每类风险新增模板。

---

## 最终建议

本轮真正应进入v3.4的改动有七项：

1. 第四步增加税后实际到手股息，但不改变税前100万元目标；
2. 建立简单、统一的10%/12%折现率规则和±1%敏感性；
3. 对高范式风险保留窄范围的仓位硬约束；
4. 新增多上市地税后总回报选择规则；
5. 明确同行与可加仓持仓的选择顺位；
6. 补齐接近目标型仓位；
7. 增加快筛/完整研究两种运行模式，并附一个风险去重示例。

不建议纳入：通用20%公平折价、所有港股统一税后80万元、机械行业资本成本表、所有研究强制中途确认，以及“价格≥H12”的错误表述。
