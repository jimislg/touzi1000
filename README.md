# 长期投资跟踪系统

一个无外部依赖的本地仪表盘，用于持续管理中国及港股投资组合。系统围绕四件事工作：目标是否可达、公司论文是否成立、价格是否到位、仓位是否越界。

## 当前投资口径

- 投资本金：1000万元
- 目标：5年2倍、10年5倍
- 长期被动股息：税后100万元/年，并能持续增长
- 当前持仓和现金以 `data/portfolio.json` 为唯一组合口径
- 股票池价格线来自截至2026-08-28完成的公司分析；到价只触发复核，不触发自动买入

## 启动

```bash
npm start
```

打开 <http://127.0.0.1:4173/>。

## 页面模块

- 决策中枢：目标收益缺口、资金部署、税后股息和红黄预警
- 股票池：质量等级、论文状态、P12/P15/P17.46价格线、目标仓位和硬上限
- 持仓跟踪：实时估值、成本盈亏、集中度和动作建议
- 风险地图：识别可能同时受同一因子冲击的持仓
- 公司研究：保留情景估值、证据、评分和财务质量审计
- 复盘纪律：每日检查、月度仓位复核、季度论文修订

## 数据与验证

- 行情来自腾讯公开行情接口，手动点击“立即更新”会显示采集时间以及行情是否变化。
- 基本面数据有独立日期，不能把旧财报和新股价混作同一时点。
- 价格线、增长率和分红均为情景假设，不是收益保证。
