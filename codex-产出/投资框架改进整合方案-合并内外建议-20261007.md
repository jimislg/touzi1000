外部建议的核心判断我完全认同：**三步法骨架合理，不加分析维度，把"好公司、合理价格"变成可兑现的每股现金增长，让第四步真正完成资金配置。**

## 一、逐条回应与落地映射

### 建议1：资本预算一致性（现金分配表）——✅ 完全采纳，这是回购事故的框架级根因修复

10-06快筛"回购双重计算"事故（格力/携程/恒瑞/伊利payout含回购又吃g增长）的根因正是没有这张表。lint只是事后拦截，这张表是事前勾稽。

**落地**：
- **报告模板新增一页"现金分配表"**（每股口径）：`经营现金流 - 维持性capex = 可分配现金 → 增长再投资 / 分红 / 回购（走净股数，不进payout）`，末行必须回答"钱够不够、缺口谁补"
- **勾稽检查**（非硬约束）：`g ≈ 再投资比例 × 增量资本回报`。两处豁免：银行/地产（已有PB/ROE与分部口径）；早期高增长公司（说明依据即可）
- **档位复核器**：payout输入框旁加"回购已走股数"开关，防再次双重计算
- 增长来源三分类（提价/扩产/回购增厚）写进第二步八维，作为增长假设的证据标签

### 建议2：经济性存疑 vs 证据待核分离——✅ 采纳，修复"快筛歧视资料缺失公司"的系统性偏差

上一轮校正把泡泡/名创/伊利/伟星标"C暂定"，语义混乱正在于此：其中相当部分是**证据待核**（海外同店数据没查齐），不是竞争优势削弱。资料缺失多的公司被判C、资料全的显得更优秀——这是评级系统的bug。

**落地**：
- **grade只表达经济性判断**；新增正交字段 `researchStatus: done / partial / pending` + `evidenceGap`（缺什么，一句）
- 泡泡现归类改为：`grade=B+待定（经济性）+ researchStatus=partial（缺海外同店利润率/老IP复购数据）`——不再是"C暂定"
- **缺关键证据不给正式买价，但不解释为"公司不好"**——与"审计未完成不能给正式买价"原则一致
- 平台B/C池表头加"研究完成度"列，signal中心对 partial 且已触发价格的标的提示"先补研究再进第四步"

### 建议3：好价格附"需要什么成立" + 边界机会标记——✅ 采纳

单点IRR的伪精确正是17.46%目标的最大陷阱：模型算出17.5%不等于稳稳达标。"终值=当前PE零修复"也不自动等于保守（若当前PE本身在历史高位）。

**落地**：
- universe每只新增 `assumptions` 字段：**2-3个必须成立的经营条件**（如格力=空调需求不萎缩+渠道改革兑现；长电=来水均值回归+电价不改革）。只测最影响结论的变量
- **边界机会标记**：任一合理假设±10%变动使结论在合格/不合格间翻转 → note标"边界机会"，仓位上限自动降一档
- 报告模板在四档价格表下加一行"本价格合格所需条件"，逐条对应assumptions

### 建议4：基础仓位与机会仓位分开——⏸ 单独讨论，我先给代价定价

问题真实存在：好公司经营兑现但价格不跌，H12档25%仓位的钱可能永远等不到H15。但这个改动的本质是**用组合预期回报换资金利用率**，必须显式定价：

| 方案 | 资金利用率 | 组合加权预期回报（粗算） |
|---|---|---|
| 现行：H12只建25%→H15建60% | 低（当前投放19.6%的部分原因） | 偏高（新建仓成本更低） |
| 基础/机会分仓：H12可建至上限 | 高 | ≈12.x%（趋近H12线） |

我维持此前诊断：组合隐含IRR已只有10.7%，若H12即建满基础仓位，组合预期回报将钉死在12%附近，10年终值约3100万——**这个交换不是不对，是不能不明着做**。建议讨论顺序：先上P0组合IRR仪表（两周内），用真实数字跑"H12建满 vs 等待"两情景的组合回报差，再决定基础仓位的锚（H12还是H10）与上限。**不是等得久就提高买价，也不允许越涨越追——这两条红线先行确认。**

### 建议5：现金等待成本进目标检查 + 费用进最终财富——✅ 采纳（按事实更正后的口径）

他给的数学情景放进驾驶舱直接可见：**20%现金零收益 → 其余80%仓位需年化21.83%才能整体17.46%**。当前119万现金@1%、投放19.6%，这个数字比任何叙事都有说服力。

**落地**：
- 驾驶舱新增一行"现金拖累后要求回报"：`(1+17.46%)/(1-现金占比) - 1` 实时算
- **季度三查**（固定动作，不写长报告）：①剩余目标要求年化 ②合格机会集合（价格≥12%的标的数，当前0只）③现金等待成本。**若合格机会不足，承认路径缺口，不通过调高预测、加杠杆填补**
- 费用进最终财富：股息税已进（A股免税档/港股20%），补交易费用粗系数（A股~0.1%双边、港股通~0.3%+组合费），终值口径统一改"扣费后"

### 建议6：一页决策卡 + 预测复盘——✅ 采纳，且是两份建议合并后唯一全新机制，价值最大

复盘机制是让方法**逐渐可靠**的唯一途径——股价涨跌不能证明研究正确，这句话应该刻进平台。

**落地**：
- **决策卡7字段**结构化为平台note模板：`质量资格 / 回报来源（现金分配表一句话）/ 当前价格条件 / 最大反方观点 / 三项触发指标 / 研究完成度 / 下一步动作`。日常只看这页，无关键事实变化不重算
- **预测快照**：每份研究报告定稿时自动存参数快照（g、利润率、资本投入、股数四项+当时价格），**每年10月跑一次复盘**，错误归因到四类：增长错/利润率错/资本投入漏/股数判断错
- 2026基线快照可在第一批执行时从已定稿报告（腾讯/平安/宇通/东阿+7只持仓）直接提取建立

## 二、股息目标定位（外部建议末段）——✅ 采纳，修正平台呈现

数学关系确认无误：100万/1000万=10%（立刻），100万/5000万=2%（第10年）。含义：
- **前期不为股息牺牲复利**——股息完成度8.4%作为KPI有诱导"为股息买高股息股"的风险，改为**先导指标**（成本股息率4.26%×已投本金=当前股息，随投放自然增长）
- **终态必须验证实际派息能力**（现金分配表的分红列正好承接）
- 平台股息表头部加一行口径说明，撤掉孤立完成度百分比作为主KPI
