**采纳**：2026-10-07 郎刚确认（"1听你的"）
**原则**：不加分析维度，把"好公司、合理价格"变成**可兑现的每股现金增长**，让第四步真正完成资金配置

## 一、现金分配表（资本预算勾稽）——每份完整报告必附

每家公司用一张表回答：**公司赚到的钱，维持经营用多少、增长用多少、分红多少、回购多少？钱够不够？**

| 现金分配表（每股口径） | 金额/比例 | 依据 |
|---|---|---|
| 经营现金流 | | 已核实财报 |
| − 维持性资本开支 | | 估算，标注口径 |
| = 可分配现金 | | |
| → 增长再投资 ___% | | 提价/结构改善（轻资本）或 扩产/开店/并购（须给投入额、兑现时间、增量回报依据） |
| → 现金分红 ___% | | 已实施口径 |
| → 回购 ___% | **走净股数变化，禁止再计入payout** | |
| 缺口/富余 | | 融资补 or 留存 |

**勾稽检查**（一致性检验，非硬约束）：`g ≈ 再投资比例 × 增量资本回报率`。禁止同时假设"增长不错+分红很高+回购很多"而总现金不够。
**豁免**：银行/地产（沿用PB/ROE与分部口径）；早期高增长公司（说明依据即可）。
**提醒**（1984年巴菲特股东信）：高盈利主业可能掩盖其他项目的低回报资本配置——分部看，不只看合并报表。

## 二、研究完成度标记——与grade正交，消灭"资料缺失惩罚"

**grade只表达经济性判断**（竞争优势是否削弱、资本配置是否毁灭价值）。研究完成度独立标记：

- `researchStatus: done`——关键证据齐，可给正式档位
- `researchStatus: partial`——缺关键证据，**不给正式买价**（档位标注"研究口径"），但**不得解释为公司不好**
- `researchStatus: pending`——尚未研究，只有快筛参数

缺什么写进 `evidenceGap`（一句话）。资料缺失多的公司不得因缺失被判C；资料全的公司不得因资料全显得更优秀。**审计未完成≠公司差。**

## 三、边界机会标记——好价格必须回答"需要什么成立"

每只标的在四档价格下必须写明：**当前价格获得合格回报，需要哪些经营条件成立？**（`assumptions`字段，只列最影响结论的2-3个变量）

- 测试规则：对每个假设做合理区间扰动；**任一假设±10%变动使结论在合格/不合格间翻转 → 标记"边界机会"，仓位上限自动降一档**
- 禁止：为达标反推增长；把"终值=当前PE零修复"自动视为保守（若当前PE在历史高位，须说明）
- 目标精确（17.46%）不代表预测能精确（17.5%）

## 执行纪律（每周节奏，2026-10-07郎刚定）

**每周三查**（无长报告，只查三件事，写进平台周检记录）：
1. **剩余目标要求年化**：当前总资产→5年2000万/10年5000万所需年化
2. **合格机会集合**：现价IRR≥12%的标的数与名单（当前0只）
3. **现金等待成本**：现金占比×现金收益 → 持仓部分的要求回报（当前：现金占37%，持仓需约27%）

若合格机会不足：**承认目标路径存在缺口，不通过调高预测、加杠杆填补。** 个股回报达标≠整个本金达标。

**每周预测复盘**：对照《预测快照》基线，检查本周新事实（财报/公告/分红变化/价格相对档位），错误归因四类：**增长错／利润率错／资本投入漏／股数判断错**。不用股价涨跌证明研究正确。

**股息口径**：前期不为股息牺牲复利（100万/1000万=10%、/5000万=2%，纯数学关系）；终态必须用现金分配表的分红列验证实际派息能力。股息完成度不作主KPI，改先导指标（成本股息率×已投本金）。
