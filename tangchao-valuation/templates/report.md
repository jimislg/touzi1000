> 用法：`scripts/calc.py` 会自动生成下列章节的数据骨架（`report_data.md`），
> 人工补的是：**【判断】** 段落、第 3 节闸门定性、第 5.1/5.2 的经验线解读、第 10 节失效条件、第 11 节交叉验证。

> **顺序不可调整**：全景在前（第 4–5 节），旧口径在后（第 6–7 节）。

## 5. 估值全景：利润锚 → 价格轴（★唯一决策依据）

> 一屏看完：利润锚（第 4 节）→ 价格轴（本节）。**四层 DCF 是决策层；经验线是辅助参考，不参与任何取值。**

| 层次 | 性质 | 口径 | 估值（亿） | 每股 | 对应 PE | 相对现价 |
|---|---|---|---|---|---|---|
| **买入线** | 决策层 | DCF r=12% | | | | |
| **中枢** | 决策层 | DCF r=10% | | | | |
| **乐观** | 决策层 | DCF r=8% | | | | |
| *经验线* | 辅助参考 | 峰值PE × 50%（>25× 则封顶 25×） | | | | |
| **卖出（减仓）线** | 决策层 | DCF r=6% | | | | |
| 现价 | — | 市价 | | | | — |

**卖出（减仓）线 = DCF(6%) = ___。不取 min，不受经验线影响。**

> **定位**：现价 ___ 落在「___」与「___」之间——第 k/4 档（按决策层价格从低到高）。经验线 ___ 在现价下方/上方，仅作参考。

![估值全景：四层价格与经验线（参考）](ladder.svg)

### 5.1 辅助经验线（只展示，不进公式）

| 项 | 值 |
|---|---|
| 峰值 PE（日期） | |
| × 50% | |
| 25× 硬顶 | 触顶 / 未触顶 |
| 经验线股价 | ___（___×） |
| 与 DCF(6%) 之差 | |

> 它回答「历史上市场最多愿意给多少倍」，**不回答「它值多少」**。改它、删它，上面六行的价格一个都不动。
> 命中四个死穴之一时（峰值年利润暴跌 / 距今 >8 年 / 上市不足 5 年 / 低于买入线），只在此加一句注释，不改任何数字。

【判断】：现价相对买入线贵/便宜多少？卖出线还有多远？哪一层的可信度最低、为什么？
