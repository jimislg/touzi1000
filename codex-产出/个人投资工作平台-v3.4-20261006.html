方法论速查 v3.4 核心纪律

流程（前三步研究 → 第四步组合，防火墙隔离）

  • 第零步：研究准备·双源核验·一票否决（诚信/杠杆/流动性红线）
  • 第一步：细分市场三轴——需求轴（结构性vs周期必答）／利润池轴（产能分层）／范式风险 → 参数传导 + 风险去重（同一风险只罚一次）
  • 第二步：好公司八维 → A（核心复利）/B（优秀但有条件）/C/D；A/B才进观察池
  • 对标：茅台（质量标尺）+ 最优直接竞争者，只比公司不比价格
  • 第三步：审计门9条全过 → 正常化盈利 → 三情景 + 概率加权期末财富 → 经济价值区间（10%默认／B类·强周期12%）+ 四档价格
  • 第四步（拟交易才触发）：三重机会成本 → 纳入前后测算 → 仓位与分档；不得倒推修改前三步

    • 四档价格与标签

  • P10/H10=10年10%：回报门槛参考，不作唯一安全边际锚
  • P12：初始关注价，最低新增资金门槛
  • P15：优秀机会价，正常仓位门槛；P17.46：目标机会价
  • 标签：目标达成型≥17.46%／接近目标型15-17.46%／组合辅助型10-15%／回报不合格<10%（不投新增资金）

    • 仓位与分档建仓（占总资产）

  • A·目标达成型：首3-5%／正常10-15%／硬20%；A·接近目标：2-4%／8-12%／硬15%
  • A·组合辅助：2-3%／5-8%／硬10%；B类：首1-2%／3-5%／硬8%；单股绝对硬约束25%
  • 分档：≤P12累计25% → ≤P15累计60% → ≤P17.46累计100%

    • A/H 双门槛（多上市地）

  • H较A折价≥25% 且 绝对价格≤自身档位，两道全过才有行动资格
  • 买入永远锚定绝对价格与税后人民币回报；折价扩大≠买入信号；折价仅因A股上涨时不触发
  • 港股通红利税20%；A股持股>1年免税

    • 红线精选（完整25条见SOP）

  • 禁止把TTM峰值利润当正常利润；禁止为得出「可以买」而调参
  • 禁止因低PE/低PB/高股息单独认定便宜；禁止直接加权各情景IRR
  • 价格下跌不是加仓理由；旧价格线自动冻结，历史报告须重审
