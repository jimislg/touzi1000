# 美的集团2026中报重估与买点修正

> 日期：2026-09-01；财务截止2026H1；价格87.73元（2026-08-31收盘）。

## 结论

美的仍为A类公司，2026H1质量闸门基本通过，但价格闸门未通过。半年收入、归母利润和经营现金流分别增长3.55%、1.66%和0.73%；扣非下降25.31%主要受到汇兑损失与套保收益分类错配影响，不能单独解释为经营崩坏。

制造业毛利率下降0.55个百分点、工业技术收入下降12.72%，说明旧模型8%长期增长和16倍终值PE过于乐观。改用5%增长、14倍终值PE后：

| 项目 | 修正结果 |
|---|---:|
| 87.73元基准10年IRR | 9.85% |
| P10 | 86.8元 |
| P12 | 75.1元 |
| P15 | 61.1元 |
| P17.46 | 52.0元 |

执行：87.73元不买；≤75.1元建1.5%—2%，≤61.1元扩大至4%—5%，≤52元才接近8%硬上限。旧条件“中报通过且≤88元”作废。
