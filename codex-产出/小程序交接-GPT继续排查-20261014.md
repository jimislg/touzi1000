## 七、按 kind 的处置预案（拿到详情后对号入座）
| r.error.kind | 含义 | 处置 |
|---|---|---|
| `permission-denied` | 网关对小程序 Referer 做了 appid↔应用绑定校验 | 把小程序与云应用绑定（WorkBuddy 云服务应用设置里关联小程序 AppID），或退到云函数/服务端代理 |
| `unauthenticated` | SDK auth 流程真机取 token 失败 | 查 SDK `getAccessToken` 的 token endpoint 是否在 mp-api 域内；mock 环境有 storage 告警但成功，真机 storage 可用反而可能走了不同分支 |
| `network` | SDK 内部 fetch 失败 | 检查 polyfill（Headers/URL）与基础库版本 |
| `backend-unavailable` / 其他 | 网关或上游问题 | 用 curl 复现第六节的请求头组合对照 |
