# 数据获取规范（v3.0 对齐版 · 2026-09-21 重写）

> 本文件原为旧 100 分制体系下的补丁（"实时股价必须用 WebSearch"）。该结论已过时：
> neodata 的「统一行情查询」返回带时间戳的实时行情，不再需要靠检索拿价格。
> 现行规则以 `SKILL.md` 为准，本文件只保留具体命令。

## 优先级

| 顺序 | 用途 | 来源 |
|---|---|---|
| 1 | 行情、财报、汇率、分红、研报、公告 | `neodata-financial-search`（脚本自带鉴权缓存，12 小时有效） |
| 2 | neodata 未覆盖的结构化字段（技术指标、股东结构、筹码） | `westock-data`（需先安装） |
| 3 | 前两者都不覆盖的定性背景 | WebSearch / 公司 IR 原文 |

**禁止**：用检索结果拼装可实时查询的字段；混合多来源拼装同一字段；用训练数据回答行情问题。
**双来源核验**：股价、股本、市值、收入、归母净利润、经营现金流、FCF、现金、负债、分红回购、海外收入——每项至少两个来源，误差 >5% 停止估值。

## 标准命令

```bash
SKILL=~/.workbuddy/plugins/cache/cb_teams_marketplace/finance-data/*/skills/neodata-financial-search

# 1) 实时行情（返回带接口查询时间与交易状态，可作[事实]引用）
python3 $SKILL/scripts/query.py --query "安踏体育（02020.HK）最新股价、涨跌幅、市盈率、总市值"

# 2) 汇率（务必单独查，要四位有效数字；不要用中间价两位小数）
python3 $SKILL/scripts/query.py --query "HKDCNY 港元兑人民币 实时汇率报价"

# 3) 财务三表（利润表口径含归母净利润、基本/摊薄每股收益）
python3 $SKILL/scripts/query.py --query "安踏体育 2025年全年归母净利润、每股收益；2026年中期业绩"

# 4) 分红派息明细（港股中期息/末期息分列，用于 DPS0 与股息增长核验）
python3 $SKILL/scripts/query.py --query "安踏体育2026年中期业绩公告 归母净利润 每股股息"

# 5) 港股专项（卖空比例、港股通持股）
python3 $SKILL/scripts/query.py --query "安踏体育 港股通持股比例 卖空比例 最近5个交易日"
```

鉴权失效时：`connect_cloud_service` 取 `tempToken` → `query.py --save-token "<凭证>"` → 重试一次，仍失败即告知服务不可用并停止。

## 曾踩过的坑（保留，避免重犯）

1. **不要用中间价两位小数做估值**：`0.86` 与 `0.8531` 在港股模型里差 0.8%，足以改变分档触发判断。用「外汇汇率」接口的实时价。
2. **港股股息税**：内地个人经港股通持港股，股息按 20% 扣税；倒算买价与 IRR 必须用税后口径，并同时给出税前对照。
3. **归母净利润要区分"报表值"与"调整后值"**：安踏 2026H1 报表归母 94.87 亿，剔除一次性后 79.38 亿（同比 +12.9%）。做正常化基准时用调整后值，并在报告里写清口径。
4. **权益法收益不可当经营利润**：应占联营公司权益（Amer 等）与集团经营溢利分开列示。
5. **历史报告中的价格、汇率、PE 一律视为过期**，包括本技能 references 里的任何数字。
