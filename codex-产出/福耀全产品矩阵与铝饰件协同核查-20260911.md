# 福耀全产品矩阵与铝饰件协同核查

> 核查日期：2026-09-11  
> 财务资料截止：2026年中报  
> 范围说明：“全部产品”指福耀及FYSAM官网、2025年报和2026年中报公开披露的产品家族，不可能覆盖每个整车项目、型号和SKU。

### 2. 基础玻璃和市场产品

| 产品/业务 | 内容 | 分类 |
|---|---|---|
| 汽车级浮法玻璃 | 汽车玻璃深加工的基础玻璃，包括透明、着色、超薄等技术方向 | 上游纵向一体化 |
| 汽车玻璃 | 前挡、侧窗、后挡、天窗及其他车身开口部位玻璃；可叠加上述功能 | 核心主业 |
| 机车/轨道交通玻璃 | 高铁、城市轨道交通、工程车辆玻璃；包括加热除霜除雾等功能 | 同技术、不同客户和认证体系 |

### 3. 汽车铝件和饰件

综合福耀官网、2025年报和FYSAM官网，当前公开披露的产品包括：

| 产品 | 具体形式 | 与车窗一体化程度 |
|---|---|---|
| 车窗铝合金/镁合金亮饰条 | 车窗周边亮条、门框亮条、高光套件 | 中到高，取决于是否与玻璃共同装配交付 |
| 不锈钢亮饰条 | 通过包边注塑或后装与玻璃集成 | 高 |
| PMMA/PC高亮饰件 | 高亮饰条、面板，与玻璃颜色和造型衔接 | 中到高 |
| 彩色字标等装饰件 | 可与玻璃总成集成 | 中 |
| 车窗槽饰条/边缘条 | 可预装密封件，作为完整系统元素交付 | 高，属于车窗开合与密封系统的一部分 |
| A/B/C/D柱饰件、立柱和面板 | 外观装饰；部分产品可集成车窗导轨结构 | 中，靠近车窗系统但不完全等于玻璃 |
| 支架 | 玻璃或饰件安装结构件 | 中，需看具体项目 |
| 门下沿饰条、门槛饰条 | 独立车身外饰 | 低到中 |
| 车顶行李架系统 | 高光、哑光、黑色或彩色行李架，可带横梁 | 低，与玻璃主业的直接协同最弱 |
| 横梁和功能件 | 部分带传感器功能 | 低到中 |
| ALUCERAM表面处理 | 高耐碱黑色/高光/哑光铝表面处理技术 | 属于铝饰件工艺能力 |

关键事实：福耀官网明确把外饰件分为“外饰件集成玻璃”和“独立高亮外饰”两类。因此，不能把全部铝饰件都视作玻璃总成，也不能把全部铝饰件都视作无关多元化。

### 4. 上游材料、装备和工艺能力

| 产品/能力 | 用途 | 是否应视作独立多元化 |
|---|---|---|
| 硅砂 | 浮法玻璃原料 | 否，玻璃上游 |
| 精炼铝 | 铝饰件原料 | 铝饰件纵向一体化，不直接强化玻璃工艺 |
| 模具 | 汽车玻璃、包边、饰件成型 | 原则上属于制造能力支撑 |
| 设备、模检具、检验夹具 | 自制生产设备、工装和质量检测 | 原则上属于主业制造壁垒 |
| 塑料、橡胶、纤维制品和汽车配件 | 用于包边、附件、模具和总成 | 需按最终用途判断；多数与玻璃总成相关 |

公司全球布局页面还列出同步设计、研发、商务、配送和售后服务。这些是解决方案能力，不是单独的实物产品。

## 二、铝饰件是否形成新的竞争力

### 已被事实支持的部分

1. 福耀官网明确披露：通过包边注塑或后装，把不锈钢/铝合金亮饰条、PMMA/PC高亮饰件等与玻璃组成总成。
2. 平齐式车窗需要协调玻璃、外饰件、包边和车身钣金，确实不是单独卖一片玻璃。
3. FYSAM能够供应预装密封件的完整车窗饰条系统，可减少整车厂装配工序和流程成本。
4. 福耀2025年报把精密铝件和智能饰件列为智能玻璃的配套产品，并明确称汽车饰件可满足玻璃集成需求、增强与整车厂的合作联系。

因此，**集成玻璃的铝饰条、车窗槽饰条、导轨/密封结构和平齐式车窗，确实可以构成汽车玻璃主业的同心延伸**。如果福耀能够同步设计并以单一总成、单一质量责任和更少整车厂装配步骤交付，竞争维度就从“玻璃单件”提升为“车窗系统”。

### 尚未被事实证明的部分

1. 公司没有披露多少铝饰件收入来自“玻璃一体化订单”，多少来自独立饰件和行李架订单。
2. 没有披露组合投标是否提高了玻璃项目中标率、单车价值量或客户转换成本。
3. 没有单独披露铝饰件投入资本、自由现金流和ROIC。
4. 车顶行李架、横梁、门槛饰条等产品与玻璃的技术及制造协同较弱，不能自动计入玻璃护城河。
5. FYSAM拥有成熟铝饰件技术和完整生产链，但历史亏损说明“有产品能力”不等于“已创造经济利润”。

## 三、修正后的判断

上一轮把铝饰件整体视为普通多元化，结论过于粗糙，应修正为：

- 福耀绝大多数产品仍围绕汽车玻璃的功能升级、上游材料和总成交付，整体不是跨行业多元化；
- 与玻璃共同设计、装配和交付的铝饰件属于主业延伸，可能增强车窗系统竞争力；
- 独立高亮外饰、行李架和横梁属于邻近业务，仍需单独证明资本回报；
- “业务聚焦”可以由“存疑”调整建议为“基本通过，但设边界”；
- “资本配置”继续维持黄灯，因为协同收入比例和独立ROIC尚未披露。

这意味着：不能给全部铝饰件零估值，也不能因公司称其为“一体化方案”就直接给溢价。更合理的做法是把铝饰件分为“玻璃总成型”和“独立外饰型”两组估值。

## 四、下一步最需要验证的事实

1. 福耀与整车厂签订的是一张玻璃订单还是“玻璃+饰件/导轨/密封”组合订单？
2. 铝饰件与玻璃是否共用同一个项目团队、质量责任和交付编号？
3. 组合交付后，整车厂减少了多少供应商、工序、装配时间和质量责任接口？
4. 集成型铝饰件收入占全部铝饰件收入多少？行李架等弱协同产品占多少？
5. 集成型项目是否提高了福耀玻璃的中标率、份额、毛利率或单车价值量？
6. 铝饰件BU和FYSAM的独立ROIC、经营现金流、产能利用率和盈亏平衡时间是什么？

在以上问题得到回答前，能够确认的是“产品结构存在协同基础”；尚不能确认的是“协同已经转化为可持续经济利润和更宽护城河”。
